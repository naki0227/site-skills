# 使用例：ふねの古本市（架空の催し）

好みの台帳（`plugins/site-skills/skills/site-skills/references/taste.md`、第1〜5回）が、作るものに効くかを確かめるために作った。ユーザーの指示「つくってみて」（2026-11-07）。

- 題材（架空）：鴨谷港の第2岸壁に泊まるフェリー「かもや丸」の船室と甲板が、年に2回、2日だけ古本の売り場になる。11月22日（土）・23日（日）、10:00–16:00、24の古本屋、入場無料。
- 色は3案とも同じ3色：船体の青 #1d3fcf・白（朝の海／甲板のペンキ）・救命浮環の橙 #ff5a1f。台帳の「いちばん好きは3回とも青」から。
- 写真：Wikimedia Commons の4枚（`photos/credits.json`）。画面に出典を書いた。

| 案 | 寄せた「いちばん好き」 | 考えの一文 |
|---|---|---|
| `a.html` 航路 | wedding.tonami-komuro.com（第3回） | 港から島への航路の点線と軌道の線が、丸窓の写真と日付の券をつなぐ。斜体のセリフ体の大きな英字 Books Afloat |
| `b.html` 窓 | dokomi.de（第5回） | 船の青い外板が地になり、角の丸い客室窓・丸窓から甲板と本が見える。信号旗の市松と救命浮環を散らし、日付と数字の札 |
| `c.html` もやい綱 | miraiz-persol.jp（第4回） | 船を岸につなぐもやい綱が、不定形に抜いた本の写真と縦書きの名前に巻きつく色の線になる |

- inspect（PC 1440・スマホ 390）：3案とも FAIL 0。WARN は A 10・B 14・C 14。残した WARN のうち、大きな日本語の題（jp-head-size）・SVG の線（svg-hero）・写真が覆う割合（photo-cover）・橙のボタン（orange-cta）は、台帳の好み（大きな字・線・写真を部品にする・救命浮環の橙）に寄せたため。書体（ai-font）と一語だけ色を替える題（accent-word）は、ユーザーの答えを見て決める。

## 選ばれた B を最後まで作った（`index.html`、2026-11-07）
ユーザーの答え「今回のテーマなら 順番にBCA」。B の最初の画面をそのまま使い、下の章を足した。
- 章：船内の地図と24の古本屋 → 来る前に（雨の日・お金と袋・船の中で）→ 行き方 → 次の回（2027年5月）→ フッター。
- 触れる1つ：船を横から見た図と階のボタン。階を選ぶと、図のその階が青くなり、店の点（橙）とその階の店の一覧だけが残る（4階 甲板 8店・3階 客室 10店・2階 車両甲板 6店）。スクリプトが無くても24店ぜんぶが見える。
- 最初の画面の形を下まで運ぶ：船体の丸窓（地図の船・来る前にの写真）、信号旗の市松（見出しの横）、救命浮環（次の回の帯）。色は3色のまま。
- 店・港・船・町の名前はすべて架空。
- inspect：FAIL 0 / WARN 14（PC 1440・スマホ 390）。直した FAIL：枠線の数（一覧の罫を外した）、スマホの横スクロール（写真の列）。

## 下の章の作り直し：ヒーローと別々にしない（2026-11-07）
ユーザーは下の章の良し悪しを判断できないと言ったので、好きな実在サイトの同じ役目の章と4組並べて聞いた。答えは「全部Y（実在）」「ヒーローと別々じゃない感じがしていい」。下の章を、最初の画面の部品が主役のまま続く形に作り直した。
- 24店：青の地のまま、極太の大きな見出しと、右の端からはみ出す本の丸窓。船の図を画面の幅いっぱいにし、各階に店の番号の橙の丸を描いた。一覧は、左に切り欠きのある乗船券の形の札。
- 来る前に：クリームの地に、左の端からはみ出す大きな市松の旗、右下からはみ出す浮環、航跡の窓。3つの項目は、最初の画面の窓と同じ角の丸め方の青い面。
- 行き方：日付を両側に切り欠きのある乗船券に。甲板の写真を、最初の画面と同じ形の窓で右の端からはみ出させた。次の回は、最初の画面の右下と同じクリームの不定形の面。
- 前の版（見出し＋文＋表）は、ユーザーの見比べで4組とも負けた。
- inspect：FAIL 0 / WARN 21。

## 下の章に本物の人を入れる（2026-11-07）
1つずつ変えた3案（`test/`）で、ユーザーは「人を入れる」と「断面の絵」をどちらも「いい」、題材的に本物の人の写真のほうがいいと答えた（重ねて細かくする案は「煩雑」）。`index.html` の下の章に、古本市・古本屋で本を見る人の写真（神田古本まつり・セーヌ河岸・神保町）と、岸壁を歩いて船に乗りに行く人の写真（ワニノ港）を入れた。どれも何が写っているかを書き、ふねの古本市の写真としては見せていない。
