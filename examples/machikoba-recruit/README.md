# 使用例：町工場の採用サイト（河内精機）

架空の依頼「大阪府東大阪市の町工場・河内精機（創業1965年、従業員38名、精密な金属部品の切削）の採用サイト。若手の機械オペレーターを採りたい」を、site-skills の手順どおりに1枚の HTML にしたもの。

- ファイル：`index.html`（依存なし・外部読み込みなし・画像なし。図は SVG。約 72KB）
- Artifact：https://claude.ai/artifact/WZVX1SbegJjs3XMWmoqeA7
- 会社・人物・電話番号・求人番号はすべて架空（ページのフッターにも書いた）。

## 作る前に決めた4つ（site-skills）
- **ただ1つの行動**：工場見学の申し込み（同じフォームで「見学してから応募」「見学なしで応募」も選べる）。
- **相手と来た道**：東大阪・八尾あたりの10代後半〜20代。工業高校生、フリーター、別の仕事からの転職。ハローワークの求人票・学校の進路指導・Instagram から来る。
- **まだ動かない理由3つ**：①町工場は暑い・汚い・きついという印象 ②図面も機械もわからない不安 ③給料・休み・残業が見えない。
- **出せる証拠**：残業 11.4時間・年間休日 117日・定着 8/9人・技能検定 14人の実数、先輩4人の声（前職つき）、設備台数、1日の流れ、空調で室温 31.2℃→27.4℃。

1文にすると：「東大阪の10代後半〜20代に、まず工場見学をフォームから申し込んでもらう採用ページ」。

## 選んだスキルと理由
- **主：`corporate-quality-bar`（下位タイプ：採用サイト）**。してもらうことが「会社を信頼して、採用に進んでもらう」なので、選ぶスキルの表どおり。
- **副：`lp-quality-bar`（雰囲気：ミニマル・ハードウェア）**。corporate は「流れ・骨組み」のスキルで、見た目の値を持たないため。teenage engineering の「製品が主役で UI は黒子、墨・白・灰だけ」が、「部品（切削品）を主役にする」町工場に合う。和・上質（とらや）は老舗の菓子寄り、読みもの（ほぼ日）は人が主役で数字が弱い、と比べて外した。
- corporate の「採用サイト」「中小・地域企業」は**見本がまだ無い**ので、スキルの指示どおり近い見本を使った：LayerX（startup.md。採用サイトを持つ）と Valmont（enterprise.md。機械加工・溶接の採用写真を持つメーカー）。

## 確かめたこと（Playwright、1440px と 390px）
- 最初の画面と全体を撮って目で見た。最初に撮ったときの問題を3つ直した：①フォームの「確認する」ボタンが明るい地に白で見えなかった（フォームの枠を明るい章として扱った） ②h1 が「7分の / 1を、」で切れた（語のまとまりを inline-block に） ③章の見出しの下線と一覧の上線が二重。
- 横スクロール：なし（scrollWidth＝画面の幅。はみ出すのは overflow:hidden の帯の中だけ）。
- コンソールのエラー・ページのエラー：0。
- 操作：部品のタブ（クリックと←→キー）、人の「話を読む」、沿革の年、給料の切り替え、フォーム（空で送る→8か所のエラーの一覧とその欄の赤枠 → 入れて確認 → 送る（送信中の表示）→ 完了と受付番号 → もう一度）、使ったスキルのダイアログ（Esc で閉じる）、SPメニュー、帯の「止める」。すべて動いた。
- reduced-motion：帯の animation が none になることを確認。

## スキルで足りなかったこと（自分で決めた部分）
スキルを育てるための手がかり。ここに書いたことは、どのサイトの値でもなく、自分で決めた。

1. **採用サイトの見本が無い**（corporate の recruit.md・sme-local.md が空）。「社員の声の見せ方」「職種の探し方」「応募までの手順」「募集要項の項目と並べ方」「見学から入る流れ」は、どの実在サイトの値でもない。人の行・1日の流れ・給料の切り替え・見学日の選び方はすべて自分で作った。採用サイト（特に中小の製造業）を1つ解剖すると、この例の大半が出典つきに置き換えられる。
2. **募集要項・応募フォームの型が無い**。必要な項目（給料・賞与の実績・年間休日・応募資格の年齢の例外事由・試用期間）、フォームの欄の数と必須の数、確認画面の有無、エラーの出し方は corporate に無い。LayerX の「入力→確認→完了・入力欄8つ」だけを足場にし、エラーの一覧・欄の赤枠・残りの必須の数・文字数は自分で決めた。エラーの色 #b30000 はとらや（lp wa-premium）の目印の赤を借りた。
3. **見た目の値の多くが英語のサイトの値**。Valmont の h1 76.5px・行間 1.05・字間 -0.03em は欧文用で、和文に当てると行が重なる。行間 1.25・字間 0 は自分で決めた。日本語の採用・コーポレートサイトの文字の値が欲しい。
4. **雰囲気の表に「工場・ものづくり」が無い**。ミニマル・ハードウェアを借りたが、teenage engineering は「製品写真が色を持つ」前提で、写真を使わない（使えない）場合に色をどこに持たせるかは書かれていない。部品の図を SVG で描いて色を持たせたのは自分の判断。
5. **teenage の文字の段（980幅で 18px）を 1440px にそのまま比率で伸ばすと本文が約 26px になる**。上限 1080px で止めたのは自分の判断（スキルには「ズームを止めない・下限をつける」はあるが、上限は無い）。
6. **teenage の補助色 #7f7f7f は明るい章の上で 3.67:1**。lp の minimal-hardware.md は墨の地しか想定していない。明るい章の補助色 #5c5c5c は自分で決めた。
7. **流れる帯を止めるボタン**（WCAG 2.2.2）はどのスキルにも無い。reduced-motion で止まるだけでは足りないので足した。
8. **架空の会社の扱い**（電話番号・求人番号を架空と書く、送信しない旨を完了画面に出す）はスキルの範囲外で、自分で決めた。
