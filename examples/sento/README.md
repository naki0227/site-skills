# 使用例：十条湯 サウナ予約（架空）

東京・北区の架空の銭湯「十条湯」のサウナを、60分ごとの枠で予約する画面。男女別・定員6名・当日割あり。日付・時間帯・人数を選んで空きを見て、予約の前（内容の確認）までを作った。

- 画面：[`index.html`](index.html)（1枚の HTML・外部ファイルなし・約56KB）
- Artifact：（公開後に追記）
- 作った日：2026-10-26

## 決めた4つ（site-skills「作る前に決めること」）
| 項目 | 決めたこと |
|---|---|
| ただ1つの行動 | 空いている60分の枠を選んで「予約へ進む」（予約を確定する直前まで） |
| 相手・どこから | 十条・東十条・王子あたりに住む常連と、Google マップや「十条 サウナ」で検索してきた人。ほとんどスマホ、仕事帰りの夕方〜夜 |
| まだ動かない理由3つ | ①行っても満員かもしれない（電話しないと分からない）②サウナ代が入浴料込みか、当日割がいつ効くか分からない ③行けなくなったときに何か取られるか分からない |
| 出せる証拠 | 昭和29年創業、サウナ92℃・水風呂16.5℃（地下水）・外気浴4脚、定員6名の男女別、料金の内訳（550円＋680円、当日 −160円）、キャンセルは1時間前まで無料・支払いは当日番台 |

理由①には枠ごとの残り席（6マス）と日付の ○△×、②には合計の内訳と「表示の合計から増えません」、③には合計の枠の中のキャンセル・支払いの3行で答えた。

## 選んだスキルと理由
- **主：`booking-quality-bar`**。してもらうことが「空きを探して予約してもらう」なので、site-skills の表どおり。
  - 下位タイプは **レンタル・体験**（時間で区切った枠を予約する体験に近い）。ただし見本がまだ無いので、SKILL.md の「近い下位タイプの見本を使う」に従い、**チケット・イベント（DICE）** と **宿（じゃらんnet）** の値を出発点にした。飲食（時間帯の選び方）も近いが、こちらも見本が無い。
- **副：`lp-quality-bar`**、雰囲気は **温かい飲食（びっくりドンキー）**。booking は「流れ」のスキルで見た目の値を持たないため。銭湯は「地域の店」で、温かい飲食の向く題材に当たる。和・上質（とらや）は老舗にも合うが、無彩色の引き算は町の銭湯の気安さと合わないので選ばなかった。混ぜていない（1つだけ）。

## スキルで足りなかったこと（自分で決めた部分）
スキルを育てるための手がかりとして、正直に書く。

1. **時間で区切った枠の見本が無い**。レンタル・体験も飲食も「（まだ無い）」で、60分の枠を1日分並べる型・一つの枠の定員の見せ方・受付の締め（開始15分前）は、どのサイトの値も無かった。じゃらんnet の部屋数の段階（10室以上／4〜9／1〜3）を定員6に縮めたのは自分の判断。飲食（席の時間帯予約）か体験（ジム・サウナ・教室）の予約サイトを1つ解剖すると埋まる。
2. **男女別のような「分かれた在庫」を選ばせる型が無い**。どちらを先に聞くか、切り替えたら選んだ枠を外すかは自分で決めた。
3. **割引の見せ方が無い**。DICE は割引コード（ログイン前に開けない、という弱点）だけ。日付で自動に付く割引（当日割）を、日付の帯・一覧・内訳でどう示すかは自分で決めた。
4. **予約前の確認の段の中身**。SKILL.md は「確定の直前まで」が範囲だが、確認の段（規定への同意のチェック、エラーの出し方）の見本は無かった。DICE・じゃらんnet とも、その手前で止まっている。
5. **文字の大きさの段と日本語の本文**。booking には文字の値が無く、lp の温かい飲食（びっくりドンキー）も文字は「丸い英字＋小さな和文」だけで、大きさ・行間の数値が無い。12〜40px の段と行間1.7は自分で決めた。
6. **構造化データの型**。viewpoints は Hotel・Restaurant・Event などを挙げるが、銭湯・サウナに合う型は無い。`LocalBusiness`＋`Offer` は自分の判断（実在サイトでの確認なし）。
7. **checklist.md が下位タイプ別に分かれていない**。宿の項目（泊数）とチケットの項目（一覧カードの4列・割引コード）が同じ表に並び、当てはまらない項目を自分で外す必要があった。どの下位タイプの項目かを書いておくと迷わない。
8. **SP で最初の画面に検索を入れる、という決まりが booking に無い**。lp の compare.md（星野リゾート「検索が最初の画面」）で気づいたが、booking 側には値が無かった。
