# 使用例：瀬戸ノ口陶器市の特設ページ

依頼（架空）：岐阜県の架空の町「瀬戸ノ口」で毎年5月に開く陶器市（窯元41軒・2日間）の特設ページ。来場してもらうことが目的。日程・会場マップ・出店する窯元・アクセス・雨天時の案内を1ページで。

- ページ：`index.html`（1枚の HTML、約55KB。外部は Google Fonts の3書体〔Noto Sans JP・Shippori Mincho B1・Klee One〕だけ。写真3枚は `photos/`〔Wikimedia Commons、出典は `photos/credits.json`〕）
- Artifact：https://claude.ai/artifact/TXFnEFtKe1fwRYM5HVcWpc （非公開。見せるには Artifact の共有メニューから共有する）
  - Artifact の中では「カレンダーに入れる」（.ics のダウンロード）が動かない（ビューアーがダウンロードを許さないため）。`index.html` をブラウザで直接開けば動く
- 2026-10-26 に4回、2026-11-02・11-05 に1回ずつ、11-06 に3回作り直した。いちばん新しいのは下の「9回目の作り直し」。それより前の記録は「作り直しで変えたこと」

## 8回目の作り直し（2026-11-06）：写真と文字以外の要素を足す（本物か作例か 第3回）
第3回の当てっこで、陶器市は「明らかに AI」に選ばれた（銭湯・町工場とともに）。決め手は「文字の後ろの色とか背景色、文字と写真以外の要素（イラストとか）が無い」。選ばれなかった学童アプリ（名前マグネットの札・アプリの画面・手書きのメモ）と焙煎所（手描きの袋の絵・回る英字の刻印）との違いはそこだけだった。相手の mamafes.net は、線の人物・吹き出し・札を写真に重ねていた。前回の報告の「手の跡のある絵が無い」がそのまま当たった。

### 足したもの（どれも自分で描いた SVG。線は `feTurbulence`＋`feDisplacementMap` でゆらし、判子は掠れさせた）
| 要素 | 題材のどこから | 置き方（PC） |
|---|---|---|
| 茶碗と湯呑のスケッチ | 並ぶ器。墨の線、志野の白、内側に緋色・湯呑に灰釉の淡い塗り | 角丸の皿の写真の下から灰釉の面にかかる（右上） |
| 窯元の判子「窯元 四十一軒」 | 窯元の印。朱の二重丸、掠れたインク | 灰釉の面の上、日付の右に傾けて |
| 窯の煙 | 登り窯の煙。ゆらいだ3本の線 | 丸の登り窯の写真から、アーチの空へ立ちのぼる |
| 手書きの値札（前からの HTML） | 店先の札 | アーチの右下からはみ出して傾く |

- 日付・一文・ボタンは、PC では灰釉の色の面の上（前から）。スマホでも、日付・一文・ボタン・出典を灰釉の面の上に置いた（前は生成りの無地）。題はのぼりの緑の上。
- 601〜1200px の幅を足した：写真を上半分、文字を下半分の灰釉の面に（992px で日付と写真が重なっていた）。

## 7回目の作り直し（2026-11-06）：最初の画面に層を作る（本物か作例か 第2回）
明るく作り直した版を、実在の plantsandcrafts.dougukan.jp（植物×匠）と名前を隠して並べたら、また見抜かれた（決め手「文字の大きさ、デザイン性のある枠、並べ方」）。前の版は「左に題・右にアーチの写真」の行儀のよい2列で、余白が広く、題はふつうの明朝の 80px だった。

### 手本の層と題の作り方（前回撮った10件から3件）
- **植物×匠**（plantsandcrafts.dougukan.jp）：白地 → 画面の中ほどから下に**灰の色の面**（全幅の帯）→ その上に**不定形に切り抜いた写真**（茅葺きの里と人）を大きく置き、帯からも画面の下端からもはみ出す → 写真の外の右上に、**黒の大きな題「植物×匠」**（約120px、太い）と会場ごとの日付、左上に**縦書きの副題**。層は 地・帯・写真・題・縦書き の5つ。
- **ママフェスまつもと**（mamafes.net）：白地 → 中央に**角の丸い不定形の枠の写真**（子どもが遊ぶ広場）→ その左端に重ねて**傾けた黄色の札**（次のイベントの日時）→ 右端に重ねて**縦書きの題を青・黄の札に1文字ずつ**（「この街の子育てを誇りに」）→ 下に**手描きの線の人物の絵**が写真にかかる。層は5つ、重なりとはみ出しが4か所。
- **燕三条 工場の祭典**（kouba-fes.jp）：灰の地 → **同じポスター（青・橙の不定形）を3枚**横に並べ、題「燕三条工場の祭典2026」を各ポスターの下に → 下に**職人の写真5枚の角丸の帯**（右端で切れて画面の外へ）。題はポスターの絵と一体で、文字そのものより絵が主役。

### 前と後で変えた値
- **最初の画面**：のぼり＋会場図＋値札（381字）→ **暗くしたモノクロの写真（有田陶器市の通り）を全面に敷き、題「瀬戸ノ口陶器市」96px・日付 32px・一文・ボタン1つ**。会場図は2つ目の章に下ろした。写真の出典は写真の右上に小さく重ねた（外に帯を足さない。`ai-tells.md` 第3回）。
