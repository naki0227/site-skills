# 使用例：瀬戸ノ口陶器市の特設ページ

依頼（架空）：岐阜県の架空の町「瀬戸ノ口」で毎年5月に開く陶器市（窯元41軒・2日間）の特設ページ。来場してもらうことが目的。日程・会場マップ・出店する窯元・アクセス・雨天時の案内を1ページで。

- ページ：`index.html`（1枚の HTML、外部の読み込みなし、58KB）
- Artifact：（公開後に書く）

## 決めた4つ（選ぶスキルの「作る前に決めること」）
| 項目 | 決めたこと |
|---|---|
| ただ1つの行動 | 当日、来場してもらう。ページの上ではその手前の「カレンダーに入れる」（.ics）を主のボタンにし、「行き方を調べる」をヘッダーに常に置く |
| 相手・どこから | 岐阜・愛知に住む器好き。前年に来た人と、Instagram・地元ニュースから来る人。多くはスマホ（仮定） |
| まだ動かない理由 | ① 車で行って停められるか・電車で行けるか（遠い）② 雨だったらどうなるか ③ 41軒もあって、どこを回ればいいかわからない |
| 出せる証拠 | 第38回という続いた年数、窯元41軒の名前と器と値段、昨年の来場 2万8,700人、昨年 P1 が満車だった時間（10:40〜13:10） |

動かない理由の3つに、1つずつ部品を当てた：①→ 出発地を選ぶ行き方と駐車場の表、② → 判断の時刻と3段階、地図を「雨の日」に切り替える、③ → 窯元の絞り込みと「回る窯元」（駅から歩く順に並べ直す）。

## 選んだスキルと理由
- **主：`game-quality-bar`（下位タイプ「イベント・ライブ」）**。選ぶスキルの表の「行く準備をしてもらう」に当たり、`types/event.md` が「日程と会場、当日の案内」を見ることにしている。依頼の中身（日程・会場・行き方・雨天）がそのまま当たる。
- **副：`lp-quality-bar`（雰囲気「和・上質」）**。game の SKILL.md が「トップ1枚の見た目は lp-quality-bar」と言っている。陶器（工芸）なので「和・上質」（とらや）を選んだ。UI を無彩色に引き、色を器（釉の色）に持たせられる。
- 迷った点：選ぶスキルの「迷ったとき」には「1ページで完結し、流れが無い → lp」とあり、lp を主にする読み方もできた。日程・地図・行き方という**来場までの流れ**を持つ型が game の event 側にしか無いので、game を主にした。

## チェックリストの結果
確かめ方：Playwright（Chromium）で 1440px と 390px の最初の画面・全体・地図・ダイアログを撮って目で見た。1200/992/768/600/430/360px で `scrollWidth` が画面幅と同じ（横スクロールなし）。コンソールのエラー 0。タブ（クリック・矢印キー・URL）、地図の点・晴れ／雨の切り替え、検索・焼き・区画の絞り込み・0件のときの表示と解除、「回る窯元」（localStorage に残り、読み直しても残る）、行き方の切り替え、登録フォームの空・形の誤り・成功、.ics のダウンロード、`#kiln-B3` で開く、をスクリプトで動かして確かめた。

## スキルで足りなかったこと（自分で決めた部分）
1. **主と副の決め方がぶつかる**：選ぶスキルの表では「行く準備」で game、「迷ったとき」では「1ページで流れが無い → lp」。地元のイベント（陶器市・祭り・マルシェ）の特設ページがどちらか、書かれていない。
2. **地図の型が無い**：会場マップの描き方（区画・番号・凡例・SP での大きさ・雨の日の切り替え）は、どのスキルにも実測が無い。全部自分で決めた。Lollapalooza の会場図や、実在の陶器市（多治見・瀬戸・益子など）の会場図を解剖すると埋まる。
3. **出店者一覧（数十件）の型が無い**：game の event はラインナップを「文字で組む」までで、40件前後をどう絞り込み・並べるか（区画・種類・検索・0件）は無い。窯元名・器・値段の並びも自分で決めた。
4. **雨天・中止の案内の型が無い**：屋外イベントで最も気にされる「判断の時刻・3段階・変わる場所」は、Lollapalooza の解剖が開催後だったこともあり何も無い。
5. **行き方・駐車場の型が無い**：出発地を選ぶ切り替え、駐車場の表、満車の時刻、シャトル。booking の宿・飲食の側にもアクセスの型があるか確かめていない。
6. **「回る窯元」（自分の回る順のリスト）**：フェスの「マイタイムテーブル」に当たる部品だが、スキルに無い。
7. **lp の common.md と和・上質の型がぶつかる**：common.md の「1セクション1アクセント色」「和文太・字間広め」「ディテール3つ（ずらし影など）」が、とらやの「無彩色・字間は触らない」と合わない。checklist.md は common.md 側で書かれているので、和・上質を選ぶと checklist を満たせない項目が出る。どちらを優先するかが書かれていない。
8. **ヒーローに文字を載せない型と、イベントの日付をすぐ見せる必要**：とらやは「文字は載せない」、Lollapalooza は「日付をヘッダーに常時」。両方を取り、題と日付は器の下に置いたのは自分の判断。
9. **game-quality-bar の event.md は Lollapalooza 1件で、英語・大規模フェス**。地方の小さな催し・日本語の見本が無いので、値（Anton・青 `#32c3e2` など）は見た目には使わず、流れと反面教師だけを使った。
