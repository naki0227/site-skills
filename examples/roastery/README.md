# 使用例：三日月珈琲（コーヒー豆の通販）

site-skills が「AIっぽくない質の高いスキル」になっているかを試すために、架空の依頼を1つ形にしたもの。

- 依頼：福岡市の小さなコーヒー焙煎所「三日月珈琲」の通販サイト。豆は12種類、200g と 500g、挽き方を選べる。定期便あり。商品一覧 → 商品詳細 → カートまで。
- 成果物：`index.html`（1枚・約70KB。外部は Google Fonts の Klee One だけ。絵は使わない）
- 2026年10月26日に、ユーザーの「結構AIっぽい」という評価を受けて作り直した。下の「作り直しで変えたこと」が今の版。「当てた型と出典」以下は1回目の記録で、アーチ・紙色の地・袋の絵など、作り直しで外した部品も含む（今の版の部品と出典は、画面右下の「使ったスキル」にある）。
- 公開：https://claude.ai/artifact/ExdgusUQzC4gUZcihJdrLw（Artifact。非公開なので、見せる相手には Share から共有する）

### 作り直しで分かった、スキルで足りなかったこと
- ec-quality-bar の見本（とらや・Allbirds）はどちらも写真が主役の一覧で、**写真を使わない一覧**（文字のラベルが主役）の型が無い。ラベルの組み（何を何行、どの書体で）は自分で決めた。
- とらやのボタンは角丸23px のピルだが、ai-tells は「丸いピルのやわらかい見た目」を AI っぽさに数える。ai-tells は「種類ごとのスキルを優先」と書くが、今回は親セッションの指摘に従って四角にした。どちらを優先するかの線引きが要る。
- lp-quality-bar「温かい飲食」の型（紙色2色の地・アーチ・楕円の境目）は、ai-tells の「やわらかい無難な地」とほぼ同じものを指す。副で当てると AI っぽさが出やすい型なので、lp 側に注記があるとよい。
- 焙煎予定の黒板・焙煎記録のような「題材でしか成り立たない部品」を探す問いが、ec の viewpoints には無い（ai-tells の最後の問いだけ）。

## 選んだスキルと理由
- 主：**ec-quality-bar** — `site-skills` の表で、してもらうことが「商品を探して買ってもらう」（一覧→詳細→カートの流れがある）ため。
- 副：**lp-quality-bar** — ec-quality-bar は流れの型で、店の雰囲気（色・角・遊び）を決める型を持たない。選ぶスキルの手順3に従って足した。食い違いは主を優先（文字の大きさ・字間・ホバーはとらや側）。
- 下位タイプ：ec は **食品・ギフト**（見本：とらや）。定期便は「単品・D2C」の問いだが見本が無いので、食品・ギフトを出発点にした。lp の雰囲気は **温かい飲食**（見本：びっくりドンキー）。

## スキルで足りなかったこと（自分で決めた部分）
スキルを育てるための手がかりとして、出典の無い判断をすべて書く。

1. **定期便の見せ方**：ec の viewpoints は「単品・D2C」で定期購入を問うだけで、見本が無い。割引率（8%）・間隔（2/3/4週）・解約の締め（5日前）・「回数の縛りなし」を詳細の買い方の選択に置くこと、かごの行に「定期便（3週ごと）」と出すこと、定期便を一覧の下に帯で説明することは、どれもサイトの値が無く自分で決めた。定期便のあるストア（コーヒー・D2C）の解剖が要る。
2. **バリエーションが「容量×挽き方」の2軸で、挽き方が在庫に関係しない場合**：Allbirds（サイズ×色、どちらも在庫あり）ととらや（箱の入り数は別URL）はどちらも当てはまらない。挽き方を文字のボタン5つ・用途を小さく添える形は自分で決めた。
3. **焙煎日・お届け日の計算**：とらやは「最短お届け日」を出すが、「焙煎してから送る」店の、焙煎日→発送日→到着日の3段の見せ方は見本に無い。
4. **絞り込みを即時反映にした判断**：rules 6 は「即時にしない場面では適用ボタン」と書くが、即時にしてよい条件（件数・通信の有無）を書いていない。12点・通信なしなので即時にした。
5. **包装の「必須」**：checklist は「のし・包装をかごで商品ごとに必須で選ばせる」だが、ギフトでない自宅用の豆に毎回選ばせるのは手間になる。ギフトの比率が低い店で同じ扱いでよいかは、スキルに判断の材料が無い。
6. **主と副の食い違い**：lp の checklist（欧文細×和文太・字間広め・見出しの型の繰り返し）と ec の見本（とらや：字間 normal）がぶつかる。選ぶスキルの「主を優先」に従ったので lp の項目に × と △ が付く。副として使うときに lp のどの項目を外してよいかが、lp 側に書かれていない。
7. **一覧の焙煎度の目盛り・産地の行**：食品の一覧カードに「味の手がかり」を何で載せるかは見本に無い（とらやは名前と価格だけ）。5つの豆の目盛りと産地の行は自分で足した。
8. **品切れの札の位置**：とらやの順位札は写真の左上だが、アーチの角では左上が切れる。札を下に置いたのは自分の判断。
9. **かごに入れた後の知らせの重なり**：ec rules 1 はドロワー（Allbirds）と上から下りる帯（とらや）を同列に挙げるが、両方を使うと帯がドロワーの頭を隠す。どちらか1つにする、と書いてあると迷わない。
10. **送料の地域区分と金額、送料無料の線（4,800円）、ギフト箱の値段、返品の連絡先**は題材の設定として自分で決めた（スキルの範囲外）。
