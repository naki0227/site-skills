# 最初の画面（ユーザーに「本物か作例か」を当ててもらった結果）

出典：2026-11-05〜11-26、作例と、事例集（Web Design Clip）の実在のサイトを並べ、ユーザーに AI の作例を当ててもらった第1〜20回。くわしい記録は site-skills の `references/aesthetic.md`「本物か作例か」と `references/ai-tells.md`。ここには、型の数値より先に守ることだけを置く。

## まず雰囲気を1つの言葉で決める
- 作る前に雰囲気を1つの言葉で決め（例「曇り日の深い水」「飴色の朝」）、写真・大きな字・小さな字・構図・色を全部それに合わせる。部品を足すたびに「この字はこの写真と同じ世界か」を見て、合わなければ外す（第14回：力強い筆の「永」＋静かな写真＋細いゴシックの項目は「雰囲気と、文字の雰囲気と、構図が合ってない」で全部当てられた）。
- 雰囲気は題材の世界から取る。好きな見た目（ファッションのポップな作り）を、銭湯・陶器市・町工場にそのまま当てない（2026-11-07「全然雰囲気に全部合ってない」）。町の人が英字で呼ばない店の名前を英字にしない。
- 好きと言われた実在は、写真・字・構図が同じ世界：atami-sanga.jp（静かな暗い海＋小さな筆のロゴ＋余白）、ginger.sakatashop.jp（泥つきの生姜の接写＋荒い筆の大きな「強い生姜」「夏。」）、gunte-lab.kachiboshi.co.jp（白い地＋黄色の縁取りの英字＋手袋を作る人＋吊るした手袋）、tabotenzu.com（破いた紙の窓の中の家族の写真）、mtd-inc.co.jp/recruit（破いた紙・網点・矢印の切り貼り）、fondan.jp（焼き菓子の接写のはみ出し）。 いちばん好きと言われたのは nbgcp.com（全身の人を切り抜いて並べ、まわりに切り抜いた文字や形を色とりどりに散らし、大きなセリフ体の英字の見出しと小さな日本語の一言、第19回）。作例で「AI だと思うけど好き」と言われたのは、縦長の写真3枚（昼の川・宿の広縁・夜のガス灯）の上に藍の暖簾を掛けて屋号を染め抜いた温泉宿（第19回）。

## 主役
- その土地の人の写真が多い題材なら、人を主役にする。人の写真を何枚も重ね、まわりに題材の世界の物（札・団扇・値札・伝票）を組み、名前はその物の上に置く（第20回：いちばん見分けにくかった「あーわからん」。好きと言われた実在も人が主役のものが多い。顔が大きく分かる写真と子どもは使わず、出典の行に「写真の人物は店と関係ありません」）。
- 写真が大事（2026-11-21、ユーザー「やっぱ写真って大事」。並べた実在の多くは写真が主役）。本番のサイトは店の自前の写真を主役にする。作例は、先に良い写真がある題材を選んでから作る（写真が弱い題材を絵で埋めると、絵で分かる）。
- 写真は1枚に限らない。写真の上に写真を重ねる・何枚かを並べてずらす（第18回「写真一つだからかな？ 写真の上に写真重ねたりとか、そういうのがあるとなおいい」。実在の seiwaceramics はタイルの写真を何枚も重ね、yuien.life は3枚を並べた上にロゴを重ねていた）。
- 主役（見せたい物）は1つ。写真なら、扱いに作り手の手を入れる（破いた窓・接写のはみ出し・切り貼り・大きな筆の言葉と組む）。土地の写真1枚をそのまま大きく置き、名前を小さく字を少なくしただけの画面は「ビミョい」（第15回）。
- 写真は題材の土地・時代と合うものだけ。合う写真が無ければ絵で描く。ただし続けて作る作例を全部絵にしない。プログラムで線を揺らした SVG の絵は、ベクターの均一さで作った絵だと分かる（第17回「SVG か、あとフォントとかですごいわかりやすい」）。絵にするなら、手で描いた質（線の太さのむら・塗りのはみ出し・紙や筆の質感）が出る描き方を選ぶ（第14回：愛媛のみかんにイスラエルのオレンジ収穫の写真、堺の鍛冶屋に築地の研ぎ場の写真で、雰囲気が合わなかった。第12回：手の揺れのある線で描いた夜の古本屋の絵は本物として通った）。
- 器・食べ物・布・花など色そのものが商品の物は、色を変えない（2026-11-16「元々の色しっかり見えないとダメなやつは色変えちゃいけんでしょ」）。
- 切り抜きは、輪郭を手で囲んで整える。縁がきれいに取れない写真は切り抜かない（第9回「写真の切り取りの甘さ」）。

## 字
- 名前は、題材の世界の中に現れる形を先に考える（第16回：曇ったガラスを指でなぞった跡で書いた花屋の名前は、実在と見分けがつかず通った）。
- 名前を書体で画面いっぱいに大きく置かない（第10回：作例5つが全部それで当てられた）。大きく見せる字は、手で引いた字（SVG のパス・レタリング）のほうが本物に見えた。
- キャッチコピーを文章にしない。「〜しています。」「〜を、〜に。」の1文は置かない。置くなら「強い生姜」「夏。」のような文になっていない言葉だけ（2026-11-16）。それも毎回は置かない：手で書いた大きな言葉＋「。」を物の横に置く形（「朝五時。」「七時。」「ネル。」）は続けるうちに型になり「わかりやすい」と当てられた（第16回）。キャッチコピー＋手書き風の下線を左下に固めるのは「めっちゃ嫌い」（2026-11-07）。
- 小さな情報の字（日付・時刻・所在・ボタン）を明朝や手書き風にそろえない。雰囲気に合うふつうの書体で（第12回：3つともそこで作例と分かった）。
- 小さな字の書体を1つに決め打ちしない（第17回：全部の作例の小さな字を Noto Sans JP にそろえていて、書体で分かりやすいと言われた）。雰囲気の言葉から作例ごとに選ぶ。

## やらない（当てられた形）
- 写真の上に地の色の違うカードを貼る（第8回）。題を色の箱に入れる・題のすぐ上に短い日付（第7回）。
- 作例どうしで同じ組み方（1色の地＋大きな名前の真ん中に切り抜き＋右端の縦書き＋丸い印）（第9回）。
- 決まりを1つずつ満たして部品を集める。決まりは足すほど全部の作例が同じ形で満たして型になる（第1〜8回）。
