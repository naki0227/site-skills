# メディアで見ること・決めること

解剖でも、作るときでも、この順に見る。作るときは、それぞれに「どうするか」を1行で決めてから書き始める。
解剖で裏づけた値は `types/<slug>.md` に、どのサイトの値かを添えて書く。このファイルには問いだけを置く。

- **本文**：本文の幅（1行の文字数）、文字の大きさ、行間、段落の間、見出しの段（PC/SP）、書体。
- **記事の頭**：題、日付と更新日、著者、カテゴリ、アイキャッチ、リードの並び。
- **目次**：あるか、固定か、いま読んでいる位置を示すか。
- **部品**：画像・図・表・引用・コード・手順（番号）・注釈の組み方、SP で表をどうするか。
- **記事の終わり**：著者紹介、関連記事、シェア、次の記事、購読の誘い。
- **広告と同意**：広告の位置と数、読み込みでレイアウトがずれるか、同意バナーの大きさと重さ。
- **データと重さ**：構造化データ（Article・NewsArticle・Recipe・BreadcrumbList）、OGP、記事1本の通信量、文字サイズの変更・ダークモード。
