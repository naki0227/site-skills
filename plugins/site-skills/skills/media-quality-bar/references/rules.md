# 横断ルール：メディアのサイトをまたいで効いていること

2つ以上のサイトで同じ結果になったことだけを、番号つきで書く。1サイトだけの発見は `types/<slug>.md` に置く。
書くときは（〇〇と△△で確認）のように、元になったサイトを添える。

1. 長い記事でも目次を付けないサイトがある。高さ1万px超の記事は目次と「いま読む節」の印を付ける（メルカリエンジニアリング：高さ 15,659px、ProPublica：高さ 21,446px、どちらも目次無し）。
2. 画像の width/height が抜けると、記事の途中で寸法が決まらず、元画像を引き伸ばしたり本文を押し下げたりする。全画像に寸法を付ける（メルカリエンジニアリング：アイキャッチ無しで PC CLS 0.064、ProPublica：長い記事の写真が元 300px を 810px に拡大）。
3. 記事の終わりに「次の1本」へ進む大きな導線を置く。2サイトとも関連は小さな一覧だけで、著者紹介も無かった（メルカリエンジニアリング：関連3件の帯、ProPublica：Read More 枠・More in 分類6本・Most Read 9本）。
4. 一覧の2ページ目以降に URL を持たせる（メルカリエンジニアリング：「もっと見る」で増やした分に URL 無し、ProPublica：連載の川24本で終わり、次のページへのリンクが見つからない）。
