# 横断ルール：メディアのサイトをまたいで効いていること

2つ以上のサイトで同じ結果になったことだけを、番号つきで書く。1サイトだけの発見は `types/<slug>.md` に置く。
書くときは（〇〇と△△で確認）のように、元になったサイトを添える。

1. 長い記事でも目次を付けないサイトがある。高さ1万px超の記事は目次と「いま読む節」の印を付ける（メルカリエンジニアリング：高さ 15,659px、ProPublica：高さ 21,446px、どちらも目次無し）。
2. 画像の width/height が抜けると、記事の途中で寸法が決まらず、元画像を引き伸ばしたり本文を押し下げたりする。全画像に寸法を付ける（メルカリエンジニアリング：アイキャッチ無しで PC CLS 0.064、ProPublica：長い記事の写真が 1200px を 1440px に拡大）。
