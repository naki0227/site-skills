35. SP で画面に固定する帯（アプリの誘い・広告・タブ）は、合わせて画面の1割までにする。レシピを台所で読む画面を、固定の帯が2割〜3割ふさぐサイトが続いた（白ごはん.com：固定の広告と下のタブで画面の下 20%、Great British Chefs：ヘッダーと下の広告 110px で 22%、Nadia：上のアプリの誘い 54px・下のアプリ 40px・下の広告 116px で 390×664 の 32%。2026-11-19）。固定は1本にし、閉じるボタンを付け、閉じたことを覚える。

36. PC 用と SP 用で別の図を出すなら picture と media で片方だけ読む。2枚の img を display:none で出し分けると、隠した側も読むサイトが続いた（Quanta Magazine：PC 用と SP 用の SVG を両方で 1,207KB、dancyu：is-pc／is-sp の写真を両方読みトップの JPEG 20,054KB）。2枚の img にするなら両方を loading="lazy" に：Linear Now は SP 用に縦に切り直した図（2352×2720 など）を .show-mobile に入れ、lazy の4枚は PC で読まれなかったが、eager の1枚目（2352×1280）は PC でも読まれた（2026-11-20）。

37. ダーク／ライトを切り替えるなら、ロゴと本文の図もテーマに合わせて替えるか、どちらの地でも読める形にする。地だけ替わり、絵が前のテーマのまま残るサイトが続いた（YAMAP MAGAZINE：ダークで黒いロゴが残り 1.20:1、Linear Now：ライトにしても本文の図が暗い PNG のままで、白い地に黒い板が並ぶ。2026-11-20）。
38. og:image は公開後に URL を開いて、200 で返る・1200×630 前後の JPEG か PNG であることを確かめる。テーマや置き場所を変えたあとに古い道や読めない形式のまま残るサイトが続いた（Ottolenghi：http の .heic・2962×3950・1,695KB、CyberAgent Developers Blog：子テーマの名前を onepress-child-20220324 に変えたあとも …/onepress-child/…/og.png を指して 404。twitter:image は記事の絵で、2つが食い違う。2026-11-21）。
39. 図は本文の列より広げてよい。広げるのは図・写真・コードの箱だけにし、キャプションと本文は列に戻す。広げても本文の列は 584〜704px に保つ（Canary Media：本文 584px・図は左右 -240px で 1064px、Linear Now：本文 624px・図だけ 976px でキャプションは列へ、The Fly Blog：本文 704px・コードと囲みは +32px・絵は +64px。2026-11-22）。図の埋め込みは高さを先に取る（横断ルール2）。 Josh W. 40. 手順が8を超える記事は、いまの手順を示す印を PC と SP の両方に置く。長い手順でも目次も印も無いか、PC だけのサイトが続いた（King Arthur Baking：手順17・10,852px で無し、Great British Chefs：手順18・SP 15,224px で無し、dancyu：無し、キャンプ飯：PC だけ左に縦の点・SP は display:none）。
41. 一覧は最初の 12〜24本だけ配り、続きは URL のあるページ送りで読む。全件を1ページに書いて写真も全部読むサイトが続いた（白ごはん.com：831件・PC 52,092px・15.41MB、キャンプ飯：278本のカードと写真をトップに全部・89.48MB、「もっと見る」は隠したものを出すだけ、The Fly Blog：213本を1ページ）。 Josh W. Comeau でも：分類 CSS の31本を1ページ・ページ送り無し（2026-11-26）。
42. アイコンの書体・ライブラリは、使うアイコンだけを SVG で持つ。ページで1つも使っていないアイコンのライブラリを全ページで読むサイトが続いた（SmartHR Tech Blog：Font Awesome 665KB・使用0、キャンプ飯：Font Awesome Pro の all.min.js 4,990KB・使用0・gzip 無し）。
43. 本文の列は、1行が英語 65〜75字・日本語 38〜45字に収まる幅にする。広い画面に合わせて列を広げ、1行が長くなるサイトが続いた（Google Design：1100px・18px で約135字、SmartHR Tech Blog：930px・18px、DeNA Engineering：870px・17px、東洋経済オンライン：870px・18px、dancyu：1000px・15px で約66字）。守れている見本は Canary Media（584px）・Linear Now（624px）・The Markup（620px）。
44. 記事の公開日は画面のどこかに必ず出す。日付が記事のどこにも無いか、HTML では空のサイトが続いた（Google Design：画面・HTML・JSON-LD とも 0、LINEヤフー Tech Blog：日付が HTML で空、ほぼ日：頭に無く終わりに英字の曜日つきだけ）。
