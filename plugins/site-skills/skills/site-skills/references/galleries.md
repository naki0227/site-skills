# 手本を探す場所（事例集・ギャラリー）

出典：yamayuki_design の Instagram リール「目的別 Webデザイン参考サイト9選」「ポートフォリオ特化 参考サイト8選」（ユーザーが画面録画で共有、2026-11-01）。どれを何に使うかを、ここでの使い方（解剖する手本を選ぶ・作る前に見本を集める）に書き直した。

| 探したいもの | 場所 |
|---|---|
| 国内の作り込まれたサイトを、業種やテイストで | SANKOU!、S5 Style、81-web、MUUUUU.ORG（コーポレート中心） |
| 国内外の質の高いサイトを幅広く | I/O 3000、Web Design Clip（国内・海外・LP・レスポンシブなど条件で絞れる） |
| スマホ・タブレット・PC での見え方の違い | Responsive Web Design JP（同じサイトの3つの幅を並べて見られる） |
| なぜ良いのか（見るところ・使える場面・直すところ）の解説つき | マネるデザイン研究所 |
| 実装まで含めた作り込み | STUDIO Showcase、Framer Community Gallery |
| Web 以外（広告・ポスター・雑誌・パッケージ）の世界観 | Pinterest、Dribbble |

使い方（同じリールの考え方）：「なんとなく眺める」のでなく、**何を参考にするかを先に決めて**見る（構成か、配色か、文字か、動きか）。見る量を増やし、「この見せ方がいい」「この構成がわかりやすい」を集めてから作る。

- 解剖の手本を選ぶときは、ここに載っているサイトを優先する（各 anatomy リポジトリの DAILY.md 手順1「事例集に載っている」）。
- 作るときは、見本を3〜5つ集めて、何を真似るか（値）を1行ずつ書いてから始める。
- 同じリールで紹介されていた無料イラスト素材のサイトは載せていない。SVG の平たいイラストを主役にすると AI っぽく見えた（`ai-tells.md`）ことと、素材ごとに利用規約が違い、public のリポジトリに入れられるとは限らないため。
