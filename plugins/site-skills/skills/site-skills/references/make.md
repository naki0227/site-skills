# 作る前に決めること（詳しく）

出典：[Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)（MIT）の「the run」1〜5（247サイトの調査と、目隠しの比較テスト）を、site-skills の使用例5つ（examples/、2026-10-26）で確かめた形に書き直したもの。

## 1. 題材の棚卸し（8〜12個）
この題材にしかなく、競合には無い物を書き出す。考えはここからしか出てこない。
- **名前**とその意味・由来（屋号、地名、創業者の名）
- **場所**：住所、通り、近所、その場所の見た目（看板の文字、タイル、壁の色、光、天気）
- **数字**：席数、部屋数、定員、値段、創業年、駅からの分数
- **制約**：月に1回だけ焼く、冬は休み、予約のみ、定員6名
- **素材と色**：のれんの藍、鋳物の黒、クラフト紙、作業着の紺
- **決まった時刻と手順**：5時に窯に火を入れる、7時の始発、下校時刻
- **その世界の紙もの**：時刻表、値札、伝票、のぼり、記録票、連絡帳、黒板

taste-skill の目隠しテストでは、どの題でも、勝ったページはこの一覧の1つ（名前と意味、通り、題材を題材たらしめる制約）から作られていた。負けたページは、構図は良くても「業種の定番の考え」だった。site-skills の使用例でも、AIっぽさが消えたのは、のぼり・焙煎予定の黒板・下足札・検査記録票のような**現場の紙と道具を部品にした**ときだった（`ai-tells.md` の「代わりに何をするか」）。

## 2. 考えの一文と、競合テスト
> このページでは **〔棚卸しの1つ〕** が **〔部品〕** になる。

- 例（使用例から）：「このページでは、学童のホワイトボードの出欠表が、最初の画面の触れるボードになる」「このページでは、銭湯の下足札が、時間を選ぶ部品になる」
- **競合テスト**：いちばん近い実在の競合（2本先の通りのパン屋、別の山の山小屋）の名前を入れても文が成り立つなら、その考えは業種のもの。考え直す。「清潔でモダン」は考えではない。
- 一文の前半を探す場所：その題材が**作る物**（作った物そのものを画面の素材にする）、**形**（断面・輪郭を拡大して枠にする）、**名前**（文字に写真を入れる、2つに割る）、**場所**（行きたくなる1つの眺め）、**手順**（スクロールで順に演じる）、**紙もの**（チケット・メニュー・ラベル・伝票）。

## 3. 主張と証拠の列
デザインの前に、ページを「1章＝1主張＋証拠」の行で書く。主張の無い章は消す。これで「ヒーロー→ロゴ→特徴3つ→声→料金→ボタン」の定番の順から抜けられる。
```
1. 下校から20分来ない子が、すぐ分かる。         → 触れる出欠表（時刻を進めると赤くなる）
2. 連絡帳の返事が、ボードに出る。             → 保護者の返事が並ぶ連絡帳
3. 月額は登録児童数で決まる（40人まで 8,800円）。→ 料金の表、ボタン
```
- 証拠は作らない：実在しない顧客の声・導入社数・評価の星・報道ロゴは書かない。証拠が無いときは、物そのもの・仕組み・題材の事実（値段・場所・年・含まれるもの）で示す。
- 見本の細部（部屋の名前と料金、料理の名前と値段）は書いてよい。むしろ全部書く（1つだけだと未完成に見える）。どれが見本かは報告に書く。

## 4. 触れる1つ
題材の本物の中身で動く部品を1つ。taste-skill の目隠しテストでは、勝ったページには全部これがあり、審査は最初にそれを挙げた。
- 題材の本当の中身を使う／スマホで親指で使える／スクリプトが無くても読める／読むのを邪魔しない／1つだけ（遊び場にしない）
- 例：時刻を進めると出欠表が変わる（学童）、男女と人数を選ぶと空きの木札が変わる（銭湯）、容量と挽き方で値段と着日が変わる（焙煎所）

## 5. 見出しと最初の画面
- 最初の画面は、相手の最初の問いに大きな文字で答える：催しなら何が・いつ・どこで（日付は見出しか2番目の大きさに。小さい字だけにしない）、製品なら何で何をするか、店なら何の店でどこにあるか。
- 見出しの下に、それが何かを平たく言う1文を置き、最初の画面に本物のボタンを1つ置く。
- 見出しは題であって文ではない。日本語では PC で2行、スマホで3行までを目安にし、それを超えたら言葉を削る（`scripts/inspect.js` が数える）。

## 6. 写真
出典：ユーザーの見比べ（2026-10-26、実在の写真＋出典を選んだ）と、taste-skill の imagery の順。
1. 題材そのものの写真（依頼主が持っているもの）
2. 題材の「まわりの世界」の本物の写真：`node scripts/photos.js search "<英語の検索語>"` で Wikimedia Commons の自由に使える写真を探し、`get <番号> <フォルダ>` で取る（出典は credits.json に残る）。題材の一覧（棚卸し）の、場所・素材・道具・紙ものを検索語にする（例：noborigama、sento bathhouse、lathe、kraft paper coffee bag）。見つけた写真は大きく使う（最初の画面の主役、章の全幅の帯）。
3. 題材の情報そのもの（図・表・地図）
4. 題材の色の面と大きな文字
- 写真は題材の物として見せず、何が写っているかと出典を画面に書く。生成した写真は使わない。
