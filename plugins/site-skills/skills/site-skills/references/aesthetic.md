# 美的感覚：色と比率と重ね方

出典：yamayuki_design の Instagram リール（配色パレット2本・比率と原理・定番デザインスタイル20選。ユーザーが画面録画で共有、2026-11-01）から読み取った原則を、ユーザーの見比べ（同じ日、架空の陶器市の同じ中身で5組）で確かめたもの。5組ともユーザーは同じ側を選んだ（下の表）。文章と値は書き直しで、作者の画像・パレットそのものは入れていない。

| 見比べ | きれいと選ばれた側 | 選ばれなかった側 |
|---|---|---|
| 色の量 | 3色（地の白・主の緑・差し色の朱）を、ほぼ同じ量の大きな面で | 70:25:5（地が7割、差し色はボタンだけ） |
| 写真の色 | 写真をモノクロにし、主の色の面と差し色だけを足す | 写真をそのままの色で使い、文字に別の色を足す |
| 差し色 | 題の一語・日付・大事な語など、何か所にも同じ差し色 | 差し色はボタン1か所だけ |
| 分け方 | 文字と写真を 1:1.618（黄金比）で | 1:1（半分ずつ） |
| 題と写真 | 題を写真の上に、画面いっぱいの大きさで重ねる | 題を写真の横に、ふつうの大きさで |

## どちらを主にするか（X と Y の比較）
同じ題材（架空の窯元「三ツ谷窯」）・同じ原稿・同じ写真で2案を作り、ユーザーが X を選んだ（2026-11-01）。
- X：この美的感覚を主にし、種類ごとのスキルの実測の値は支えに（地の灰白・主の炎の朱・差し色の灰釉の青緑。写真は全部モノクロに朱を重ねた2色刷りの調子。題は写真の上に画面いっぱい。どの章も 1:1.618）。
- Y：lp-quality-bar の和・上質（とらやの実測値：白・#111・#ccc・赤は目印だけ・ピルのボタン）を主にし、この美的感覚は取り入れる側に。
→ **作るとき、色・比率・題の置き方はこの美的感覚で決める。** 種類ごとのスキルは、構成・流れ（一覧→詳細、予約の手順など）・文字の段・状態・重さの値の支えに使う。解剖のノートで本家を写す再現デモだけは、本家の値のまま。

## 決まり
1. **色相は3つまで、量は大胆に。** 地・主・差し色の3色に決めたら、ほかの色相を足さない。そのかわり、主の色は画面の1/3以上の大きな面で使い、差し色も題の一語・日付・値段など何か所に使ってよい。控えめに少しだけ置くと、物足りなく見えた（70:25:5 は選ばれなかった）。
   - `ai-tells.md` の「色相のばらばらな小さなラベルを散らす」（AIっぽいと選ばれた）とは別物：あちらは色相が増えること、こちらは同じ色を大きく繰り返すこと。
   - 3色の組み方の例（リールのパレットの型）：濃い地（オフブラック・深い紺）か淡い地（グレージュ・ピーチベージュ・オフホワイト）に、鮮やかな主の色1つ、その反対側の鮮やかな差し色1つ（マゼンタとライム、青と橙、紺と朱、黄と青と赤紫など）。色相環で向かい合う2色か、三角に離れた3色にすると、色どうしがぶつからない。
2. **写真はモノクロにして、色を足す（ポスター・告知の型）。** 写真の色を活かそうとせず、まずモノクロにし、主の色の面と差し色を上に重ねる。**店・会社・宿のサイトには当てない**（下の「本物か作例か」：この型で作った作例は4つとも見抜かれた）。
3. **分け方は黄金比。** 文字と写真、本文と余白などの大きな分け方を 1:1.618 にする。半分ずつにしない。紙の比（白銀比 1:1.414）、三分割、横長の 2.39:1、正方形 1:1 も、題材に合えば使う。どれか1つに決めて通す。
4. **題は写真に重ねて大きく（ポスター・告知・夜の催しの型）。** 最初の画面の題を、写真の上に画面の幅いっぱいの大きさで置き、写真を暗くする。**店・会社・宿のサイトでは、明るい地に写真を余白で囲んで置き、題は写真の外に濃い色で置く**（下の「本物か作例か」）。
5. **スタイルは1つ選んで通す。** グラスモーフィズム・ハーフトーン・デ・ステイル・わびさび・Bento Grid・Y2K など、定番のスタイルから使うなら1つだけ選び、全部の章で同じ扱いにする。混ぜない。

## 印象と、配色と、構図

**読み上げの型：2色で土台の印象を決め、3色目の差し色で印象を動かす。** 落ち着いた2色に鮮やかな差し色を1つ足すと、「ポップ」「親しみ」「活気」「エネルギッシュ」の側へ動く。差し色は飾りではなく、印象を決める役目を持つ。

**この表は「正解」ではなく「選択肢」。** ユーザーの言葉（2026-11-01）：「これは全部良くて、その紹介する特色によって変わる」「どっちにも選んでないやつも全然使える。会社によるかも」。同じ日の見比べ（6つの雰囲気×3つの配色）でも、AI っぽいと選ばれた配色は1つも無く、選ばれたのは雰囲気によって、動画の法則どおりの配色（採用・IT）、色相の近い暖色3つ（学園祭の黄・橙・赤）、AI がよく選ぶとされる配色（カフェのクリーム＋テラコッタ、ファッションのベージュ＋黒＋金、コスメのパステル）とばらばらだった。
- **色そのものが AI っぽいのではない。題材の特色を見ずに、いつも同じ色を選ぶのが AI っぽい。** 静かで自然派のカフェならクリーム＋テラコッタ、上質で静かなファッションならベージュ＋黒＋金、やわらかい雑貨ならパステル、にぎやかな学園祭なら近い暖色の3つ、が合うことがある。
- だから、配色と構図は、**題材の特色を1行で言ってから**選ぶ（例：「年に2回だけ焚く登り窯の、炎の色」→ 朱を主に）。その1行と、選んだ配色・構図の理由をコードの先頭のコメントに書く。理由が「この業種ではよくあるから」なら選び直す。

使い方：題材の特色を1行で書き、それに合う印象を上の言葉から1つ決め、その行の型（2色の土台＋差し色、構図）を出発点にする。合わなければ、別の行の型や表に無い組み合わせを使ってよい。値はそのまま写さず、題材の色（`ai-tells.md` の「現場の色」）に寄せて置き換える。どの行でも共通なのは、**大きな文字か大きな写真の、どちらか1つが画面の主役**であること。中央に小さな題とボタンを並べる型は使わない。
- 不定形の塗り（ぐにゃっとした形）・吹き出し・手書きの文字・ステッカーを組み合わせる構図は、合うはずの「軽やか・エネルギッシュ」でも選ばれなかった。使うなら1つだけにする。

## 業種の手本を先に測る（ORBITO の試作への指摘、2026-11-01）

- **作る前に、その業種の手本を事例集から5〜10件選び、`node scripts/sample.js <URL…>` で地・文字・差し色・書体と太さ・ボタン・罫の数を測ってから、3色と書体を決める。** 決まり1（鮮やかな主の色を大きな面で）は、ポスター・告知・ポップな LP の型。手本の業種が使っていなければ使わない。
- 色は「題材そのもの」（服・料理・建物の写真）に持たせ、画面の地と文字は色の入った無彩色に寄せる業種がある（ファッションはそう）。
- 書体は雰囲気で替える。ORBITO 第3版では COOL＝Archivo＋Zen Kaku Gothic New、CUTE＝Cormorant Garamond の斜体＋Zen Old Mincho（手本の Univers・DIN／Sabon・游明朝の代わりの Google Fonts）。
- **定番の書体でもよい。AI っぽくなければ（ユーザーの許可 2026-11-02）。** 前の決まり「標準・定番の書体は使わない」（2026-11-01）は、下のファッション80件の実測と食い違ったので改めた：和文の本文は Web フォント42件・端末の標準16件で、Web フォントでいちばん多いのは Noto Sans JP（セレクト・カジュアル 28件中8件）。和文の見出しも本文と同じ書体か明朝（Shippori Mincho・游明朝）を太さ 400 で組み、Dela Gothic One・Yusei Magic のような癖の強い書体は80件で0件だった。書体は「手本の業種で実際に使われているか」で選ぶ。`scripts/inspect.js` の default-font は、Web フォントを指定せず端末の標準で描かれたときだけ WARN にする。
  - 雰囲気から選ぶ。ORBITO では COOL＝Syne（英字）＋Murecho（和文）、CUTE＝Cormorant Garamond 斜体（英字）＋Kaisei Decol（見出し）＋Zen Maru Gothic（本文）にし、本文の書体ごと切り替えた。
  - **書体の癖は、大きな字でしか見えない。** Zen Kaku Gothic New → Murecho に替えても、見出しが 26px のままでは「変わらん」と言われた。和文のゴシック体どうしは 15〜26px ではほぼ同じに見える。書体を選んだら、最初の画面の題を 40px 以上（PC で 40〜60px）にし、その下の1〜2行の文も同じ書体で組んで、癖を見せる。長い本文は読みやすさを優先して別の書体でよい。
  - 見比べ（2026-11-01、見出し最大 52px・本文も同じ書体、ORBITO の色）：COOL は Murecho・Dela Gothic One・DotGothic16・Reggae One・Zen Antique から、最初は **Murecho**、大きく組んだ ORBITO を見たあと **Dela Gothic One**（極太で角ばったゴシック体）に替えた。CUTE は Kaisei Decol・Hachi Maru Pop・Yusei Magic・Mochiy Pop One・Zen Kurenaido から **Yusei Magic**（マーカーで書いたような字）。反応は「うーん」で、決め手のある書体ではまだ無いかもしれない。大きく組んで初めて、書体の違いを比べられた（大きくしてから選び直した）。
  - **書体を選んだら、商品の部品から形を取って題を作り込む。** COOL の書体は見比べで「一番ましだけど納得いかない」と言われ、不満は「字の形そのもの」と「ロゴのように作り込んでいない」だった。字の形の候補を広げると Train One と LINE Seed JP（LINE、OFL。Google Fonts 以外は使う字だけ `fontTools.subset` で埋め込む）が好まれ、「デザイン性をもっとプロダクトの性質に合わせるなら良い」と言われた。宇宙服の部品（反射テープ・パイピング・名札・命綱・洗濯表示のタグ）から5つ作り、**命綱**（字の下を1本の綱が通り、端にカラビナ。綱は服の橙）が選ばれた（2026-11-01）。
    - 作り方：字の輪郭を書体から取り出し（`fontTools` の SVGPathPen）、SVG の題にして部品の形を足す。題の文字は画面読み上げ用に h1 の中に残す。
    - CUTE も同じ考え方で、かわいい側の部品（ステッカー・ワッペン・リボンの命綱・刺繍）から4つ作り、**リボンの命綱**（COOL の命綱の綱がピンクのリボンになり、端が蝶結び）が選ばれた。COOL と CUTE で**同じ部品を、気分ごとに素材だけ替える**と、切り替えたときに同じ店に見える。章の題（New in・Fitting・Store）にも同じ綱・リボンを通した。
    - 題と、その下の文の書体はそろえる（題を LINE Seed JP、下の文を Dela Gothic One にしたら、太字が2種類ぶつかった）。
  - 手本のサイトの書体（Univers・DIN・Sabon など）が有料なら、形の近い Google Fonts から、定番の一覧に入らないものを選ぶ。
- ファッションの本文は 12〜15px が多かった（DROP TOKYO・DEADLY PONIES 12px、kolor 14px）。ここは真似ず、本文 16px の決まり（`ai-tells.md`）を残した。

## 本物か作例か（ユーザーに当ててもらった結果）
### 第1回（2026-11-05）
今日の作例4つ（昆布の食品・シャツ・会社・宿）と、Web Design Clip の同じ業種の実在のサイト4つ（kofukuzen.jp・maisontakuya.jp・takumi-tateyama.co.jp・kagari-kisshotei.com）の最初の画面を、ヘッダーと出典を隠して並べた。ユーザーは**4つとも作例と見抜いた**。決め手：「写真と文字の雰囲気と、枠の作り方とか、色の使い方」。
| | 作例4つ | 実在4つ |
|---|---|---|
| 最初の画面の明るさ（0〜255、画素の平均） | 68〜84 | 151〜214 |
| 白っぽい部分（平均 200 以上の画素） | 2〜6% | 28〜74% |
| 暗い部分（平均 60 未満） | 29〜60% | 0〜27% |
| 写真の置き方 | 4つとも画面いっぱいの四角い写真を暗く沈め、その上に白い題 | 明るい地に、写真を余白で囲んで置く。丸・不定形の切り抜き・複数の写真の組み合わせ・縦書きの題 |
| 色 | 画面全体が1色の暗い色（紺・灰）に寄る | 地は白か生成り。色は写真そのもの（大豆・緑・赤い椅子）と少しの差し色の文字 |
- 原因：この表の上の決まり2（モノクロの写真に色を重ねる）と4（題を暗くした写真に重ねる）。どちらもポスター・告知（yamayuki_design のリール）の型で、店・会社・宿のサイトの型ではなかった。見比べ第3回で「暗い写真の全面」が選ばれたのは、比べた相手（写真が上・文字が下のカード）も実在から外れていたため。
- **店・会社・宿のサイトの最初の画面は明るくする**：明るい地（白・生成り）に、色のある写真（商品・人・場所）を余白で囲んで置き、文字は写真の外に濃い色で。枠は四角だけにせず、手本の業種の切り抜き方（丸・不定形・複数の写真）を測ってから選ぶ。`scripts/inspect.js` の dark-first が、最初の画面の明るさ 110 未満かつ白っぽい部分 15% 未満を WARN にする。
- 暗い全面の写真は、題材に理由があるとき（夜の催し・映画・ゲーム・ポスターそのもの）だけ。
### 第2回（2026-11-06）
第1回を受けて明るく作り直した site-skills の使用例5つ（陶器市・焙煎所・学童アプリ・銭湯・町工場の採用）と、同じ業種の実在5つ（plantsandcrafts.dougukan.jp・jorganic-coffee.jp・tetetoco.jp・ichinobo.com/sakunami・dorokogyo.co.jp/recruitment）を並べた。ユーザーは**また5つとも見抜いた**。決め手：「文字の大きさとか、デザイン性のある枠とか、並べ方とか」。明るさの差は消えた（作例 182〜232）が、次の差が残った。
| | 作例5つ | 実在5つ |
|---|---|---|
| 何も無い面（16px 角の区切りで濃淡がほぼ無い所） | 47〜72%（中央値 49%） | 28〜54%（中央値 31%） |
| 最初の画面の写真・絵・製品の画面（150×100 以上） | 1〜2個 | 1〜9個（中央値 4個） |
| 最初の画面の文字 | 190〜436字 | 23〜250字（中央値 161字） |
| 題 | ふつうの文字を 40〜80px | 作り込んだ題：142px のロゴのような英字（DORO KOGYO RECRUIT）、文字を絵にした題（植物×匠）、大きく太い題（子どもの発達の話を…） |
| 枠と並べ方 | 左に文字・右に写真の2列、四角か角丸の写真1〜2枚と丸1つ、余白が広い | 不定形の切り抜き・人物の絵・アプリの画面・色の面を重ねて層を作る。要素が重なり、はみ出す |
- **最初の画面は、層を作る**：写真・切り抜き・絵・製品の画面・色の面を3つ以上、大きさを変えて重ねる。左に文字・右に写真の行儀のよい2列で、余白を広く空けない。`scripts/inspect.js` の sparse-first が、何も無い面 45% 超かつ写真や絵 2個以下を WARN にする。
- **題を作り込む**：ふつうの文字を大きく置くだけにしない。手本の業種の題の作り方（ロゴのような英字・文字の絵・太く大きな題）を見て、題材の部品から作り込む（上の「商品の部品から題を作り込む」）。
- **最初の画面の字を減らす**：手本の中央値（今回 161字）を目安に、説明は下の章へ。
- 第1回の「明るくする」は効いたが、それだけでは見分けられた。1つ直すと次の差が見える。
- 宿・温浴は、実在でも暗い全面の写真がふつう（演出を除いた8件の明るさの中央値 118）。ただし写真の上にはロゴしか置かない。dark-first はその業種では理由を1文で書いて残してよい。
### 第3回（2026-11-06）
層と題を作り込んだ使用例5つと、前回と別の実在5つ（mamafes.net・tabisurukissa.com・hacomono.jp・kajimanomori.co.jp・livedo.jp/high_school-recruit）を並べた。ユーザーの答え：「全部わかるけど、明らかに AI っぽいものだけ選んだ」→ 銭湯・町工場・陶器市の3つ。学童アプリと焙煎所は選ばれなかった（初めて差がついた）。決め手：「文字の後ろの色とか背景色、文字と写真以外の要素（イラストとか）が無いのが AI」。
| | 選ばれた3つ（明らかに AI） | 選ばれなかった2つ |
|---|---|---|
| 写真と文字以外の要素 | 無し（銭湯ののれん・陶器市ののぼりは題そのもの） | 学童：名前マグネットの札・アプリの画面・手書きのメモの切れはし／焙煎所：手描きのコーヒー袋の絵・回る英字の刻印 |
| 題と文の後ろ | 生成りの無地 | 黄色の面・クラフト紙の色の面 |
- **写真と文字だけで最初の画面を作らない**：題材から取った絵（手の跡のある線）・札・手書きのメモ・スタンプ・製品の画面のどれかを、写真と重ねる。実在でも mamafes の線の人物と吹き出し、livedo のキャラクターと工場の絵、hacomono の製品の画面がある。`scripts/inspect.js` の photo-text-only が、最初の画面に SVG・canvas・透過画像（48px 以上）が1つも無いと WARN にする（この回の5つで、ユーザーの選んだ3つとちょうど一致した）。
- **題と文の後ろに色を置く**：生成りの無地の上に置かず、題材の色の面・帯・札の上に置く。
- 「全部わかる」ので、まだ見分けはつく。明らかさが下がった2つ（学童・焙煎所）を次の基準にする。

## 当てる順番
