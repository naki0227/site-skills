# 美的感覚：色と比率と重ね方

出典：yamayuki_design の Instagram リール（配色パレット2本・比率と原理・定番デザインスタイル20選。ユーザーが画面録画で共有、2026-11-01）から読み取った原則を、ユーザーの見比べ（同じ日、架空の陶器市の同じ中身で5組）で確かめたもの。5組ともユーザーは同じ側を選んだ（下の表）。文章と値は書き直しで、作者の画像・パレットそのものは入れていない。

| 見比べ | きれいと選ばれた側 | 選ばれなかった側 |
|---|---|---|
| 色の量 | 3色（地の白・主の緑・差し色の朱）を、ほぼ同じ量の大きな面で | 70:25:5（地が7割、差し色はボタンだけ） |
| 写真の色 | 写真をモノクロにし、主の色の面と差し色だけを足す | 写真をそのままの色で使い、文字に別の色を足す |
| 差し色 | 題の一語・日付・大事な語など、何か所にも同じ差し色 | 差し色はボタン1か所だけ |
| 分け方 | 文字と写真を 1:1.618（黄金比）で | 1:1（半分ずつ） |
| 題と写真 | 題を写真の上に、画面いっぱいの大きさで重ねる | 題を写真の横に、ふつうの大きさで |

## どちらを主にするか（X と Y の比較）
同じ題材（架空の窯元「三ツ谷窯」）・同じ原稿・同じ写真で2案を作り、ユーザーが X を選んだ（2026-11-01）。
- X：この美的感覚を主にし、種類ごとのスキルの実測の値は支えに（地の灰白・主の炎の朱・差し色の灰釉の青緑。写真は全部モノクロに朱を重ねた2色刷りの調子。題は写真の上に画面いっぱい。どの章も 1:1.618）。
- Y：lp-quality-bar の和・上質（とらやの実測値：白・#111・#ccc・赤は目印だけ・ピルのボタン）を主にし、この美的感覚は取り入れる側に。
→ **作るとき、色・比率・題の置き方はこの美的感覚で決める。** 種類ごとのスキルは、構成・流れ（一覧→詳細、予約の手順など）・文字の段・状態・重さの値の支えに使う。解剖のノートで本家を写す再現デモだけは、本家の値のまま。

## 決まり
1. **色相は3つまで、量は大胆に。** 地・主・差し色の3色に決めたら、ほかの色相を足さない。そのかわり、主の色は画面の1/3以上の大きな面で使い、差し色も題の一語・日付・値段など何か所に使ってよい。控えめに少しだけ置くと、物足りなく見えた（70:25:5 は選ばれなかった）。
   - `ai-tells.md` の「色相のばらばらな小さなラベルを散らす」（AIっぽいと選ばれた）とは別物：あちらは色相が増えること、こちらは同じ色を大きく繰り返すこと。
   - 3色の組み方の例（リールのパレットの型）：濃い地（オフブラック・深い紺）か淡い地（グレージュ・ピーチベージュ・オフホワイト）に、鮮やかな主の色1つ、その反対側の鮮やかな差し色1つ（マゼンタとライム、青と橙、紺と朱、黄と青と赤紫など）。色相環で向かい合う2色か、三角に離れた3色にすると、色どうしがぶつからない。
2. **写真はモノクロにして、色を足す。** 写真の色を活かそうとせず、まずモノクロにし、主の色の面と差し色を上に重ねる。写真の色とページの色が喧嘩しない。自由に使える実写（`scripts/photos.js`）とも相性が良い（写真の元の色に左右されない）。
3. **分け方は黄金比。** 文字と写真、本文と余白などの大きな分け方を 1:1.618 にする。半分ずつにしない。紙の比（白銀比 1:1.414）、三分割、横長の 2.39:1、正方形 1:1 も、題材に合えば使う。どれか1つに決めて通す。
4. **題は写真に重ねて大きく。** 最初の画面の題（または名前の一語）を、写真の上に画面の幅いっぱいの大きさで置く。読ませるため、写真を少し暗くする（暗幕 15〜25%）か、モノクロにする。日付・場所・ボタンは、題と離して隅に置く。
5. **スタイルは1つ選んで通す。** グラスモーフィズム・ハーフトーン・デ・ステイル・わびさび・Bento Grid・Y2K など、定番のスタイルから使うなら1つだけ選び、全部の章で同じ扱いにする。混ぜない。

## 印象と、配色と、構図
出典：yamayuki_design の配色のリール（パレットごとに読み上げられた「印象」と、パレットを使った作例の構図。ユーザーが画面録画で共有、2026-11-01。音声は文字に起こして確かめた）。構図は、ユーザーの見比べ（同じ配色で構図だけを3つ変えた6組）で、6組中5組がその作例の構図を選んだ。AI がよく作る型（中央の題・NEW のラベル・ボタン2つ・写真のカード）は6組とも AI っぽいと選ばれた。

**読み上げの型：2色で土台の印象を決め、3色目の差し色で印象を動かす。** 落ち着いた2色に鮮やかな差し色を1つ足すと、「ポップ」「親しみ」「活気」「エネルギッシュ」の側へ動く。差し色は飾りではなく、印象を決める役目を持つ。

| 印象（読み上げ） | 地・主（2色の土台） | ＋差し色で | 構図（作例の型） | 見比べ |
|---|---|---|---|---|
| クールでエッジ → ポップで遊び心 | オフブラック＋ビビッドマゼンタ | ライムグリーン | モノクロの写真を全面に、主の色の球を浮かべ、差し色の巨大な欧文ロゴを写真に重ねる | ✓ 選ばれた |
| 爽やかで知的 → 親しみやすさと活気 | グレージュ＋ロイヤルブルー | ビビッドオレンジ | 明るい地、左に太いゴシックの2行のコピー、右に写真、後ろを主と差し色のリボンが流れる（Web のヒーロー） | ✓ |
| 華やかでフェミニン → ポップで個性的 | コーラルピンク＋クリムゾンレッド | オリーブライム | 地いっぱいに画面からはみ出す巨大なセリフ文字を主の色で敷き、その前に写真 | ✓ |
| 爽やかで軽やか → エネルギッシュでポップ | ライムグリーン＋ラベンダーパープル | ビビッドレッド | 作例は「白地に不定形の塗り・吹き出しのロゴ・手書き・ステッカー・傾けた写真」だが、ユーザーは**写真全面＋巨大なロゴ**の構図を選んだ | ✗ 作例の構図は選ばれなかった |
| レトロモダン | ピーチベージュ＋ディープブルー | バーミリオン | 巨大なレトロ書体（太いセリフ）を上に、平らな幾何学の絵（アーチ・丸・半円）、日付は小さく隅 | ✓ |
| シティポップ | レモンイエロー＋コバルトブルー | ラズベリーピンク | （作例：黄色の地に縦長の大きな書体と筆記体、イラストの人物、縦書きのコピー。見比べはまだ） | — |
| ガーリー | ローズピンク＋クリムゾンレッド | スカイブルー | （作例：ピンクの地に白い装飾的な書体、きらめき、リボン、写真のコラージュ、縦書き。見比べはまだ） | — |
| レトロポップ | ポピーレッド＋サンシャインイエロー | ペールアクア | 黄色の地に主の色の太い文字の塊、差し色の四角のブロック、日付を大きく、写真は隅 | ✓ |
| テックポップ | オフホワイト＋ロイヤルブルー | ライムグリーン | （作例：白地に青の大きな文字、イラストの人物、ライムの差し色。見比べはまだ） | — |

**この表は「正解」ではなく「選択肢」。** ユーザーの言葉（2026-11-01）：「これは全部良くて、その紹介する特色によって変わる」「どっちにも選んでないやつも全然使える。会社によるかも」。同じ日の見比べ（6つの雰囲気×3つの配色）でも、AI っぽいと選ばれた配色は1つも無く、選ばれたのは雰囲気によって、動画の法則どおりの配色（採用・IT）、色相の近い暖色3つ（学園祭の黄・橙・赤）、AI がよく選ぶとされる配色（カフェのクリーム＋テラコッタ、ファッションのベージュ＋黒＋金、コスメのパステル）とばらばらだった。
- **色そのものが AI っぽいのではない。題材の特色を見ずに、いつも同じ色を選ぶのが AI っぽい。** 静かで自然派のカフェならクリーム＋テラコッタ、上質で静かなファッションならベージュ＋黒＋金、やわらかい雑貨ならパステル、にぎやかな学園祭なら近い暖色の3つ、が合うことがある。
- だから、配色と構図は、**題材の特色を1行で言ってから**選ぶ（例：「年に2回だけ焚く登り窯の、炎の色」→ 朱を主に）。その1行と、選んだ配色・構図の理由をコードの先頭のコメントに書く。理由が「この業種ではよくあるから」なら選び直す。

使い方：題材の特色を1行で書き、それに合う印象を上の言葉から1つ決め、その行の型（2色の土台＋差し色、構図）を出発点にする。合わなければ、別の行の型や表に無い組み合わせを使ってよい。値はそのまま写さず、題材の色（`ai-tells.md` の「現場の色」）に寄せて置き換える。どの行でも共通なのは、**大きな文字か大きな写真の、どちらか1つが画面の主役**であること。中央に小さな題とボタンを並べる型は使わない。
- 不定形の塗り（ぐにゃっとした形）・吹き出し・手書きの文字・ステッカーを組み合わせる構図は、合うはずの「軽やか・エネルギッシュ」でも選ばれなかった。使うなら1つだけにする。

## 業種の手本を先に測る（ORBITO の試作への指摘、2026-11-01）
上の決まり1〜4は、yamayuki_design のリール（ポスター・告知の作例）から来ている。ユーザーの指摘「原色や白黒のそのままの色はあまり使わない」「情報の密度・ボタン・章の区切りがこんなにはっきりしているほうが珍しい」「雰囲気ごとによく使う書体があるはず」「教えた参考サイトを活かせていない」を受けて、`galleries.md` の事例集（MUUUUU.ORG・Web Design Clip のファッション）から開けた10件を `scripts/sample.js` で 1440px で測った（kolor・TOKYO BASE・niko and…・DROP TOKYO・ARTS&SCIENCE・Champion・DEADLY PONIES・LALEROBE・Make My Lemonade・Femme&Fierce）。
| 見たもの | 実測 | ORBITO 第1・2版でしたこと |
|---|---|---|
| 差し色 | 原色・蛍光は0件。暗くくすんだ色（kolor #283249、Champion #012169、Femme&Fierce #7c0b40、Make My Lemonade #4e2629、DROP TOKYO #7f2929） | #FF4F00 の大きな面、ミント #8FF5E4 |
| 地 | 真っ白（TOKYO BASE・niko and…・Champion・Make My Lemonade）か、色の入った白・黒（ARTS&SCIENCE #ecebeb、DEADLY PONIES #f0efeb／#141414、TOKYO BASE #edf1f2、kolor #283249） | #0C0B10・#FFD9E6 |
| 文字の色 | 純黒 #000 が6件（指摘と違い、文字の黒はふつう） | ― |
| 書体 | グロテスク体（kolor LTUnivers、TOKYO BASE DIN、DROP TOKYO Neue Haas Unica、niko and… Helvetica Neue）か、セリフ・明朝（ARTS&SCIENCE Sabon、as it is 游明朝）。太さは 400〜600、900 は0件 | Noto Sans JP 900 ＋ Unbounded 800 |
| ボタン | 塗りか枠のある短いリンクが0個のサイトが6件。あっても小さく角0（DEADLY PONIES 黒、Make My Lemonade 1px の枠） | 大きな橙の塗りボタン、2px の枠の切り替え |
| 章の区切り | 全幅の罫は8件で0本。写真と余白で区切る | 一覧の罫・フッターの上の罫 |
| 色を持つ物 | 写真（モデル・服）。画面の地と文字はほぼ無彩色 | 地・惑星・ロゴ・ボタンに色 |

- **作る前に、その業種の手本を事例集から5〜10件選び、`node scripts/sample.js <URL…>` で地・文字・差し色・書体と太さ・ボタン・罫の数を測ってから、3色と書体を決める。** 決まり1（鮮やかな主の色を大きな面で）は、ポスター・告知・ポップな LP の型。手本の業種が使っていなければ使わない。
- 色は「題材そのもの」（服・料理・建物の写真）に持たせ、画面の地と文字は色の入った無彩色に寄せる業種がある（ファッションはそう）。
- 書体は雰囲気で替える。ORBITO 第3版では COOL＝Archivo＋Zen Kaku Gothic New、CUTE＝Cormorant Garamond の斜体＋Zen Old Mincho（手本の Univers・DIN／Sabon・游明朝の代わりの Google Fonts）。
- ファッションの本文は 12〜15px が多かった（DROP TOKYO・DEADLY PONIES 12px、kolor 14px）。ここは真似ず、本文 16px の決まり（`ai-tells.md`）を残した。

## 当てる順番
作る前（`make.md`）に、上の「業種の手本を先に測る」をしてから、3色（地・主・差し色の色名と値）と、分け方の比率と、題の置き方を1行ずつ書いてから作る。作った後は `critique.md` の見方7（色）で「主の色が大きな面を持っているか」「色相が3つを超えていないか」を見る。
