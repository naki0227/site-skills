# 横断ルール：ECのサイトをまたいで効いていること

2つ以上のサイトで同じ結果になったことだけを、番号つきで書く。1サイトだけの発見は `types/<slug>.md` に置く。
書くときは（〇〇と△△で確認）のように、元になったサイトを添える。

1. カートに入れても、ページを移さない。押した場所の近くで反応を返す（Allbirds：右からドロワー、とらや：上部に黒い帯＋ボタンが「追加しました」に変わる、Our Place：約0.56秒で右から幅422px のドロワー、中川政七商店：約0.17秒でボタンの上に 328×56 の吹き出し＋ヘッダーの赤い数、Tracksmith：JS で「JUST ADDED」の小窓を4秒、カートの印で幅840px のドロワー、BASE FOOD：約0.2秒で下の中央に role="status" のトースト 309×53 を約4秒＋ヘッダーの袋の数、Iittala：1.16秒で右下に 446×56 のトーストを約3.5秒＋ヘッダーの数。role も aria-live も無い）。反例：Sey は普通のフォーム送信で /cart に移る（作るときは移さない）。
2. SP では、カートボタンを画面の下に固定する（Allbirds：スクロールすると現れる固定、とらや：sticky; bottom:0 の帯に数量も入る、Our Place：最初の画面から 358×48 を固定、Sey：fixed・bottom:0・padding 20px の 390×100、中川政七商店：説明を過ぎて0.5秒後に幅75%、押すと色の行の窓、Tracksmith：購入の列を過ぎてから 390×74 の帯、サイズ未選択なら押すと列へ smooth で戻す、BASE FOOD：購入の列を過ぎてから SP 390×71・PC 800×76 の丸い帯、押すと数量の select へ戻す）。反例：Iittala は SP に固定のボタンを置かないが、最初の画面（844px）に名前・価格・帯 y=717〜757 を入れている（固定しないなら、最初の画面に入れる）。出す合図は IntersectionObserver で拾う（Tracksmith は IntersectionObserver、中川は scroll の検知と setTimeout＝反面教師）。
3. 返品の条件は、詳細の本文ではなくフッターの法務・サポートのページにだけある。作るときは詳細から1手で届くようにする（Allbirds は Refund policy の窓、とらやは特定商取引法の表示、Our Place はフッター Support → Returns。詳細の「Free Shipping & Returns」の印はリンクではない。中川政七商店はフッター → ご利用ガイド → 返品・交換の2手。Tracksmith はフッター → 案内の1手で、ドロワーに「30-DAY RETURNS & EXCHANGES」の1行）。反例：Iittala は詳細のカートの帯の直下に「Free returns within 30 days of delivery.」（0手。ただし3行を約3秒ずつ回す窓の中）。
4. 一覧の画像は lazy で読む（Allbirds img 69/83、とらや 61/63、Our Place 68/71、Tracksmith 164/173。反例：中川政七商店は 94点を1ページに出して lazy 0/186）。数十点なら1ページに全部出す店（Allbirds 39件、とらや 27件、Tracksmith 79枚）と、12点ずつ「LOAD MORE」で足す店（Our Place 44点）があるが、件数を出さずに送るのは反面教師。送るなら「44点中12点」と残りの数を出す（Iittala：39点ずつ「Load more」と「Showing 39 of 93 products」、img 85/113 を lazy）。件数とカードの数をそろえる（Allbirds の JSON-LD 148／39件、Tracksmith の「145 RESULTS」／79枚はずれる）。
5. BreadcrumbList の構造化データは、テーマの標準では付いていない（Allbirds・とらやは無し、Our Place はアプリ「SchemaPlus」で後から足している、Sey は JSON-LD そのものが0、中川政七商店は詳細に Product だけ、Tracksmith は詳細に Product だけで画面のパンくずも無い、BASE FOOD は自前の Next.js でも JSON-LD が0で、画面のパンくずだけある）。反例：Iittala は自前のテーマで一覧・詳細・案内に BreadcrumbList を付けるが、詳細の道が「Gifts → Gifts under 25 €」で品の種類の道になっていない。作るときは最初から付ける。
6. 絞り込みを「選ぶたびに反映」にしない場面では、適用ボタンで反映し、選んだ条件を結果の上に並べ直す（Allbirds：SP の全画面フォームで「APPLY FILTERS」→ 一覧の上にチップ、とらや：「条件で探す」の「検索」→ 結果の上に「検索条件：…」の帯と件数）。選ぶたびに反映する場合も、選んだ条件を「×」付きで並べて「すべて外す」を置く（Our Place：Applied Filters と Clear all、Tracksmith：「TEES ×」と CLEAR・群の名前に「STYLE (1)」、Iittala：ドロワーの下の「See 1 results」の数がすぐ変わり、閉じると件数の横に「Blue ×」、帯に「Reset all」）。反例：中川政七商店は選ぶたびにページを読み直して一番上に戻り、チップも無く、0件では選んだ条件が欄から消えて外せない。
7. ページの重さの主因は写真ではなく JS（Allbirds：JS が毎ページ約8.6MB、とらや：写真は詳細で317KBだが Google タグと同意バーで毎ページ約2.2MB、Our Place：画像は 0.9〜1.6MB だが JS が毎ページ約12〜15MB、Sey：一覧の絵 411KB に対し JS が毎ページ約4.3MB、うち購入手続きの先読み約1.8MB、中川政七商店：AI チャットの WASM が開く前から毎ページ約14.2MB、Tracksmith：写真 0.04〜2.5MB に対し JS 約2.3MB・一覧の HTML 3.6MB・accessiBe 891KB とカートのおすすめ 528KB を毎ページ、BASE FOOD：画像 0.04〜4MB に対し JS が毎ページ約17〜19MB、うち決済の Stripe 約3.7MB をトップと空のカートでも、Iittala：JS が毎ページ約5.7〜6.5MB（ほどいた後）、うち Shopify の購入手続きの先読み49〜66本をカートが空でも。トップだけは全面の動画 12.1MB が主因）。作るときは写真より先にタグと JS を削る。
8. カートに入れた後の画面で、送料無料までの残りを金額とバーで示し、数量を変えるとすぐ言い直す（Allbirds：「あと$86で送料無料」、Our Place：「$165 away」と $135／$300 の2段のバー、Tracksmith：空のときから「ADD $200 TO YOUR CART…」とバー）。とらやはかごでも出さない、中川政七商店は吹き出しで言わない、BASE FOOD は送料無料の条件が無く、最低額 ¥2,600 に届かないときも足りない金額を言わない、Iittala はカートで「Shipping: Calculated at checkout」と会員の条件の灰の1行だけ（反面教師）。
9. 商品詳細に送料の金額が無い（とらや：案内は別サイト、Sey：記載なし・定期便だけ「free shipping」、Tracksmith：$10〜は別のサブドメインのヘルプ記事だけ、BASE FOOD：500円は会社サイトの特定商取引法の表示だけで、カートにも行が無い、Iittala：一律 9.90 € は配送の案内のページだけで、カートは「Calculated at checkout」）。作るときは詳細の購入の列の近くに、送料の金額か送料無料の条件を書く。
10. 送料無料の条件は、全ページの頭の帯に常に出す（Our Place：40px の告知バーに「Free shipping $135+」、中川政七商店：40px・#f2f2f2 の帯に「11,000円以上で送料・代引き手数料無料」とフッターに金額）。詳細から0手で届く。告知を回すなら最初の1枚にする（Tracksmith は3枚を矢印で送るうちの3つ目、Iittala は4本を回すうちの3本目で、しかも会員の条件＝反面教師）。条件だけでなく金額もどこかに必ず書く（Our Place は $135 未満の送料の金額が見つからない＝反面教師）。
11. ブランドの色を塗ったボタン・札・印は、文字とのコントラストが足りないことが多い（とらや：順位札 2.37／2.85、Our Place：未選択の枠 1.47、Sey：灰の文字 3.69、中川政七商店：カート 白／#32a2c5 2.95・メール便可 2.12、Tracksmith：押せない「SELECT A SIZE」を opacity .2 にして 1.28、BASE FOOD：小さな見出しの黄 #fac83c／白 1.57・押せない「今すぐ購入」1.55・札の白／#f05e88 3.15）。作るときは主の行動の地と白の文字で 4.5 以上を計算して確かめる。
12. 品切れのサイズは消さずに斜線で残し、押せるようにして、押したら購入のボタンの場所を入荷通知に替える（Allbirds：斜線＋薄く・「NOTIFY ME」、Tracksmith：1px の斜線・メールか電話の欄）。Iittala：見本を opacity .4 で残し、黒い帯の場所を灰の「Notify me」344×51 に替える。反例：Our Place は売り切れの色を画面から消す、Sey は select の中で「Sold Out」と書いて選べない。Tracksmith・Iittala は入荷の時期を書かない（作るときは書く）。
13. バリエーションを選ぶまで、購入のボタンに何を選ぶかを書いて押せなくし、選んだらボタンに金額か「カートに入れる」を出す（Allbirds・Tracksmith とも「SELECT A SIZE」、Tracksmith は選ぶと「$80 — ADD TO CART」）。押せない状態の文字も 4.5 以上で読ませる（Tracksmith の opacity .2 は 1.28）。
14. 買い方の選択肢（単品／セット、定期便／一回）は、幅いっぱいのラジオカードにし、選んだ1枚だけ開いて条件や次の選択を出す。比べる元の金額（Value・打ち消した定価）をカードか金額の横に置く（Our Place：464px の3枚、選んだ1枚に色と「$284 Value」、BASE FOOD：432px の2枚、継続 305px／一回 76px、「¥3,060（打ち消し）¥2,448」と2回目以降の金額）。未選択の枠は両方とも 3:1 に届かない（1.47・1.67）ので、作るときは濃くする。
15. 色や味の違いを別の商品ページにする店は多い。そうするなら一覧では色ごとに1枚のカードにし、詳細では見本か行から1手でほかの色へ届かせる。押したときにページごと読み直さず、写真・在庫・URL だけ替える（中川政七商店：色ごとに URL と JAN が別で、詳細に色ごとの行、Iittala：色ごとに商品 ID が別で、40×40 の写真の見本を押すと 3.51秒・2,868KB の読み直し、BASE FOOD：味のカードを押すと別の商品ページへ移る）。見本の上の名前は品の色の名前にし、系統名（Iittala の「Red」）にしない。
