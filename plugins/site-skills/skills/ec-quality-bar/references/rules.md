# 横断ルール：ECのサイトをまたいで効いていること

2つ以上のサイトで同じ結果になったことだけを、番号つきで書く。1サイトだけの発見は `types/<slug>.md` に置く。
書くときは（〇〇と△△で確認）のように、元になったサイトを添える。

1. カートに入れても、ページを移さない。押した場所の近くで反応を返す（Allbirds：右からドロワー、とらや：上部に黒い帯＋ボタンが「追加しました」に変わる）。
2. SP では、カートボタンを画面の下に固定する（Allbirds：スクロールすると現れる固定、とらや：sticky; bottom:0 の帯に数量も入る）。
3. 返品の条件は、詳細の本文ではなくフッターの法務ページにだけある。作るときは詳細から1手で届くようにする（Allbirds は Refund policy の窓、とらやは特定商取引法の表示）。
4. 一覧は、数十点ならページ送りなしで1ページに全部出し、画像は lazy で読む（Allbirds 39件・img 69/83が lazy、とらや 27件・img 61/63が lazy）。
5. BreadcrumbList の構造化データは付けていない（Allbirds、とらや）。画面のパンくずがあっても検索結果には出ない。作るときは付ける。
6. 絞り込みを「選ぶたびに反映」にしない場面では、適用ボタンで反映し、選んだ条件を結果の上に並べ直す（Allbirds：SP の全画面フォームで「APPLY FILTERS」→ 一覧の上にチップ、とらや：「条件で探す」の「検索」→ 結果の上に「検索条件：…」の帯と件数）。
7. ページの重さの主因は写真ではなく JS（Allbirds：JS が毎ページ約8.6MB、とらや：写真は詳細で317KBだが Google タグと同意バーで毎ページ約2.2MB）。作るときは写真より先にタグと JS を削る。
