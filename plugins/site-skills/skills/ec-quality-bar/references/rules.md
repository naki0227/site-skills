# 横断ルール：ECのサイトをまたいで効いていること

2つ以上のサイトで同じ結果になったことだけを、番号つきで書く。1サイトだけの発見は `types/<slug>.md` に置く。
書くときは（〇〇と△△で確認）のように、元になったサイトを添える。

1. カートに入れても、ページを移さない。押した場所の近くで反応を返す（Allbirds：右からドロワー、とらや：上部に黒い帯＋ボタンが「追加しました」に変わる、Our Place：約0.56秒で右から幅422px のドロワー、中川政七商店：約0.17秒でボタンの上に 328×56 の吹き出し＋ヘッダーの赤い数）。反例：Sey は普通のフォーム送信で /cart に移る（作るときは移さない）。
2. SP では、カートボタンを画面の下に固定する（Allbirds：スクロールすると現れる固定、とらや：sticky; bottom:0 の帯に数量も入る、Our Place：最初の画面から 358×48 を固定、Sey：fixed・bottom:0・padding 20px の 390×100、中川政七商店：説明を過ぎて0.5秒後に幅75%、押すと色の行の窓）。出す合図は IntersectionObserver で拾う（中川は scroll の検知と setTimeout＝反面教師）。
3. 返品の条件は、詳細の本文ではなくフッターの法務・サポートのページにだけある。作るときは詳細から1手で届くようにする（Allbirds は Refund policy の窓、とらやは特定商取引法の表示、Our Place はフッター Support → Returns。詳細の「Free Shipping & Returns」の印はリンクではない。中川政七商店はフッター → ご利用ガイド → 返品・交換の2手）。
4. 一覧の画像は lazy で読む（Allbirds img 69/83、とらや 61/63、Our Place 68/71。反例：中川政七商店は 94点を1ページに出して lazy 0/186）。数十点なら1ページに全部出す店（Allbirds 39件、とらや 27件）と、12点ずつ「LOAD MORE」で足す店（Our Place 44点）があるが、件数を出さずに送るのは反面教師。送るなら「44点中12点」と残りの数を出す。
5. BreadcrumbList の構造化データは、テーマの標準では付いていない（Allbirds・とらやは無し、Our Place はアプリ「SchemaPlus」で後から足している、Sey は JSON-LD そのものが0、中川政七商店は詳細に Product だけ）。作るときは最初から付ける。
6. 絞り込みを「選ぶたびに反映」にしない場面では、適用ボタンで反映し、選んだ条件を結果の上に並べ直す（Allbirds：SP の全画面フォームで「APPLY FILTERS」→ 一覧の上にチップ、とらや：「条件で探す」の「検索」→ 結果の上に「検索条件：…」の帯と件数）。選ぶたびに反映する場合も、選んだ条件を「×」付きで並べて「すべて外す」を置く（Our Place：Applied Filters と Clear all）。反例：中川政七商店は選ぶたびにページを読み直して一番上に戻り、チップも無く、0件では選んだ条件が欄から消えて外せない。
7. ページの重さの主因は写真ではなく JS（Allbirds：JS が毎ページ約8.6MB、とらや：写真は詳細で317KBだが Google タグと同意バーで毎ページ約2.2MB、Our Place：画像は 0.9〜1.6MB だが JS が毎ページ約12〜15MB、Sey：一覧の絵 411KB に対し JS が毎ページ約4.3MB、うち購入手続きの先読み約1.8MB、中川政七商店：AI チャットの WASM が開く前から毎ページ約14.2MB）。作るときは写真より先にタグと JS を削る。
8. カートに入れた後の画面で、送料無料までの残りを金額とバーで示し、数量を変えるとすぐ言い直す（Allbirds：「あと$86で送料無料」、Our Place：「$165 away」と $135／$300 の2段のバー）。とらやはかごでも出さない、中川政七商店は吹き出しで言わない（反面教師）。
9. 商品詳細に送料の金額が無い（とらや：案内は別サイト、Sey：記載なし・定期便だけ「free shipping」）。作るときは詳細の購入の列の近くに、送料の金額か送料無料の条件を書く。
10. 送料無料の条件は、全ページの頭の帯に常に出す（Our Place：40px の告知バーに「Free shipping $135+」、中川政七商店：40px・#f2f2f2 の帯に「11,000円以上で送料・代引き手数料無料」とフッターに金額）。詳細から0手で届く。条件だけでなく金額もどこかに必ず書く（Our Place は $135 未満の送料の金額が見つからない＝反面教師）。
11. ブランドの色を塗ったボタン・札・印は、文字とのコントラストが足りないことが多い（とらや：順位札 2.37／2.85、Our Place：未選択の枠 1.47、Sey：灰の文字 3.69、中川政七商店：カート 白／#32a2c5 2.95・メール便可 2.12）。作るときは主の行動の地と白の文字で 4.5 以上を計算して確かめる。
