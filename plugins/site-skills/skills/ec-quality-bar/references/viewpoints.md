# ECで見ること・決めること

解剖でも、作るときでも、この順に見る。作るときは、それぞれに「どうするか」を1行で決めてから書き始める。
解剖で裏づけた値は `types/<slug>.md` に、どのサイトの値かを添えて書く。このファイルには問いだけを置く。

- **一覧**：グリッドの列数（PC/SP）と1枚のカードに載る情報（画像・名前・価格・色数・レビュー・在庫や新着の印）。色で絞ったとき、カードの色見本と写真がその色に移るか。鞄なら、何が入るか（A4・PC のインチ・ボトル）で絞れるか。絞り込みの場所・項目数・SP での出し方・反映のしかた（すぐ／適用ボタン）。並べ替えの初期値。件数の表示。ページ送り／無限スクロール／もっと見る。
- **詳細のファーストビュー**：最初の画面に入るもの（名前・価格・税込の表記・バリエーション選択・カートボタン）。画像の枚数・縦横比・ズーム・SP のスワイプ。購入の列より上に編集の写真や動画の段を置くか、置くならそれで何が最初の画面から落ちるか。
- **バリエーションと在庫**：色はスウォッチか文字か、在庫切れの見せ方（消す／薄くする／入荷通知）、選ぶと何が変わるか（画像・価格・URL）。形や容量が違う同じ品（量り売り・缶・袋）なら、同じ単位（1kg・1杯）の値段を出すか、量を選んだら合計を言い直すか。寸法が二軸（身幅×丈）なら、品切れの組み合わせをどちらを選んだときに見せるか、身幅の側にも印を出すか。
- **カートに入れる**：ボタンの位置（SP で固定か）と押した後の反応（ドロワー／移動／トースト）、数量の変え方。カートでの合計・送料・送料無料までの残り。
- **買う前の不安**：送料・返品・支払い方法・納期・特定商取引法の表記に、商品詳細から何手で行けるか。カートのボタンの直下に約束（返品の日数・送料・包装）を何行置くか、回すか全部見せるか。値段の中身（原価の内訳・工程ごとの取引先と最後に行った日）を詳細に出すか、出すならどの段に。
- **データ**：構造化データ（Product・Offer・AggregateRating・BreadcrumbList）、パンくず、画像の alt。
- **重さ**：一覧の画像の合計と遅延読み込み、詳細の画像の大きさと枚数、レビューや推薦の外部スクリプト。和文の Web フォントとアイコンのフォントの合計。
- **状態**：検索・絞り込みの0件、在庫切れ（一部の容量／全部）、入荷待ち、販売終了の行き先、カートが空、数量の上限、読み込み中、入れられなかったときで、それぞれ何を言い、次に何を押させるか。実店舗があるなら、オンラインの品切れから店の在庫へつなぐか。
- **写真を使わない一覧**：写真の代わりに1件に何を何行、どの書体・大きさで載せるか。比べる軸（産地・味・焙煎度・値段）を全部の札で同じ行に置いているか。
- **品数の多い店**：カテゴリは何段か、色・柄の違いを1つの商品の選択肢にするか別の商品にするか、色ごとにボタンを置くか、一覧は1ページに全部出すか送るか。色ごとに別ページにするなら、見本を押したときに読み直すか、見本の上に品の色の名前と系統名のどちらを出すか。
- **定期便と最低額**：定期便と一回の買い方をどう選ばせるか（カード・切り替え）、間隔・割引・変更の締め切りをどこに書くか、数量の初期値と選択肢の刻み、最低額や送料無料に届かないとき何を言うか、カートで買い方を切り替えたとき差額をどう出すか。打ち消し線の元の値段は何の合計か、数（1・2・3・6組）の札の率は実際に安くなる率か、カートで数を増やしたとき組の値段を当てるか。
- **お届け期間と届け日**：作った組・仕込みの回で届く週が決まる品なら、バリエーションを期間にするか、受付を終えた期間をどう見せるか（残す・消す・理由と次の日付）、届け日の指定を購入の列でさせるかカートの先でさせるか、熨斗・ラッピングの可否をどこで言うか。贈り方（自宅へ／贈り先へ／住所を知らない相手に eギフト）を購入の列で選ばせるか、選ぶと何が開き、手数料をどこで言い、カートのボタンがどこまで下がるか。季節の品なら販売期間をトップと詳細のどちらに日付で書くか。
- **名入れ・刻印**：詳細のどこから入るか（カートのボタンと並べるか）、入力を別の面にするか、使える文字・文字数・行の決まりを欄の前に書くか、追加の値段・発送の遅れ・返品不可をどこで言うか、刻印の見本の書体をどのページで読むか。
- **型×色で値段が違う品**：色や型を選んだとき値段・分割払いの額・URL を言い直すか、一覧・比べる表・構造化データの値段はどの組み合わせの値段か、上の軸（型）で選べない色をどう見せるか、保証などの有料の付け足しを最初から選んでいないか。
- **組で売る品**：カバーと中身・本体と付属のように別の商品を組ませるなら、一覧のカードに組と単品のどちらの値段を出すか、詳細で組か単品かをどう選ばせるか（タブ・カード）、最初に選ばれている中身は何か、選んだ組をどこで言い直すか、カートで組を1行にするか中身ごとの行に割るか、組の値引きがあるか。
