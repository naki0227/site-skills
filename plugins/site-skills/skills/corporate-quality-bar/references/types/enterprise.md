## 真似る型（2サイト：Valmont・日清食品グループ）
- **ナビは左に「事業や世界」、右に「用事」**。Valmont は左に事業2つ▾、右に Careers・Company・Investors。日清は左に商品情報・企業情報、右にお客さま窓口・リクルート↗・オンラインストア↗。別ドメインは↗で区別する（両方）。
- **下の段の出し方は2通り**。項目に1文を添えたいときは画面の端を 10px 残した黒いパネル（Valmont：題＋1文＋2列のリスト、1,420×520px）。項目が多く1文が要らないときは、文字の行を段々に足す（日清：2段目4項目→3段目 6〜12項目、16px 太字、後ろは blur 5px＋黒 10%）。どちらも SP は全画面の開閉で、いまの世界を開いて出す（日清）。
- **ヘッダーは下へ読むと隠れ、上へ戻すと出す**（Valmont：76px を隠し上へ 38px 戻すと黒い浮きバー、日清：94.5px を transform .4s cubic-bezier(.19,1,.22,1)）。
- **会社のトップは入口から始める**。Valmont は「1文→数字4つ→価値観4語→年表」、日清は「入口の格子7枚（4列×322×181px・名前は下）→ニュース4→IR→サステナ→グループ会社」。上場企業なら IR の帯を会社トップに置き、資料の名前に［PDF 316KB］の形で種類と大きさ、次の決算発表日を1行で添える（日清）。
- **商品と会社の両方を持つなら、トップを2つに分け、同じヘッダーで地の色を変える**（日清：商品 #1a1a1a・会社 #fff、title も分ける）。ただし会社の側の h1 と「何の会社か」の1文は、会社のトップに必ず置く。
- **文字は1書体・2太さまでに絞り、大きさをトークンで持つ**（Valmont：Roboto 400 だけ・root×clamp の10段、日清：Aoto Gothic 400/700・5役×3段＝15段、行間は役ごとに1つ）。
- **ホバーと開閉の曲線を1本に決める**（日清：cubic-bezier(.19,1,.22,1)、ホバーは不透明度 .8／.6・.5s。Valmont：GSAP expo.out 0.5s）。
- **採用はグループの入口で振り分け、各社の採用サイトへ ↗ で渡す**（日清：新卒・キャリア・アルムナイ＋16社、Valmont：US／AUS・NZ／Global の3つ）。

## 反面教師
- トップの1文の誤字「has a been」（HTML に PC 用・SP 用の2つの文があり、画面に出る方だけ誤り）、「infastructure」「reimbursment」、Company のメガメニューの1文が Careers の流用。白地の文字に #828282（3.84:1）・#c0c0c0（1.82:1）。`lang` 空、構造化データ無し（Valmont 2026-10-25）。
- 行の出し方が scrub なので、スクロールを止めると本文が半透明のまま残る。reduced-motion で止まるのは最初の画面だけ（Valmont）。
- PC と SP で同じ画像、一覧の小さな写真に原寸、同じ画像を2つのホストから二重に読む（Valmont）。
- 採用ページ 14.85MB・写真33枚で alt 無し。画像が全部 alt 無しの事業ページ（Valmont）。
- 自サイトのニュース（Projects）が2025年2月で止まり、絞り込みも無い（Valmont）。
- 会社ページに設立・資本金・本社の表が無く、代表メッセージも自サイトに無い（Valmont）。
- トップの h1 が CM の題（「カプポッポ 篇」）で、会社の話は 79% の位置。採用・ニュース・IR の入口がトップに無い（日清 2026-10-29）。
- ブランドの赤 #ff0000 を、白地の 16px のリンクと白字の地にそのまま使い 4.00:1（日清）。文字に使う赤は #e00000（5.04:1）に分ける。
- トップ 36.85MB：SNS の写真を原寸で 306px に、CM の YouTube を2つ埋め込みプレーヤーを2回、会社トップの株価の図に 2,719KB（日清）。
- ナビの開閉に grid-template-rows（レイアウトの値）を動かし、▾のボタンは 12×27px。reduced-motion は CSS に 0（日清）。
- フッターが4項目でサイトの地図が無い。会社の4ページに description と構造化データが無い（日清）。
