# 横断ルール：コーポレートのサイトをまたいで効いていること

2つ以上のサイトで同じ結果になったことだけを、番号つきで書く。1サイトだけの発見は `types/<slug>.md` に置く。
書くときは（〇〇と△△で確認）のように、元になったサイトを添える。

1. 採用への入口は、ヘッダーの常設ナビとトップの本文の両方に置く（LayerX：ナビ2か所＋Join Us の節、Valmont：Careers▾＋トップの入口03）。ヘッダーとフッターだけにした竹中庭園緑化は、トップの7区画のどこからも採用へ行けなかった。
2. 募集の一覧は外部の採用システムに任せ、自サイトは「どんな職場か」の話に絞る（LayerX：外部ATS、Valmont：Workday と LinkedIn、竹中庭園緑化：job-gear.net の採用サイト）。
3. 採用ページは、その会社のページの中で一番重くなる。作るときは写真や動画に上限を決める（LayerX 6.51MB が最大、Valmont 14.85MB が最大、竹中庭園緑化 6.29MB がトップ 5.74MB より重く、解析タグを入れると GTM 14本で +7.3MB）。
4. スクロール中もナビへ戻る手段を必ず残す。隠すなら戻し方を、隠さないなら画面をふさがない薄い帯にする（LayerX：左上の「ロゴ＋Menu」だけ残す、Valmont：上へ 38px 戻すと黒い浮きバー、竹中庭園緑化：隠さず白 .8＋blur 10px の丸い帯 97px）。
5. トップに数字の帯は置かず、規模の数字は会社ページ（Valmont）か本文（LayerX）か会社概要の表（竹中庭園緑化：239名・9,500万円）に回している。作るときは会社ページに数字4つ前後を表の上に置く（LayerX は本文に、竹中庭園緑化は表の中に埋もれて弱かった）。
6. トップのニュースや事業の一覧はカードでなく全幅の行で並べる（LayerX：1行 192〜196px、Valmont：1行 210px・右に写真 308×188、竹中庭園緑化：1行 74px・日付→札→題）。
7. 見出しの文を二重に持つと、片方だけ直し漏れる（LayerX：PC 用と SP 用の見出し、Valmont：PC 用・SP 用の1文の片方だけ「has a been」、竹中庭園緑化：SVG の見出しと alt が3か所違う）。文は1つだけ持ち、分けるのは見た目の側だけにする。
8. 問い合わせフォームに用件の選択が無いと、採用・買い物・取引の相談が同じ5欄に混ざる（Valmont：5欄で用件無し、竹中庭園緑化：5欄すべて必須で用件無し）。振り分けたのは LayerX だけ（フォームの前にリンク5つ）。作るときはフォームの前で振り分け、用件を選ばせる。
9. `prefers-reduced-motion` を見ていても一部だけで、動きが止まりきらない（Valmont：最初の画面だけ、竹中庭園緑化：CSS に1つも無く、reduce でもトップで16個が動く）。作るときは、浮き・差し替え・スクロール連動を全部止める。
10. SP 用の画像の出し分けが崩れて、SP で PC と同じ量を読む（Valmont：SP＝PC の画像、竹中庭園緑化：pcOnly と spOnly の img を両方の幅で読む）。`<picture>` の source で出し分ける。
11. ニュースの絞り込みはページごと読み直す作りで、1回に1MB 前後増える（LayerX：SP で最大 +1.3MB、竹中庭園緑化：PC 2.8〜3.3s・+0.9〜2.0MB）。絞り込みは URL に残したまま、その場で一覧だけ替える。
