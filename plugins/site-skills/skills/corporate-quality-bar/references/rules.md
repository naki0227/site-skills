# 横断ルール：コーポレートのサイトをまたいで効いていること

2つ以上のサイトで同じ結果になったことだけを、番号つきで書く。1サイトだけの発見は `types/<slug>.md` に置く。
書くときは（〇〇と△△で確認）のように、元になったサイトを添える。

1. 採用への入口は、ヘッダーの常設ナビとトップの本文の両方に置く（LayerX：ナビ2か所＋Join Us の節、Valmont：Careers▾＋トップの入口03）。
2. 募集の一覧は外部の採用システムに任せ、自サイトは「どんな職場か」の話に絞る（LayerX：外部ATS、Valmont：Workday と LinkedIn）。
3. 採用ページは、その会社のページの中で一番重くなる。作るときは写真や動画に上限を決める（LayerX 6.51MB が最大、Valmont 14.85MB が最大）。
4. ヘッダーは下へのスクロールで隠し、戻る手段を必ず残す（LayerX：左上の「ロゴ＋Menu」だけ残す、Valmont：上へ 38px 戻すと黒い浮きバーで戻る）。
5. トップに数字の帯は置かず、規模の数字は会社ページ（Valmont）か本文（LayerX）に回している。作るときは会社ページに数字4つ前後を表で置く（LayerX は本文に埋もれて弱かった）。
6. ニュースや事業の一覧はカードでなく全幅の行で並べる（LayerX：1行 192〜196px、Valmont：1行 210px・右に写真 308×188）。
7. 見出しを1文字ずつ分けて動かすサイトは、見出しの文を二重に持ちがちで、片方だけ直し漏れる（LayerX：PC 用と SP 用の見出し、Valmont：PC 用・SP 用の1文の片方だけ「has a been」）。文は1つだけ持ち、分けるのは見た目の側だけにする。
