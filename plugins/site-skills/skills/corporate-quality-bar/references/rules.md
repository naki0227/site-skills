# 横断ルール：コーポレートのサイトをまたいで効いていること

2つ以上のサイトで同じ結果になったことだけを、番号つきで書く。1サイトだけの発見は `types/<slug>.md` に置く。
書くときは（〇〇と△△で確認）のように、元になったサイトを添える。

1. 採用への入口は、ヘッダーの常設ナビとトップの本文の両方に置く（LayerX：ナビ2か所＋Join Us の節、Valmont：Careers▾＋トップの入口03）。ヘッダーとフッターだけにした竹中庭園緑化は、トップの7区画のどこからも採用へ行けなかった。採用サイトの HILLTOP も応募の入口はヘッダーの ENTRY と最後の Join Us! の帯だけで、社員の声・仕事・数字の区画のあとには無い。Mistral AI はヘッダーの Company の下がり窓の4項目目だけで、トップの本文・フッター・相談の振り分けのどこにも無かった。日清食品グループもヘッダー右の「リクルート↗」だけで、商品のトップ（11,284px）と会社のトップのどちらの本文にも採用の入口が無かった。採用サイトの Life at Spotify は逆に、トップの最初の画面そのものが募集の束と検索で、Latest jobs・Wanna join us?・Quick clicks・フッターの Start Your Journey と、本文に5か所の入口がある。 由紀精密もトップの本文に採用の区画が無く、右下に浮くバナー（PC 画面の10.3%）が別ドメインのエンジニア採用サイトへ行くだけ。 Linear もヘッダーに採用が無く（Resources▾ の2番目）、トップの本文・Contact にも無い。入口はフッター・About の「We're hiring →」・SP のメニューだけ。 I-ne（大企業・上場）は守っている例で、ヘッダーの6項目の6番目に RECRUIT（吹き出しに採用エントリー↗）、トップの7区画の最後に採用の区画（3,736px）を置く。 Vitsœ（中小・地域企業、英国）も上段の用事の5番目「Careers」14px とフッターだけで、トップの7区画に採用の入口が無い。 採用サイトの SmartHR は、ヘッダーの8項目に応募の入口を置かず、PC は右下に「カジュアル面談」「募集職種・エントリー」（301×80px×2）を全ページで貼りつけ、トップの ISSUE を開くと関連する求人が4件出る。SP には貼りつく入口が無く、メニューの中と最後の帯だけ。 Mercury（スタートアップ）もヘッダーは About▾ の板の CONNECT の3番目（14px）とフッターだけで、トップ（脚注まで約12,000px）と会社ページの本文に採用の入口が無い。 採用サイトの廣野鐵工所も、ヘッダーの ENTRY（下へ送ると隠れる）・メニューの板・全ページ最後の赤い帯だけで、トップの途中の職種・人・制度の区画のあとに応募の入口が無い。しかも3つとも募集要項へ行き、フォームは募集要項の下から（2手）。 Kering（大企業・上場）は守っている例で、ヘッダー右の JOIN US・ナビの TALENT に加え、トップの本文に TALENT の帯（求人の検索欄、412px）とモザイクの TALENT 2枚を置く。
2. 募集の一覧は外部の採用システムに任せ、自サイトは「どんな職場か」の話に絞る（LayerX：外部ATS、Valmont：Workday と LinkedIn、竹中庭園緑化：job-gear.net の採用サイト、Mistral AI：Ashby）。日清食品グループは総合採用サイトで新卒・キャリア・アルムナイに分け、グループ16社の採用サイト（12ドメイン、job-gear.net が3社）へ渡す。例外は Life at Spotify で、募集は自サイトの API（79件）、応募も自サイトの中の4段のシートで済ませ、外へ渡さない。 由紀精密は自サイトに3職種の募集要項を置き、応募はメール、エンジニアだけ別の採用サイト。 Linear は中間の形で、募集の一覧と詳細は自サイト（/careers/〈uuid〉、パンくず「Careers / Sales」）、応募だけ Ashby へ渡す。 SmartHR も募集の詳細と応募は Talentio（別タブ）で、自サイトは一覧（91件、4つの観点で絞る）までを持つ。 Mercury も一覧（77件・部署15）は自サイトの /jobs、詳細と応募は Greenhouse（新しいタブ）。 Kering も例外で、求人 1,654件を自サイトの /en/talent/job-offers/ に置き、メゾン・国・部門・契約の4つで絞り、6地域の件数（合計 1,654）を地図に出す。
3. 採用ページは、その会社のページの中で一番重くなる。作るときは写真や動画に上限を決める（LayerX 6.51MB が最大、Valmont 14.85MB が最大、竹中庭園緑化 6.29MB がトップ 5.74MB より重く、解析タグを入れると GTM 14本で +7.3MB、採用サイトの HILLTOP はトップの動画が PC 用 60.7MB で、開いて10秒で 42MB）。採用だけのサイトでは逆にトップが一番重く、募集の一覧が一番軽い（Life at Spotify：top 14.50MB、/jobs 3.77MB で写真 0）。 中小の由紀精密は逆で、採用 2.23MB はトップ 8.59MB・事業 7.40MB より軽い（写真の多い事業とトップが重い）。 I-ne も採用が一番重い：PC 16.40MB（トップ 9.15MB）で、うち recruit_message.jpg 1枚が 6,177KB。 Vitsœ は採用（PC 13.47MB）より事業ページ（606、PC 34.93MB）が重い。商品の写真の多い事業ページが一番重くなる例（由紀精密と同じ）。 Mercury は採用（PC 33.21MB、Mux の動画の切れ端 23,822KB）よりブログ（PC 38.99MB、先読み 27,131KB）が重い。採用の SP は 9.84MB で動画の切れ端が PC の 7%。
4. スクロール中もナビへ戻る手段を必ず残す。隠すなら戻し方を、隠さないなら画面をふさがない薄い帯にする（LayerX：左上の「ロゴ＋Menu」だけ残す、Valmont：上へ 38px 戻すと黒い浮きバー、竹中庭園緑化：隠さず白 .8＋blur 10px の丸い帯 97px）。HILLTOP は header が static で、PC ではスクロールするとナビへ戻る手段が無かった。日清食品グループは 94.5px を下へ 300px で隠し、上へ戻すと transform .4s で出す（Valmont と同じ形）。Life at Spotify はピルを隠さず浮かせ（地なし）、区画のページでは下へ読むと1段目だけ 40→−51px に逃がし、2段目を上に残す。ただし浮いたピルが本文の見出しに重なる。 由紀精密も fixed 64px の白を隠さず、事業ページでは 56px の2段目も残す。 Linear も fixed 73px・地なし blur(20px)・下線 白8% を 3,000px 送っても隠さない（竹中庭園緑化・Mistral AI と同じ「隠さない薄い帯」）。 Vitsœ も header が static で、PC・SP とも 1,500px 送ると消え、上へ戻しても出ない。沿革のページだけ年の帯（fixed・65px）が残る。 SmartHR も header は static 80px だが、スクロールすると右上に「メニューを開く」81×80px が fixed で入り、全画面のメニュー（dialog、Esc でボタンへ戻る）を開ける。隠すなら戻し方を、の形。 Mercury も sticky 72px を隠さず、下の区画の地に合わせて 透明 → #171721 → #f6f5f2 → #fbfcfd と .5s で色を替える。 廣野鐵工所はヘッダーごと下へ送ると隠れ、上へ戻すと出る（300px 戻して y=49px）。隠す間は ENTRY も消える。
5. トップに数字の帯は置かず、規模の数字は会社ページ（Valmont）か本文（LayerX）か会社概要の表（竹中庭園緑化：239名・9,500万円）に回している。採用サイトの HILLTOP も数字は専用のページ（/culture/ のタイル9つ）に回した。Mistral AI も社員「900+」は採用ページのタイルにだけ置き、会社ページには無い。作るときは会社ページに数字4つ前後を表の上に置く（LayerX は本文に、竹中庭園緑化は表の中に埋もれて弱かった）。日清食品グループも会社トップに売上・従業員の数字は無く、入口の格子と株価で代えていた。 由紀精密も数字は会社概要の2列の表の中だけ（38名・約200社）。 Linear も数字は About の本文（「Founded in 2019」「40,000 companies」）だけで、人の多さは名前173人の束で見せる。 I-ne もトップに数字の帯が無く、数字は会社概要の資本金（「2026年9月30日現在」つき）と IR の財務ハイライトだけ。 Vitsœ も数字の帯が無く、年数は本文の「For 65 years」「Since 1959」だけ。代わりに値段を「£520 を10年なら1年 £52、週に £1」と割って見せる。 Mercury もトップに数字の帯を置かず、規模の数字はニュースのカードの題（「$1B in annualized revenue and 4+ years profitable」「$5.2B valuation」）と h2「Loved by 450K+…」に置く。
6. トップのニュースや事業の一覧はカードでなく全幅の行で並べる（LayerX：1行 192〜196px、Valmont：1行 210px・右に写真 308×188、竹中庭園緑化：1行 74px・日付→札→題）。 由紀精密も全幅の行 74px（日付→カテゴリ→題→矢印）。ただし flex で、題が2行の行は列が 9〜46px ずれた。 Vitsœ の Voice も全幅の行（日付の列・題と抜粋・写真 188px の3列、1行 約260px）を8件ずつ。
7. 見出しの文を二重に持つと、片方だけ直し漏れる（LayerX：PC 用と SP 用の見出し、Valmont：PC 用・SP 用の1文の片方だけ「has a been」、竹中庭園緑化：SVG の見出しと alt が3か所違う）。文は1つだけ持ち、分けるのは見た目の側だけにする。 由紀精密：製品名が沿革では「AP-0」、メニューとフッターでは「AP-01」。 Linear：導入社数が About で 40,000、募集の詳細で 25,000。変更履歴の同じ URL の題がトップと一覧で別、日付も SEP 10 と September 14。一方でトップの h1 は見た目の行（aria-hidden）と読み上げの1文を分けており、文は1つの形。 SmartHR：最初の画面の1文を PC 用（3行）と SP 用（7行）の2組で持ち、最後の帯では「届ける価値を再定義し」が「成長の角度を塗り替え」に変わる。ISSUE 5 の h3 には同じ文が2回入る。 Mercury：社員数が会社ページで「1,000+」、採用ページで「1000+」。ブログの Company News に同じ記事が2回並ぶ。
8. 問い合わせフォームに用件の選択が無いと、採用・買い物・取引の相談が同じ5欄に混ざる（Valmont：5欄で用件無し、竹中庭園緑化：5欄すべて必須で用件無し）。振り分けたのは LayerX（フォームの前にリンク5つ）と Mistral AI（左に Support・Press・Privacy・Vulnerability の4つ）で、どちらも採用の振り分けは無い。採用サイトの HILLTOP は FAQ の「お問い合わせはこちらから」がエントリーフォームへ来る。作るときはフォームの前で振り分け、用件を選ばせる。 由紀精密は振り分けた4窓口（精密加工・技術開発・広報・採用）に採用を入れた最初の例で、「工場見学は原則お断り」と受けないことも書く。 Linear も Sales・Support・メールの3つで、採用の振り分けは無い（営業のフォームは4欄・必須3）。 I-ne も振り分ける側で、「同意する」のチェック → 個人のお客様のフォーム／用件7つ（IR・広報・OEM・取引先・人事・ガバナンス・その他）の select → 用件ごとに別のフォーム。 Vitsœ はフォームを置かず、窓口ごとに電話・メール・曜日と時間（店4・tel: 9本・mailto: 10本）を並べ、取引先・広報・採用・工場見学（tours@）も同じ表に入れる。 Mercury も会社ページの窓口は Say hello・Press inquiries の2つ（mailto）で、採用の振り分けは無い。
9. `prefers-reduced-motion` を見ていても一部だけで、動きが止まりきらない（Valmont：最初の画面だけ、竹中庭園緑化：CSS に1つも無く、reduce でもトップで16個が動く、HILLTOP：0で、reduce でも数え上げ・棒・社員カードの流れ・動画が動く、Mistral AI：グラフ・地球・視差の3か所だけで、積み木の物理・10秒で回るタブ・ロゴの帯は reduce でも動く）。作るときは、浮き・差し替え・スクロール連動を全部止める。日清食品グループは CSS 8本すべてで 0 で、CM の自動再生とヘッダーの隠れが reduce でも動く。Life at Spotify は CSS で 0か所、止まるのは JS で見る都市の帯だけで、最初の画面の縮み・4秒と2秒の自動送り・出てくる絵・見出しを打つ動きは reduce でも動く。 由紀精密も CSS に 0 で、reduce でもトップの写真が10秒ごとに差し替わる。 Linear は CSS で 42か所（no-preference 27・reduce 15）と解剖した中で最多だが、`(prefers-reduced-motion:reduced)` の書き間違いで流れる帯の複製が消えず、点の格子 75個は reduce でも動く。 I-ne は CSS 554KB に prefers-reduced-motion が0で、WebGL の背景・Barba のページ送り（2,562ms）も reduce で変わらない。 Vitsœ も CSS 605KB に 0 で、606 の組み替えの動画は reduce でも画面に入ると再生する。 守っている例は SmartHR で、速さの変数5つ（.1〜.8s）を reduce の1か所で 0s にし、点描で出る画像・視差・最初の画面の出方も JS の matchMedia で止める（解剖した中で初めて、reduce で止まりきる）。 Mercury も守っている側で、reduce で最初の画面の sticky を外し（`motion-safe:sticky`）、スクロールで送る動画を最後の絵（6.38秒）で止め、区画の動画も 0秒で止め、View Transitions も 0s にする。 廣野鐵工所（採用サイト）も CSS・JS とも 0 で、reduce で開いても最初の画面が4秒で替わり、3つの keyframes が動いたまま。 Kering は CSS に prefers-reduced-motion が0か所で、reduce でも 15秒の送り・進行の線・株価の輪（8s／6s の無限回転）など16の動きが走る。
10. SP 用の画像の出し分けが崩れて、SP で PC と同じ量を読む（Valmont：SP＝PC の画像、竹中庭園緑化：pcOnly と spOnly の img を両方の幅で読む、HILLTOP：`<video>` の source を後から JS で消すので SP でも PC 用 60.7MB の動画）。動画は JS で src を1つだけ入れてから load() する。`<picture>` の source で出し分ける。 由紀精密の事業ページも SP＝PC の 7.40MB（スライダー4枚 4.3MB）。 Vitsœ は出し分け以前に、<img sizes> が「(min-width:1060px) 2880px」と枠の幅でなく写真の幅を宣言し、PC では 235px の枠にも 2,880px の jpg を読む（606 の PC 34.93MB、うち cloudfront 30.6MB）。sizes は枠の幅で書く。
11. ニュースの絞り込みはページごと読み直す作りで、1回に1MB 前後増える（LayerX：SP で最大 +1.3MB、竹中庭園緑化：PC 2.8〜3.3s・+0.9〜2.0MB）。絞り込みは URL に残したまま、その場で一覧だけ替える（Mistral AI は 92件を全部持ち、57〜70ms・通信 0KB で替え、URL に ?categories=a,b&search=x を残した）。日清食品グループも会社・年・月を選ぶたびに読み直し（+0.5〜2.3MB・2.3〜4.9秒）、件数も出ない。Life at Spotify の /jobs も、選ぶと URL（?l=london&c=…&q=…）に残したまま、1回 15〜16KB の JSON で一覧だけ替える（読み直しても残る）。 由紀精密もニュースのカテゴリは読み直し（2.1s・+106KB）、年の select は onChange で即移動（+537KB）。一方で同じサイトの事例の絞り込みは手元の36件を 0KB で替え、#material08 を URL に残す。 I-ne も同じで、ラジオを選んでも何も起きず、「絞り込む」で ?category=&y=&keyword=#result へページごと読み直し（PC +1,078KB・SP +692KB）。 Vitsœ の Voice も Next でページごと読み直し（2.66 秒・+4,177KB）、範囲外の /page/40 も 200 で最後のページを返す。
12. 画像の alt を手で書くと、画面と食い違う（Valmont：事業・採用の画像に alt 無し、竹中庭園緑化：SVG 見出しの alt が3か所違う、HILLTOP：社員3人の写真の alt が全部「開発エンジニア」）。alt は画面に出ている名前・見出しのデータから作る。日清食品グループの総合採用サイトでは、画面で「埼玉工場採用」「神戸工場採用」の2枚の alt が両方「東日本明星」。Life at Spotify のトップは img 31のうち 21に alt 属性が無い。
13. 色の札・帯の上の白字が 4.5:1 に届かない（竹中庭園緑化：#7a9f9f で 2.88:1、HILLTOP：職種札 #da338a で 4.36:1・縦の札 2.75:1・Join Us! の帯の中央 2.94:1）。札の地は白で 4.5 を超える濃さに決め、グラデーションの上には小さな白字を置かない。日清食品グループは白字／#ff0000 の NEW・検索のボタンで 4.00:1、#ff0000 の文字も白地で 4.00:1。 由紀精密：フッターの白／#b2b2b2 で 2.12:1、確認ボタンの白／#e63232 で 4.31:1。 廣野鐵工所（採用サイト）は区画の地の5色すべてで白字が届かない：黄 #F6B000 1.89・青 #4EAEBF 2.58・橙 #F46F2C 2.93・緑 #00A44D 3.27・赤 #E43936 4.25:1（強みのカードは本文まで白）。
