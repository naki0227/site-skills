# 横断ルール：予約のサイトをまたいで効いていること

2つ以上のサイトで同じ結果になったことだけを、番号つきで書く。1サイトだけの発見は `types/<slug>.md` に置く。
書くときは（〇〇と△△で確認）のように、元になったサイトを添える。

1. 払い戻し・キャンセルの条件は、最初の予約ボタンより下に置かれがちで、実測すると買う枠から遠い（じゃらんnet：ボタン y=683 に対し規定 y=3070／DICE：枠 y=563 に対し条件 y=1034、SP も同様）。作るときは、ボタンと同じ枠の中か、すぐ下の1行に入れる。
2. 予約サイトの1ページは重い。JS が最大の荷物になる（じゃらんnet 2.78〜7.60MB／DICE 8.64〜14.42MB、どちらも PC。DICE は公演ページでも Stripe 1.1MB・reCAPTCHA 0.8MB を読む）。予約エンジン・決済・ボット対策のスクリプトは、選択を始めるまで読まない形を目指す。
