# 横断ルール：予約のサイトをまたいで効いていること

2つ以上のサイトで同じ結果になったことだけを、番号つきで書く。1サイトだけの発見は `types/<slug>.md` に置く。
書くときは（〇〇と△△で確認）のように、元になったサイトを添える。

1. 払い戻し・キャンセルの条件は、最初の予約ボタンより下に置かれがちで、実測すると買う枠から遠い（じゃらんnet：ボタン y=683 に対し規定 y=3070／DICE：枠 y=547 に対し条件 y=1034、SP も同様／TableCheck：予約フォームの主なプランに規定が無く、一部のプラン説明の※1行と、ページ最後の「関連する規約とポリシー」だけ／Othership：時間割の行と枠の詳細に無く、規約ページと店ページの料金カードの「12 HOUR LATE CANCEL WINDOW」だけ／星野リゾート：プランの中にあるが、閉じた10pxの「キャンセル規定 ∨」（70×25）の中で、開くと「カートに入れる」の上に面が重なる／Shakespeare's Globe：公演ページに返券・払い戻しが無く、48時間前までのクレジット返券と1枚 £2〜£3 の手数料はチケットの規約のページだけ／チームラボプラネッツ：入場日時・時間枠・枚数の3画面に「キャンセル」「返金」「変更」が0語。返金不可と「入場の2時間前まで・3回」の日時変更は、展示ページの 22,675px 下の FAQ とヘルプだけ／Resy：店ページに無く、枠を押したパネルで初めて「before Wed, Nov. 11 at 5:30pm」と出る。パネルの中ではボタン y=886 より上の y=246 だが、規定の無い店は行ごと消え、FAQ は「確認メールを見て」）。逆の例が Relux で、宿のページのプランの行に「2026/11/15までキャンセル無料」（12px）を予約ボタン 146×48 と同じ行に置き、プランのページでは日付と円の表を予約ボタン（y=1,955）より上の y=1,266 に出す。作るときは、ボタンと同じ枠の中か、すぐ下の1行に入れる。 Philharmonie de Paris：席の画面は合計 136.00 EUR まで出すが、払い戻し不可と48時間前までの交換（手数料10%）は仏語の CGV だけで、席の画面には右下の規約のリンク（y=1,011）しかない。 ポケットコンシェルジュ：予約の枠に取り消し・支払いの語が0。規定は店の説明文の中（「3営業日前より50%・1営業日前より100%」）か、「こちら」→ `/term#cancel-policy` が `/terms` に転送されて節の印が消える19ページの PDF（SP はダウンロードのリンクだけ）。 Lost Shore Surf Resort：升を押したモーダル（992×572）に取り消しの語が0。FAQ の取り消しは泊の規定（14日・28日）だけで、活動の「7日以内は移動も返金も無し」は、本文1行の Cove T&Cs のページの先の11ページの PDF の 2.3 だけ。 白井屋ホテル（tripla）も Relux と同じ逆の例で、プランの箱に「2026/12/02 23:59まで(現地時間) はキャンセル料がかかりません。」を予約ボタンより上（PC y=728 に対しボタン y=1,082、SP y=1,118 に対し 2,047）に置く。ただし段の表（8日前無料〜当日100%）は押したモーダルで、日付と円は無い。 Barbican：券売り場の升にも公演ページにも返券・払い戻しの語が0。「24時間前までにクレジットへ・1枚 £3」は券の案内の開閉「Returning your tickets」の中だけ。
2. 予約サイトの1ページは重い。JS が最大の荷物になる（じゃらんnet 2.78〜7.60MB／DICE 8.33〜14.42MB／TableCheck 一覧・店 13.94〜15.60MB／Othership 6.13〜12.89MB、どれも PC。TableCheck は3ページとも JS 1本 10.04MB（転送 2.38MB）。DICE は公演ページでもヘルプでも Stripe 1.1MB・reCAPTCHA 約840KB×3 を読む。Othership は時間割の無い規約ページでも予約エンジンの /js 322KB を読む／星野リゾート 3.83〜19.88MB、規定のページでも JS 3.1MB。宿ページは動画 6.73MB と Google Fonts の CSS 2.1MB が JS と並ぶ／Shakespeare's Globe 3.65〜13.30MB、JS は全ページ 1.44MB 前後で、いちばん重いのは写真（ツアーの JPEG 8.9MB・トップの GIF 2,985KB）。クッキーの帯 OneTrust 850KB は規約の入口でも読む／チームラボプラネッツ：入場日時の画面は 0.84MB と軽いが、枠を押した先の枚数の画面で reCAPTCHA 839KB×3、展示ページは動画で PC 103.84MB／Resy 19.48〜23.94MB、5ページとも JS 11.5MB・全都市の JSON 3.39MB・Stripe 1.15MB・reCAPTCHA 836KB を FAQ でも読む／Relux 8.64〜48.66MB、5ページとも AWS SDK 2,827KB・Stripe 1,147KB・圧縮なしの style.css 1,143KB を読み、一覧は宿の写真 351枚を lazy なしで 36.8MB）。予約エンジン・決済・ボット対策のスクリプトは、選択を始めるまで読まない形を目指す。 ポケットコンシェルジュ 5.45〜10.36MB、5ページとも JS 4.57〜6.38MB（共通 734.js 1,341KB・Stripe 1,149KB・同意管理 521KB）で、規約の PDF のページでも Stripe を読む。
3. 空きの記号（○・▲・×）の凡例は、記号のそばに出ていない（じゃらんnet PC：凡例は「?」の中／TableCheck の詳細：○・×・定休日に凡例なし／星野リゾート：凡例は2か月のカレンダーの下／チームラボプラネッツ：PC は凡例がカレンダーの下で、ひと月の大半を占める ○ が凡例に無い。SP だけ凡例が上／Resy：店のカレンダーは空き・破線の一部・取り消し線の休み・#cacaca の受付外の4つで、凡例が無い／Relux：部屋の空室カレンダーの ○×、プランの升の「¥65,522〜」と「-」のどちらにも凡例が無い）。作るときは、カレンダーの上に凡例を常に1行で出す。 逆の例がポケットコンシェルジュで、店の暦の面のすぐ下に「利用可能な座席（金の輪）・ウェイティングリスト」の凡例を 12px で常に出す。
4. 日付は「開始」と「終了」の2つで URL に持つと、1日でも範囲でも同じ形で引き継げる（DICE：`?from=…&until=…`／TableCheck：`date_from=…&date_to=…`、1日でも両方入る／Shakespeare's Globe：選んだ日＋7日を `unixDay` の範囲で問い合わせるが、URL は `#day` だけで残らない／Relux：`checkin=2026-11-19&checkout=2026-11-20`、宿へのリンクも同じ2つを持つ）。 Philharmonie de Paris は逆の例で `?startDate=2026-11-19` だけを持ち、範囲は作れない。 1日を選ぶ店ページでも、予約の状態を全部 URL に持つと同じ枠を開ける（ポケットコンシェルジュ：`partySize・date・time・serviceType・seatingType` の5つ、一覧は `date・time`）。（白井屋ホテル〔tripla〕：`checkin=2026/12/10&checkout=2026/12/11` に adults・order・type・room_type_codes まで URL に持ち、部屋のページからその部屋で絞って開ける）
5. 枠や部屋を選んでも、その場に合計の値段が出ない。値段は別の画面にある（TableCheck：予約フォームで数量を選んでも合計が無い／Othership：時間割の行にも枠の詳細にも値段が無く、料金は別ページの券／星野リゾート：空室カレンダーで日を選んでも「大人2名(1泊) ／名 50,750円〜」と1名の値段だけで、合計 154,300円は部屋のプランで初めて出る／Resy：一覧にも時刻の格子にもパネルにも金額が無く、$〜$$$$ の段だけ）。逆の例が Relux で、カレンダーでチェックインを押した時点（350ms）で下に「合計 ¥80,026~」、アウトで「合計 ¥150,841~」を出す。作るときは、枠を選んだ時点で人数を掛けた合計（税込）を、選んだ枠のすぐ下に出す。 Philharmonie de Paris も逆の例で、席の画面で枚数を選ぶと「TOTAL 2 TICKETS 136.00 EUR」の帯が画面下に貼り付く（PC 1038×72・SP 358×104）。 ポケットコンシェルジュ：人数を替えてもコースの行は「¥22,000 / 人」のままで、税サ込はコースの詳細の面だけ。 Lost Shore Surf Resort：モーダルで大人 £70・子ども £60 の数量を変えても通信も合計も無く、合計はカートの先。
6. 残りが少ないことを、見た目で区別していない（TableCheck：満席の時刻を #bfbfbf on #f7f7f7＝1.72:1 で残すだけ／Othership：残り3席の「3/20 Open」も「59/64 Open」と同じ 14px 700 #474747／Shakespeare's Globe：70行中1行の「LIMITED TICKETS」は値段の行と同じ 13px 700 #222、SP は 8.32px で値段 11.52px より小さい）。チームラボプラネッツは逆の例で、残りの少ない行だけ「残り28枚」を #f04137 で足す（ただし 3.81:1 で、境目は不明）。作るときは、残りを数字で出し、少ない枠（定員の2割以下など）は色と言葉を替える。 Philharmonie de Paris は「Last tickets」の言葉と丸で区別するが、色が緑 #238044 で「良い」の側に見え、数も出さない。 Lost Shore Surf Resort：既定の色（波の段）では残り1も13も同じ見た目。availability に切り替えると3色になるが、境目は画面に無い定員との比で、Manoeuvres の残り4が緑と赤に分かれる。 Barbican は色で区別する例で、残りが定員の1割未満の回だけ升を青 #006ebd の「Last few」にする（空きは緑 #427b42）。ただし数は出さず、残り2席と114席が同じ見た目。
7. 残りの部屋・席の数は、少ないときだけ数字で出し、多いときは印か何も出さない（じゃらんnet：○＝10室以上・▲＝4〜9・1〜3室は数字／星野リゾート：1〜5室は「残りN室」、6室以上は値段だけ。375升のうち104升に帯／チームラボプラネッツ：26行のうち2行だけ「残り28枚」「残り48枚」、カレンダーは ○ と △ の印だけ）。作るときは、数字を出す境目を決めて（宿なら5室前後）、凡例にその境目を書く。（白井屋ホテル：暦の日の右上に宿全体の残りが1〜9の日だけ 13×13 の札、カードには「残り4部屋！」）
8. 宿の日付は、PC で2か月を並べて選ばせる（じゃらんnet：jQuery UI `numberOfMonths: 2`／星野リゾート：横断検索 870×481・空室カレンダーも2か月）。1か月の DICE・TableCheck は1日を選ぶ予約。チームラボプラネッツは1日を選ぶ入場だが、升に日ごとの値段を入れて PC で2か月を並べる。Relux も検索の面・部屋の空室カレンダー・プランの料金カレンダーの3つとも2か月。作るときは、泊まりの範囲を選ぶ画面と、日で値段が変わる画面は2か月、値段が同じで1日を選ぶ画面は1か月。
9. SP では、予約の入口を画面下に固定の帯にする（DICE：最安値とボタン 74px／TableCheck：71px／星野リゾート：「1泊1名 37,550円〜」と空室検索 77px）。Shakespeare's Globe の SP は逆に画面の上（ヘッダー直下 y=70）に 370×54 で貼り付き、頭のボタンが消えてから出す。チームラボプラネッツの SP は入場日時・枚数の画面に固定の帯が無く、展示ページは頭の 82×30 のボタンだけ。Relux の SP はプランのページだけ下に日程・合計・予約の帯があり、宿のページには無い（一覧の下の固定の帯 390×72 はログイン・会員登録）。作るときは、帯に値段の単位（1泊1名・合計など）と、日付を選んだあとは合計を出す。 Philharmonie de Paris の SP は紺の帯 80px に Book my ticket 370×60 を最初の画面から画面下に固定（帯に日付・値段は無い）。 ポケットコンシェルジュの SP も下に 390×58 の帯と「予約」374×42 を貼り、押すと全画面の予約の面（帯に日付・値段は無い）。
10. チケットの値段は、手数料を含めた額で出し、含んだことを値段のそばで1文に言う（DICE：「From £36.05」の下に「The price you'll pay. No surprises later.」／Shakespeare's Globe：「£89–£29*」の * で1注文 £3・1枚 £1 を含むと DETAILS と公演日の表の上で言う、立ち見は除く）。作るときは、合計の下に「うち手数料 ○円」の1行を出し、手数料の無い席種はそう書く。 逆の例が Barbican で、公演ページは「From £34 (including a £4 transaction fee)」、券売り場の升は券面の「from £30」で、同じ回の最安が £4 ずれる。一覧と詳細で同じ規則にそろえる。
11. 日で値段が変わるなら、カレンダーの升に「その日のいちばん安い値段〜」を入れ、何の値段か（大人1名・1泊1名など）を升の列のそばに書く（星野リゾート：空室カレンダーの升 61×61 に「50,750円〜」、単位は「大人2名(1泊) ／名」／チームラボプラネッツ：升 51×67 に「4,400~」12px、注記「カレンダー日付の下の表示はエントランスパス（大人）の料金」）。升の最安値は、その日の中のどの枠・部屋の値段かを、選んだ先の一覧で同じ数として見せる（プラネッツの 4,400 は 20:30 の枠の値段）。Relux：プランの升 67.6×88.8 に2名1泊「¥65,522〜」13.5px、単位は升の外に無く、面の下の「2名」と「合計」から読むしかない。
12. 飲食の一覧は、カードにその日の空き時刻を4つのボタンで並べ、残りは「+」「…」で店へ送る（TableCheck：118×36・4つ＋「+」／Resy：101×40・4つ＋「…」、SP 3つ）。時刻のボタンが店の名前より強い色の主役になる（TableCheck #292929・Resy #336dde の塗り）。作るときは、時刻の下に席の種類か残りの数を1行で添え、時刻を指定されたらその前後の4つを出す。 逆の例がポケットコンシェルジュで、カードに時刻を出さず、日付と時刻を入れると件数だけが減る（97件→53件）。どの時刻が空いているかは店を開くまで分からない。
13. 宿の取り消し料は、取り消す日の段ごとの表でプランの中に出す（星野リゾート：40〜8日前10%・7〜0日前30%・不泊100%・事務手数料1,000円を率で／Relux：「2026年11月18日 (1日前)の0時〜 ¥48,630 (宿泊料金の50%)」の形で日付・円・率を4行）。星野リゾートは閉じた見出しの中、Relux は開いたまま予約ボタンより上。作るときは、選んだ日程と人数で計算した日付と円を主に、率を従にして、無料の期限を表の上に1行で大きく書く。
14. チケットの一覧・回の行には、席種ごとの値段を並べる。最安値1つより多くを一覧の段で見せる（Shakespeare's Globe：公演日の表の行に「PRICES: £89.00 - £29.00* | STANDING: £5.00」／Philharmonie de Paris：カードに「€13｜€27｜€42｜€62｜€78｜€88」、売り切れた席種だけ取り消し線）。DICE は「From £36.05」の1つだけ。作るときは席種ごとの値段を並べ、売り切れは消さずに線で残し、読み上げにも「売り切れ」と伝える。
15. 押せない部品（ボタン・人数・時刻）を薄い色にするだけで、押せない理由を言わない（DICE：買うボタンが #666／#333＝2.2:1 と ◆ だけ／チームラボプラネッツ：7つの同意を入れるまで「次へ」が opacity .2 だけ／Relux：料金カレンダーの「決定」がアウトを選ぶまで淡い紺だけ／ポケットコンシェルジュ：日を替えると枠の min〜max の外の人数が disabled、#342f28 on #1d1a16＝1.31:1、11/5 は2名だけ・11/12 は2〜4名と言う文が無い）。作るときは 3:1 以上の字で残し、そばに理由と次の手（「この日は2名だけ。3名からは11/12」）を1行で出す。

16. 在庫が場所・部屋・波で分かれるなら、分かれた単位ごとに別の行・別の升にして、同じ時刻を並べる（Othership：Free Flow を Sauna 1〜6 の部屋ごとに別の行、20:00〜21:45 に15分おきの8本／Lost Shore Surf Resort：Reef Left と Reef Right を別の週の升（423px）にし、教室も Beginner・Lessons Left・Right で別の升）。作るときは、単位の名前を升の頭の帯に書き、PC では横に、SP ではタブで切り替える（Lost Shore の SP は6つを横に 2,531px 並べ、最初の升も土日が切れる）。
17. 枚数・人数の上限を、その枠の残りの数にする（Philharmonie de Paris：席の画面の select の上限が残りの 1・3・4／Lost Shore Surf Resort：大人と子どもの数量の合計が「10 entries left」に届くと両方の＋が disabled、opacity .65）。どちらも上限の理由を数量のそばに書いていない（Lost Shore は頭に「10 entries left」20px）。作るときは、残りの数を数量の欄の横に書き、上限に届いたら「残り◯なので、ここまで」と1行出す。
18. 宿の取り消し無料の締めは、入りの日から逆算した日付（と時刻）でプランの行に1行で出すと、予約ボタンより上に来る。日付を替えたら締めも替える（Relux：「2026/11/15までキャンセル無料」12px が予約 146×48 と同じ行／白井屋ホテル：「2026/12/02 23:59まで(現地時間) はキャンセル料がかかりません。」、12/12 泊にすると 12/04 に動く）。段の表まで日付と円で出しているのは Relux だけ。
19. 「残りわずか」の段は、残りの数ではなく定員との比で決まっていて、その境目は画面に出ていない（Lost Shore Surf Resort：availability の色は定員との比で、同じ残り4が緑にも赤にもなる／Barbican：ソースで `t/capacity*100<10`、1,152席の115席以下で「Last few」、凡例なし）。作るときは境目を1つに決め、凡例に「定員の1割（○席）以下」と数で書き、少ない回は数も出す。
