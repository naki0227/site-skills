### じゃらんnet（https://www.jalan.net/ ・2026-10-24・予約サービス）
条件：2026/11/20から1泊・1部屋・大人2名・神奈川県 横須賀・三浦。題材の宿はセントラルホテル 横須賀（yad308664）。

- **データ**：宿ページは `Hotel`（address・aggregateRating）と `BreadcrumbList`。`Offer`・`checkinTime` なし。プラン詳細は JSON-LD なし。
- **重さ（PC / SP）**：トップ 5.69 / 9.47MB、一覧 6.27 / 3.17MB、宿 7.60 / 4.65MB、プラン一覧 5.22 / 3.23MB、プラン詳細 2.78 / 3.07MB。JS が最大の荷物。SP トップで Google マップ JS（1.4MB）を読む。

### 星野リゾート（https://hoshinoresorts.com/jp/ ・2026-10-28・ホテル・旅館の自社予約。75軒の施設横断検索と、宿ごとの予約エンジン）

## 真似る型
（見本：じゃらんnet・星野リゾート。2つの見本で同じだったことを先に、どちらか1つの型は出典を添えて書く。）
1. **PC の日付は2か月を並べる**（じゃらんnet：jQuery UI `numberOfMonths: 2`／星野リゾート：870×481・升 55×55）。チェックインを押したらアウトの選択に進め、泊数を出す（じゃらんnet「宿泊日数：N泊」）。SP は全画面で月を縦に並べ、下に固定の「決定」（星野リゾート 390×60）。
2. **残りは少ないときだけ数で出し、多いときは印か何も出さない**（じゃらんnet：○10室以上・▲4〜9・1〜3は数字／星野リゾート：1〜5室は「残りN室」、6以上は出さない）。0は「満室」で、升は消さずに残す。
3. **空室カレンダーの升に空きの印を入れ、値段も一緒に入れる**（じゃらんnet：月の空室カレンダーに ○▲数字×／星野リゾート：61×61 に ▲×ー と1泊1名の最安値）。人数・泊数を替えたら升の値段も替える。凡例はカレンダーの上に1行で（じゃらんnet PC は「?」の中、星野リゾートはカレンダーの下）。
4. **一覧の1件に、チェックインから数日分の値段と残りを並べ、押すとその日付で部屋へ**（星野リゾート：5日分の升 79×66、押すと `checkIn=…&stay=1`）。
5. **値段は「合計（泊数・人数・税込）」を主役に、1名を従に**（じゃらんnet：「1泊 大人2名 合計(税込)」）。星野リゾートは一覧からカレンダーまで1名の値段だけで、合計はプランで初めて出る——真似しない。
6. **連泊の割引は泊数の選択肢の中に書く**（星野リゾート「1泊 (連泊優待で最大15%off)」）。
7. **キャンセル規定はプランの中に、取消日と率の表で**（星野リゾート：40〜8日前10%・7〜0日前30%・不泊100%）。開く仕掛けにせず、予約ボタンのすぐ上に日付と金額で出す（じゃらんnet はプラン詳細まで出さず、星野リゾートは閉じた10pxの見出しの中）。
8. **絞り込みの項目に件数、価格帯は分布の棒つき**（星野リゾート：チップ全部に件数・価格帯は棒31本）。
9. **予約できる期間の制限をカードに1行**（星野リゾート「1泊のご予約は30日前より承ります」）。

## 反面教師
- キャンセル規定・支払方法を、予約ボタンより下・プラン詳細まで出さない（じゃらんnet）。値段の横に短く出す。
- 空室カレンダーの日付を押すたびにページ全体を読み直す（じゃらんnet、約0.9MB）。
- PC と SP で日付の初期値やプラン件数の数え方が違う（じゃらんnet：PC 日付未定・23件、SP 今日から・131件）。
- 地図へ移ると並べ替えが消える（じゃらんnet）。
- 一覧の値段の単位をカードに書かない（星野リゾート：「137,564円〜」が1泊1名なのは絞り込みの中にだけ）。升の列の下に「1泊1名・税込」を1行。
- キャンセル規定を10pxの閉じた見出しにし、開くと予約ボタンに重なる（星野リゾート：「キャンセル規定 ∨」70×25、カート 160×40 の上に面）。
- 一覧で選んだ日付を、宿のページへのリンクと宿のページの「空室検索」が持たない（星野リゾート。升から行くときだけ持つ）。
- 白字の主ボタン #00a0cb（3.05:1）、「残り1室」#fff on #ef9600（2.32:1）、満室 #b1b1b1 on #f0f0f0（1.88:1）（星野リゾート）。
- 宿ページ 19.88MB（動画 6.73MB・フォントの CSS 2.1MB）、横断検索で地図の JS 1.4MB を最初に読む、reduce の指定0（星野リゾート）。
