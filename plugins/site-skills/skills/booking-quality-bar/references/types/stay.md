## 見本の実測

### じゃらんnet（https://www.jalan.net/ ・2026-10-24・予約サービス）
条件：2026/11/20から1泊・1部屋・大人2名・神奈川県 横須賀・三浦。題材の宿はセントラルホテル 横須賀（yad308664）。

- **検索フォーム**：PC の順は キーワード → 種別 → 日付 → 目的（出張／旅行）→ 部屋・大人・子供 → 都道府県・エリア → こだわり6つ。SP は エリア(必須) → 日付 → 部屋・大人・子供 → こだわり。部屋 1〜10・大人 1〜9 のセレクト。
- **日付**：PC は2か月（jQuery UI `numberOfMonths: 2`、チェックイン `minDate "+1D"`・`maxDate "+365D"`）。初期は「日付未定」にチェック。チェックインを押すとアウトが翌日に入り、開いたまま。アウトを押すと閉じて「宿泊日数：N泊」。SP は1か月を枠内に表示、初期値は今日〜明日、チェックインを押すと翌日アウトで閉じる。泊数表示なし。
- **一覧**：並べ替え PC 4つ（おすすめ・安い・高い・エリア）、SP 2つ＋地図。どれもページ読み直し。値段は「1泊 大人2名 合計(税込)」が主、「1名」が従。PC は宿の下にプラン行（29軒でプランへのリンク82本）、SP はプラン1件＋「すべての宿泊プランをみる（N件）」。行ごとに「あと3部屋」「空室わずか」。SP は条件の帯（エリア・件数・日付・泊数・人数）を画面下に固定（46px）。地図は別ページで、並べ替えは引き継がれなかった。
- **詳細**：PC タブ9つ・右上に「空室検索・予約」・写真の左に月の空室カレンダー。SP タブ5つ・写真直下に合計の最安値と「宿泊プランを探す」。SP に固定の予約ボタンは無い。
- **空き**：○＝10室以上、▲＝残4〜9、1〜3は数字、×＝なし。PC は月表示で凡例は「?」の中、SP は7日の帯＋月表示モーダル（凡例は常に表示）。日付を押すとページを読み直す（約0.9MB）。プラン一覧はプラン→部屋タイプの入れ子、列は 大人1名(税込)・合計(税込)・残室。
- **予約前の不安**：IN/OUT 時刻はプラン一覧で見える。キャンセル規定（1日前20%・当日80%・無連絡100%）・支払方法・予約金はプラン詳細で初めてそろい、最初の「予約へ進む」より下（PC y=683 に対し 3070、SP y=422 に対し 3271）。
- **データ**：宿ページは `Hotel`（address・aggregateRating）と `BreadcrumbList`。`Offer`・`checkinTime` なし。プラン詳細は JSON-LD なし。
- **重さ（PC / SP）**：トップ 5.69 / 9.47MB、一覧 6.27 / 3.17MB、宿 7.60 / 4.65MB、プラン一覧 5.22 / 3.23MB、プラン詳細 2.78 / 3.07MB。JS が最大の荷物。SP トップで Google マップ JS（1.4MB）を読む。
