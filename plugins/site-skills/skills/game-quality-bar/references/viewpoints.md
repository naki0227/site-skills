# ゲーム・エンタメで見ること・決めること

解剖でも、作るときでも、この順に見る。作るときは、それぞれに「どうするか」を1行で決めてから書き始める。
解剖で裏づけた値は `types/<slug>.md` に、どのサイトの値かを添えて書く。このファイルには問いだけを置く。

- **最初の画面**：キービジュアル／トレーラー／プレイ画面のどれを見せるか、ロゴと発売日・対応機種の位置、音が鳴るか。
- **動画**：自動再生か、音の初期値、ポスター画像、YouTube などの埋め込みを押すまで読まない工夫、動画の重さ。
- **キャラクター**：一覧から1人への切り替え（タブ／モーダル／別ページ）、立ち絵とプロフィールの配置、ボイス・声優表記、URL で1人を指せるか。
- **ナビ**：固定か、ページ内の章へのジャンプ、世界観に合わせた部品（ボタン・枠・カーソル・効果音）。
- **買う・登録する**：対応機種・価格・発売日・パッケージ版とダウンロード版・特典の並べ方、ストアボタンの位置と数、事前登録の段取り。
- **表記**：年齢区分（CERO・IARC など）と権利表記の位置、多言語・地域の切り替え。
- **会場と当日**（催し）：会場図（区画・番号・凡例・SP の大きさ・PDF か HTML か・雨の日の配置）、出店者・出演者の一覧（件数・並べ方・絞り込み・1件の情報・0件）、雨天（判断の時刻・段階・出す場所・変わる場所）、行き方と駐車場（路線・台数・満車の目安・シャトル・混む時刻）、自分の回る順を持てるか。
- **安全と重さ**：点滅や激しい動きを止められるか（reduced-motion）、動画・画像の合計、共通ヘッダーやアカウントの JS。
