# 横断ルール：ゲーム・エンタメのサイトをまたいで効いていること

2つ以上のサイトで同じ結果になったことだけを、番号つきで書く。1サイトだけの発見は `types/<slug>.md` に置く。
書くときは（〇〇と△△で確認）のように、元になったサイトを添える。

1. 演出用の動画・連番画像を置いたページが、他のページより桁違いに重い。最初の画面に要らない分まで読み込み時に取る（Pokémon LEGENDS Z-A：top 32.95MB／下層 2.25〜5.81MB、Lollapalooza：top PC 21.21MB／下層 5.44〜12.51MB、ウマ娘：動画のある about PC 57.95MB／top 8.98MB、Wicked: For Good：360° 写真の部屋 PC 72〜74MB／購入 3.59MB、ペルソナ３ リロード：top PC 36.99MB／ニュース 6.42MB、ゼンレスゾーンゼロ：top PC 116.06MB／下層 14.88〜17.69MB で、65人ぶんの絵 149枚・92.1MB をローディングの7秒で取る、SAKAMOTO DAYS：top PC 13.61MB／下層 3.58〜4.32MB で、差の9MB は YouTube 4,761KB と Adobe Fonts）。重いのは top とは限らないので、歩く全ページの通信量を先に測る。
2. 動画を2本置くと、いま使わない方も読み込み時に取得している（Z-A：`<video>` 2本とも読み込み時に取得し PC 6.1MB、Lollapalooza：PC 幅で PC 用・SP 用の mp4 を両方取得し 8,392KB、P3R：PC でも SP でも PC 用・SP 用の4本 9,335KB）。使う方だけ、見える区画に来てから読む。
3. スクロールに連動した演出（仮想スクロール・ピン留め・文字の点灯）を、`prefers-reduced-motion` で止めていない（Z-A：止まらなかった、Lollapalooza：CSS・ページ内とも 0件、ウマ娘：サイトの CSS・JS に 0件で 10画面のピン留めと 50s の流れが止まらない、陶炎祭：0件で 8秒ごとのフェードと12秒の拡大が続く、Wicked：CSS に1件〔ボタンの transition だけ〕・JS に0件で WebGL の地図・部屋と shake が止まらない、P3R：5ページの CSS・JS に0件で、ローディング・動画・約11,200px の横送りが reduce でも同じ、ゼンレスゾーンゼロ：5ページの CSS に0件で、入口の背景動画 9.5MB とローディングの連番が reduce でも動く、SAKAMOTO DAYS：CSS・JS とも0件で、10秒のビジュアル送り・29.42s の英字の帯・追いかける輪が reduce でも続く）。作るときは reduce のとき静止版（全部を並べて見せる）に切り替える。
4. 動画の `preload="metadata"` は節約にならない。JS や autoplay ですぐ再生するので全部取る（Lollapalooza：metadata でも 4,303KB を取得、ウマ娘：metadata でも 10秒で 44.2MB、ループで取り直して15秒で 104.5MB）。節約するなら poster を出して押してから再生する。
5. キャラクターは1人1URLで、一覧と詳細を別ページにする（Z-A：`/characters/250227_02/`、ウマ娘：`/character/specialweek`、ゼンレスゾーンゼロ：`/character?id=166651` で題も人名、SAKAMOTO DAYS：`/character/?chara=taro` で題も人名）。前後の人物へのリンクは差が出た（Z-A・SAKAMOTO DAYS は無し、ウマ娘は左右の矢印で端で一周）ので、作るときは付ける。
6. 一覧や見出しを画像にすると、読み上げ用の文が抜けるか間違う（Lollapalooza：ラインナップ・時間割の画像の alt が空、ウマ娘：グループ見出しの画像の2つ目の alt が「ウマ娘」、ストアボタン10個に alt なし、Wicked：動画のサムネイル16枚の alt が空、P3R：版の値段8つが alt 空の画像、ニュースのカードの画像25枚に alt なし、Primavera Sound：出演者と日付を焼き込んだトップのポスターの alt が画像の URL）。文字で組むか、画像ごとに中身どおりの alt を書く。
7. 当日いちばん引かれる情報（ラインナップ・時間割・会場図の店番）を、Web の文字ではなく画像か PDF だけに置いている（Lollapalooza：ラインナップ・時間割が画像で alt 空、陶炎祭：店番 1〜211 と会場図が 1.69MB の PDF だけで、SP で読むには約9.8倍の拡大、Primavera Sound：トップの出演者はポスター画像だけで、文字の一覧〔A-Z〕へは本文からリンク0本）。作るときは HTML で組み、PDF・画像は印刷用の写しにする。
8. 買う先（ストア・店）のボタンが、キーボードと読み上げで使えない（ウマ娘：ストアボタン10個に alt なし、Wicked: For Good：店のタイル12個が `div`〔tabIndex −1〕で Tab が届かない、P3R：販売店へのリンク117個が alt 空の画像だけで名前なし、ゼンレスゾーンゼロ：ストア7つが `p` の中の alt 空の img でリンクでも button でもない）。作るときは店ごとに本物のリンクにし、店の名前と行き先（新しいタブ）を名前に書く。
9. 年齢区分を購入・登録の導線の近くに置いていない（Z-A：仕様表だけ、ウマ娘：歩いたページに無い、Wicked：歩いたページに無く Filmratings.com へのリンクだけ、P3R：フッターの SPEC だけで /stores/ には0件）。値段・版の横と全ページのフッターに置く。手本はゼンレスゾーンゼロ（最初の画面のストアの左・入手のモーダル・フッターの3か所に ESRB。ただし img で alt 空なので、文字で組む）。
10. 人物ごとに色を1つ決め、一覧と詳細の面をその色で塗っている（ウマ娘：要素の style の `--color-main`／`--color-sub`、P3R：13人に11色の `.chara.bgN` と同じ色の詳細の波、ゼンレスゾーンゼロ：`.character-color-block` の style と章札の地、SAKAMOTO DAYS：5陣営の色を一覧の名前とホバーの面に）。どれもその色の上の文字が足りない人がいる（ウマ娘：白い札 2.44〜2.73、P3R：白い組の英文 1.11〜2.74、ゼンレスゾーンゼロ：濃い #222122 の章札が Sunbringer #3953ac で 2.30・Severian #1566b8 で 2.77）。文字色を1つに決めると、明るい人か暗い人のどちらかで必ず落ちる。作るときは色を面にだけ使い、文字は濃い色にする（P3R の #1d384a なら全色で 4.46 以上）。
11. 人物を切り替える・開く部品が、名前のある button・リンクになっていない（ウマ娘：ボイス・衣装が `<a href="#">` で名前なし、P3R：一覧のカードが href の無い `a`、Switch 2 版はサムネが `li`、ゼンレスゾーンゼロ：陣営・同じ陣営のサムネ・マイク・言語の札が全部 div で tabIndex −1、SAKAMOTO DAYS：トップのビジュアルのサムネ3つが `javascript:` の a で、中の img に alt なし）。キーボードでは人物を選べない。作るときは `button`（`aria-pressed`）か1人1URL のリンクにし、名前を付ける。
12. BGM・音のファイルを、音を選ぶ前に取っている（Wicked: For Good：音の2択の前に BGM 8,762KB、ゼンレスゾーンゼロ：全ページで mp3 3,429KB を取り、ページのどこかを1回クリックすると音量 0.8 で鳴り始める。入口は同じ 6,088KB を2回）。作るときは音のボタン（入／切を文字で）を押してから取って鳴らし、動画を開いている間は 0 に下げる。
13. 公式サイトのページに見出し（h1）が無い（ウマ娘：5ページとも h1 なし、ゼンレスゾーンゼロ：5ページとも h1〜h3 が 0、Primavera Sound：Barcelona のトップと /en/news に h1 なし。トップの最初の見出しは券種の h3）。章の題・人名を見出しの要素で組む（人名は h1）。
14. フォーカスの枠を消している（Lollapalooza：991px 以下で `*:focus{outline:none}`、SAKAMOTO DAYS：全幅で `*{outline:none}`・`*:focus{outline:none}`、Tab の12手とも枠なし）。作るときは `:focus-visible` に地との比 3 以上の色で 3px の枠を付ける。
15. 決まった幅を基準に全体を縮める作りで、SP の本文が 16px を大きく割る（ペルソナ３ リロード：`width=750` の viewport で本文が実寸 10.4px、SAKAMOTO DAYS：750px 基準の vw で本文 12.48px・小見出し 6.24px）。作るときは本文を px（16px 以上）で固定し、画面比で縮めるのは見出しだけにする。
16. 中身が来ても、決まった秒数の演出が終わるまでローディング画面を出し続ける（ウマ娘：毎ページ 3.1〜3.8s、ゼンレスゾーンゼロ：入口の約7秒、SAKAMOTO DAYS：top は window の load の後に 2.2s で PC 7.39s・SP 7.96s、下層も 2.4s）。作るときは最初の1回だけ、load を待たずに短く。
17. 読み込んで数秒後に、告知・登録のポップアップで画面を覆い、閉じても次の訪問でまた出す（ペルソナ３ リロード：6.4秒のローディングのあと 1280×790・毎回、閉じるは href なしの a。Primavera Sound：Cookie を拒否しても 7.0〜7.3秒で Braze の全画面 iframe、閉じるは名前なしの button）。作るときは出さないか、1回閉じたら同じ訪問では出さず、閉じるは名前のある button・Esc で閉じる。
18. トップの動画を、押す前に YouTube の埋め込みごと読み込んで無音で流す（SAKAMOTO DAYS：読み込み 4.0s で iframe_api と埋め込み、controls:0・PC 4.8MB。Primavera Sound：`autoplay=1&mute=1&controls=0` の iframe を load で作り YouTube だけで PC 5,113KB、1組のページも autoplay=0 なのに埋め込みは作る）。作るときは題・長さを文字にした poster を置き、押してから埋め込む。
19. 全ページ共通の重いもの（フォント・決済やチャットの SDK・全部入りの JS／CSS）を、要らないページでも毎回読む（Lollapalooza：どのページも JS 3.2〜3.5MB〔Zendesk 1.2MB・Mailchimp 0.7MB〕、ペルソナ３ リロード：Noto Sans JP の OTF 8.97MB を毎ページ、Primavera Sound：文字だけのページでも JS 13MB〔Stripe 3.7MB〕と CSS 2.9MB で 16.7MB）。作るときは決済は BUY を押してから、フォントは分割、CSS は使うクラスだけ。
