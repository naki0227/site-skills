# 横断ルール：ゲーム・エンタメのサイトをまたいで効いていること

2つ以上のサイトで同じ結果になったことだけを、番号つきで書く。1サイトだけの発見は `types/<slug>.md` に置く。
書くときは（〇〇と△△で確認）のように、元になったサイトを添える。

1. トップページは下層ページより桁違いに重い。最初の画面に要らない動画・画像を読み込み時に取ってしまう（Pokémon LEGENDS Z-A：top 32.95MB／下層 2.25〜5.81MB、Lollapalooza：top 17.22MB／下層 5.44〜6.23MB）。測るのは top の通信量を先に。
2. 動画を2本置くと、いま使わない方も読み込み時に取得している（Z-A：`<video>` 2本とも読み込み時に取得し PC 6.1MB、Lollapalooza：PC 用・SP 用の mp4 を PC・SP のどちらの幅でも両方取得）。使う方だけ、見える区画に来てから読む。
