# 横断ルール：ゲーム・エンタメのサイトをまたいで効いていること

2つ以上のサイトで同じ結果になったことだけを、番号つきで書く。1サイトだけの発見は `types/<slug>.md` に置く。
書くときは（〇〇と△△で確認）のように、元になったサイトを添える。

1. 演出用の動画・連番画像を置いたページが、他のページより桁違いに重い。最初の画面に要らない分まで読み込み時に取る（Pokémon LEGENDS Z-A：top 32.95MB／下層 2.25〜5.81MB、Lollapalooza：top PC 21.21MB／下層 5.44〜12.51MB、ウマ娘：動画のある about PC 57.95MB／top 8.98MB）。重いのは top とは限らないので、歩く全ページの通信量を先に測る。
2. 動画を2本置くと、いま使わない方も読み込み時に取得している（Z-A：`<video>` 2本とも読み込み時に取得し PC 6.1MB、Lollapalooza：PC 幅で PC 用・SP 用の mp4 を両方取得し 8,392KB）。使う方だけ、見える区画に来てから読む。
3. スクロールに連動した演出（仮想スクロール・ピン留め・文字の点灯）を、`prefers-reduced-motion` で止めていない（Z-A：止まらなかった、Lollapalooza：CSS・ページ内とも 0件、ウマ娘：サイトの CSS・JS に 0件で 10画面のピン留めと 50s の流れが止まらない）。作るときは reduce のとき静止版（全部を並べて見せる）に切り替える。
4. 動画の `preload="metadata"` は節約にならない。JS や autoplay ですぐ再生するので全部取る（Lollapalooza：metadata でも 4,303KB を取得、ウマ娘：metadata でも 10秒で 44.2MB、ループで取り直して15秒で 104.5MB）。節約するなら poster を出して押してから再生する。
5. キャラクターは1人1URLで、一覧と詳細を別ページにする（Z-A：`/characters/250227_02/`、ウマ娘：`/character/specialweek`）。前後の人物へのリンクは差が出た（Z-A は無し、ウマ娘は左右の矢印で端で一周）ので、作るときは付ける。
6. 一覧や見出しを画像にすると、読み上げ用の文が抜けるか間違う（Lollapalooza：ラインナップ・時間割の画像の alt が空、ウマ娘：グループ見出しの画像の2つ目の alt が「ウマ娘」、ストアボタン10個に alt なし）。文字で組むか、画像ごとに中身どおりの alt を書く。
