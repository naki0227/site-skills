# 横断ルール：ゲーム・エンタメのサイトをまたいで効いていること

2つ以上のサイトで同じ結果になったことだけを、番号つきで書く。1サイトだけの発見は `types/<slug>.md` に置く。
書くときは（〇〇と△△で確認）のように、元になったサイトを添える。

1. 演出用の動画・連番画像を置いたページが、他のページより桁違いに重い。最初の画面に要らない分まで読み込み時に取る（Pokémon LEGENDS Z-A：top 32.95MB／下層 2.25〜5.81MB、Lollapalooza：top PC 21.21MB／下層 5.44〜12.51MB、ウマ娘：動画のある about PC 57.95MB／top 8.98MB、Wicked: For Good：360° 写真の部屋 PC 72〜74MB／購入 3.59MB、ペルソナ３ リロード：top PC 36.99MB／ニュース 6.42MB）。重いのは top とは限らないので、歩く全ページの通信量を先に測る。
2. 動画を2本置くと、いま使わない方も読み込み時に取得している（Z-A：`<video>` 2本とも読み込み時に取得し PC 6.1MB、Lollapalooza：PC 幅で PC 用・SP 用の mp4 を両方取得し 8,392KB、P3R：PC でも SP でも PC 用・SP 用の4本 9,335KB）。使う方だけ、見える区画に来てから読む。
3. スクロールに連動した演出（仮想スクロール・ピン留め・文字の点灯）を、`prefers-reduced-motion` で止めていない（Z-A：止まらなかった、Lollapalooza：CSS・ページ内とも 0件、ウマ娘：サイトの CSS・JS に 0件で 10画面のピン留めと 50s の流れが止まらない、陶炎祭：0件で 8秒ごとのフェードと12秒の拡大が続く、Wicked：CSS に1件〔ボタンの transition だけ〕・JS に0件で WebGL の地図・部屋と shake が止まらない、P3R：5ページの CSS・JS に0件で、ローディング・動画・約11,200px の横送りが reduce でも同じ）。作るときは reduce のとき静止版（全部を並べて見せる）に切り替える。
4. 動画の `preload="metadata"` は節約にならない。JS や autoplay ですぐ再生するので全部取る（Lollapalooza：metadata でも 4,303KB を取得、ウマ娘：metadata でも 10秒で 44.2MB、ループで取り直して15秒で 104.5MB）。節約するなら poster を出して押してから再生する。
5. キャラクターは1人1URLで、一覧と詳細を別ページにする（Z-A：`/characters/250227_02/`、ウマ娘：`/character/specialweek`）。前後の人物へのリンクは差が出た（Z-A は無し、ウマ娘は左右の矢印で端で一周）ので、作るときは付ける。
6. 一覧や見出しを画像にすると、読み上げ用の文が抜けるか間違う（Lollapalooza：ラインナップ・時間割の画像の alt が空、ウマ娘：グループ見出しの画像の2つ目の alt が「ウマ娘」、ストアボタン10個に alt なし、Wicked：動画のサムネイル16枚の alt が空、P3R：版の値段8つが alt 空の画像、ニュースのカードの画像25枚に alt なし）。文字で組むか、画像ごとに中身どおりの alt を書く。
7. 当日いちばん引かれる情報（ラインナップ・時間割・会場図の店番）を、Web の文字ではなく画像か PDF だけに置いている（Lollapalooza：ラインナップ・時間割が画像で alt 空、陶炎祭：店番 1〜211 と会場図が 1.69MB の PDF だけで、SP で読むには約9.8倍の拡大）。作るときは HTML で組み、PDF・画像は印刷用の写しにする。
8. 買う先（ストア・店）のボタンが、キーボードと読み上げで使えない（ウマ娘：ストアボタン10個に alt なし、Wicked: For Good：店のタイル12個が `div`〔tabIndex −1〕で Tab が届かない、P3R：販売店へのリンク117個が alt 空の画像だけで名前なし）。作るときは店ごとに本物のリンクにし、店の名前と行き先（新しいタブ）を名前に書く。
9. 年齢区分を購入・登録の導線の近くに置いていない（Z-A：仕様表だけ、ウマ娘：歩いたページに無い、Wicked：歩いたページに無く Filmratings.com へのリンクだけ、P3R：フッターの SPEC だけで /stores/ には0件）。値段・版の横と全ページのフッターに置く。
10. 人物ごとに色を1つ決め、一覧と詳細の面をその色で塗っている（ウマ娘：要素の style の `--color-main`／`--color-sub`、P3R：13人に11色の `.chara.bgN` と同じ色の詳細の波）。どちらもその色の上の白い文字が足りない（ウマ娘：札 2.44〜2.73、P3R：組の英文 1.11〜2.74）。作るときは色を面にだけ使い、文字は濃い色にする（P3R の #1d384a なら全色で 4.46 以上）。
11. 人物を切り替える・開く部品が、名前のある button・リンクになっていない（ウマ娘：ボイス・衣装が `<a href="#">` で名前なし、P3R：一覧のカードが href の無い `a`、Switch 2 版はサムネが `li`）。キーボードでは人物を選べない。作るときは `button`（`aria-pressed`）か1人1URL のリンクにし、名前を付ける。
