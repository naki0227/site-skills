- [ ] （家庭用・PC）版を選ぶと、値段（地域・税の別）・同梱物・店の名前のあるリンクが一緒に替わる。売っていない機種は消すだけでなく理由と代わりの版を書く（Baldur's Gate 3 は同梱物と行き先は替わるが値段0、Physical Deluxe で Steam・GOG が黙って消える）
- [ ] 版と機種のボタンは button（aria-pressed）で Tab が届き、店のリンクに「Steam で Standard を見る（新しいタブ）」の名前がある（Baldur's Gate 3 は版が href の無い a、店は SVG だけ）
- [ ] 年齢区分を地域ごとに出すなら、文字で書き、購入の版の横にも置く（Baldur's Gate 3 はフッターに4地域、img に alt なし）
- [ ] 固定のヘッダーは、最初の画面を過ぎたら地を敷いて本文と重ならない（Baldur's Gate 3 は地なしで、人物・種族の絵に金の字が重なる）
- [ ] CMS の空欄・仮の項目（「[Missing Label]」「Subpage 1」）が公開のページに残っていない（Baldur's Gate 3 の /merch とナビ）
- [ ] 区画ごとの動画は見える区画に来てから1本ずつ、または押して流す。同じ動画を2回取っていない（Baldur's Gate 3 の /about は7本 88,269KB、1本は2回）
