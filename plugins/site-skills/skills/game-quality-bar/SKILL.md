# ゲーム・エンタメ品質基準

目標は、最初の数秒で世界観に引き込み、「どんな作品か→だれが出るか→どこで遊べる・見られるか→買う／登録する」が迷わず進む水準。
見た目をコピーするのではなく、解剖した**流れと判断**を、作るものに合わせて翻訳する。

## 使い方
1. 下の表で、作るものに一番近い下位タイプを選ぶ。
2. `references/viewpoints.md` を読み、作る画面ごとに、そこに並ぶ問いへの答えを先に決める。
3. 選んだ下位タイプの `references/types/<slug>.md` を読み、見本の実測値を出発点にする。見本がまだ無い下位タイプは、近い下位タイプの見本を使う。
4. `references/rules.md`（サイトをまたいで効いていること）に反していないか確かめながら作る。
5. 仕上げに `references/checklist.md` を全部確かめる。

|---|---|---|---|

| スマホゲーム | iOS・Android のゲーム | ウマ娘 プリティーダービー 公式ポータル（2026-10-26）、ゼンレスゾーンゼロ 海外公式（2026-10-29） | `types/mobile.md` |

| イベント・ライブ | フェス、ライブ、展示、eスポーツ、陶器市・祭り・マルシェ | Lollapalooza（2026-10-25）、笠間の陶炎祭（2026-10-26） | `types/event.md` |

## このスキルの範囲
- 作品の公式サイトのページのつながり（世界観・キャラ・ニュース・購入）。ゲーム本体の画面は対象外。トップ1枚の見た目は `lp-quality-bar` の「エンタメ・ゲーム」の型。
- どのスキルを使うか迷ったら `site-skills` で選ぶ。
