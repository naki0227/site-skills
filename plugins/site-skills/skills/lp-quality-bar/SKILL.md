# LP品質基準

目標は「テンプレっぽさゼロ、ひと目で手間がかかっているとわかる」水準。
作るものの雰囲気（業種・トーン）に合わせて**型を翻訳**する。見た目をコピーするのではない。

## 使い方
1. 下の表で、作るものに一番近い雰囲気を1つ選ぶ（迷ったら2つまで。混ぜるのは配色と動きのどちらか片方だけ）。
2. `references/common.md`（2つ以上のサイトで確かめた共通の基礎）を読む。
3. 選んだ雰囲気の `references/types/<slug>.md` を読み、その数値を出発点にする。値を並べて比べたいときは `references/compare.md`。
4. `references/rules.md`（サイトをまたいで効いていること）に反していないか確かめながら作る。
5. 仕上げに `references/checklist.md` を全部確かめる。

## このスキルの範囲
- 見るのは**トップ（1枚目のページ）の見た目と軽さ**。商品一覧・購入・予約・料金表などの「流れ」の設計は、その種類のスキル（例：`ec-quality-bar`）を使う。どれを使うか迷ったら `site-skills` で選ぶ。
- 実装に使える部品は `lp-anatomy` リポジトリの `patterns/` にある（依存なし。`data-mood` で雰囲気を切り替える）。無くてもこのスキルだけで作れる。
