# 横断ルール：共通で効いていること（13サイト）
1. **色の主役は1つ**：多色でも「どこで使うか」が決まっている（セクション単位／ロゴ3色／1点だけ／グラデだけ）。
2. **文字は極端な対比**：太細か、巨大と極小か。中途半端なサイズを並べない。
3. **イージングは1〜2種類に固定**し、時間を3段階にする。
4. **常に動く主役は1つ**（紙吹雪／スライダー／3D／波）。他は控えめ。
5. **ブランド固有の遊びを1つ**（1OOth／揺れ／ZERO→EIGHT／GDPカウンタ）。
6. **軽さは画像で決まる**：重い2サイトは画像が8割超、軽い2サイトは写真をほとんど使わない。
7. **ホバーはマウス端末だけに閉じる**（とらやで追加）：`@media (hover:hover) and (pointer:fine)` の中に書くと、スマホでホバー状態が残らない。
8. **寸法の割合を保つ**（teenage engineering で追加）：余白・文字・行間を「基準幅の比率」で書くと、画面が変わっても見た目の割合が崩れない。ただしズームは止めず、文字に下限をつける。
9. **色を「内容」に持たせる**（ほぼ日で追加）：UIを白・灰・1色の青に絞り、色は記事（ヒーローの地色・サムネ）だけに持たせる。内容が毎日変わるサイトほど、枠は変えない。
10. **動きは「足す」**（Apple で追加）：動きなしの完成形を先に作り、動きは許される環境（reduced-motion でない・saveData でない）にだけ足す。登場の値は1つの型（.15sずつ・opacity .9s・30px/.7s）に固定する。
11. **手触りを1つのカーブで統一する**（スプラトゥーン3で追加）：登場もホバーも「少し行き過ぎて戻る」（Back.easeOut／`cubic-bezier(.34,1.3,.64,1)`）に揃えると、ゲームのような弾力が全体に出る。ただし跳ねは reduced-motion・saveData で必ず止める（本家は止めていない）。
12. **暗い面は、色でなく白の透明度で重ねる**（Linear で追加）：地を4段の灰にし、境界・ホバー・カードの面は白の 5 / 8 / 12 / 15% で作る。色を足すと面が増えて騒がしくなる。アクセントは1色、状態の色は小さな点だけ。
13. **色を「章」のデータに持たせ、境目で見せる**（星野リゾートで追加）：UIを白・`#1a1a1a`・灰に絞り、章ごとに「地の色＋文字色（黒／白）」を1組持たせる。境目は波で切る。季節・特集が変わっても枠は作り直さない。白文字は地との比を計算してから（2.1〜2.5:1は不足）。
14. **線と影を1つの値で統一する**（Oatly で追加）：枠は 1px の黒、影は 2px 2px 0 の黒（ぼかさない）に決め、押したら影の分だけ沈める（沈む量＝影の量）。窓・帯・カード・ボタン・Cookie まで同じ線で組むと、色が無くても世界観が出る。動画を主役にするなら、reduced-motion・saveData で止める（本家は止めず、PC 16.4MB・SP 11.5MB）。
15. **写真が主役なら、UI は暗室にして「沈める」動きだけにする**（teamLab で追加）：地は同じ色味の黒3段（`#0e0f0e`・`#181a18`・`#222422`）、文字は白と `#999`、有彩色は写真だけ。ホバーは写真を `.6`・1.05倍に 1s で沈め、題を .36s で浮かせる。カーブは1つ（easeOutCubic）をトークンにして手で書かない（本家は不正な `cubic-bezier` が7か所）。最初に見える1枚は lazy にせず `fetchpriority="high"`（本家は表紙も lazy）。
16. **「止める」をページの部品にする**（Graza で追加）：常に動くもの（動画・帯・回転・Lottie）があるなら、スキップリンクの次と脚注に「動きを止める」ボタンを置き、`html` のクラス1つで CSS の動きを、同じ関数で video と Lottie を止め、選択を localStorage に残す。初期値は reduced-motion（と saveData）。ただし止めても読み込みは減らない：閉じたメニューや画面外の動画は `preload="none"` にして、見えたときに読む（本家は止まったサムネ4本で 36.4MB）。
17. **押せる物の約束を1つにして、地は淡く保つ**（povo で追加）：文字は1色（`#333`）、章の地は淡い色（`#f4f4f4`・`#fffed4`・`#fff1dc`）にして、濃い色はボタンと札だけに使う。ボタンは「角丸 50px・真下 3px の同系の濃い影・右端の丸い矢印」を全部で同じにし、押したら影の分だけ沈める。章の境目は四角い箱でなく、幅140% の楕円の弧で切る。色は文字に使わない（本家の「いろいろ」は 1.83〜2.40:1）。自動の送りには点の横に止めるボタンを置く。
18. **説明の代わりに、題材の「途中の状態」を回す**（Family で追加）：機能を文で並べず、カードやスマホの枠の中で、題材の本物の画面の途中（バックアップ中・送金の待ち・残り分数）を数秒ごとに進める。章の題・色・ボタンは全部同じ値に固定し、違いは実演だけに持たせる。動画や実演を複数置くなら1本ずつ順に進め、進んでいる1枚だけ大きくする（1.1倍）。ただし実演は画面の外・タブが裏・reduced-motion・saveData で止め、動画は表示の2倍の大きさで `preload="none"`（本家は止めず、1170×2532 を 209px で9本先読みして PC 27.86MB）。
19. **題材の「見本の束」を表紙にして、ほかは黙る**（竹尾で追加）：素材の会社なら、色見本・小口・見本板そのものを表紙の全面に置き、文字はロゴだけにする。UI は墨・灰・面・白の4つ、有彩色の UI は0、押せる物の変化は opacity だけ、矢印は線、題は「英字｜和文」を同じ大きさで。色を足さないほど、見本の色が主役になる。ただし表紙の画像は HTML に書いて先読みさせ（本家は JS で後から入れて表紙全体が透明のまま待つ）、和文フォントは使う字だけの woff2 にする（本家は OTF 3本で 7.04MB）。
20. **文字の会社は、約物を「文中の一語」にして飾る**（Locomotive で追加）：写真が主役でない題材なら、住所・電話・メール・見出しの頭と尻に、箱に組んだ数字・座標・矢印を一語の高さで挟む（Locomotive の「514｜524/5678」）。飾りは `aria-hidden`、読み上げには意味の文字を別に置く。描くのは SVG か私用領域の文字にして、絵文字の文字コードは使わない（書体が届かないと色つきの絵文字が並ぶ。画面で確かめた）。色は白と黒、区切りは 2px の横罫だけにして、グリフ以外に飾りを足さない。
21. **町の店は、店の中より先に町を見せ、最初の画面は営業時間にする**（小杉湯で追加）：銭湯や豆腐店のように「通う店」なら、表紙の写真の上に営業時間・定休・料金だけを置き、申し込みのボタンは作らない。物語は町の写真と縦書きの短い段落（16px・字間 .25em・1段 40〜130字）を交互に置き、写真の並べ方を毎段変える（80/20 を左右入れ替え、間に 12列の格子、締めは全幅）。視差は「中心からの距離×.1、±100px で止め、中を 1.1倍」で控えめにして、見えている物だけを計算し、reduced-motion・saveData では止める（本家は止めず、画面外も毎回計算）。縦書きでも SP の本文は 16px（本家 13px）。
22. **分野は同じ形の札にし、違いは地の色の4変数だけに持たせる**（LPAS で追加）：仕事の分野（住宅・学校・公共など）が入口なら、札の形・題の大きさ・ボタンを全部同じにして、`data-` の属性1つで「地・淡い地・文字・反対の文字」を切り替える。文字は地ごとに白か墨を選び 4.5:1 以上を計算で確かめる（LPAS 4.73〜9.99:1）。横に流すのはページの1区間だけにし、SP と reduced-motion では縦に積む（本家は reduce でも横に動く）。見えない縮図に原寸を読まない（本家は 3.08MB）。
23. **動きの時間は CSS 変数にまとめ、reduced-motion はその変数を 0s にする1か所で止める**（SmartHR 採用サイトで追加）：`--duration-short/hover/reveal/expand` のように用途で4〜5個に名前を付け、`@media (prefers-reduced-motion:reduce){:root{--duration-*:0s}}` で全部止める。JS の動き（canvas・WAAPI・開閉）も `getComputedStyle` でこの変数を読めば、止め忘れが出ない（本家は 142枚の canvas・アコーディオン・メニューまでこれで止まる）。色の豊かさは canvas の網点（Bayer 8×8、1画素＝1粒で `pixelated` に拡大）に閉じ込めると、UI は墨・白・1色のまま、画像を使わずに面が作れる。ただし文字のグラデ（`background-clip:text`）で「まだ読んでいない行」を白くすると、地との比が足りない（本家 2.15:1）。
24. **表紙は「今週のお知らせ」を大きさを変えて重ね、行動は青い文字1つに決める**（Ableton で追加）：製品の宣伝1枚の代わりに、新版・値段・講座の3枚を 24分の1の単位で大 14/24・中 8/24（+4/24 下げる）・中 8/24（−1/24 重ねて手前）に置き、`min(4.16667vw,66.667px)` の1つの変数で 1600px から止める。毎週中身が替わっても、格子は替えない。色は記事の種類の札（文字は黒で 8.86:1 以上）と写真に持たせ、押せる文字は純粋な青 `#0000ff`（8.59:1）の1色、ボタンの形は作らず、2px の下線と線で描いた › にする。ただし乗ったときの変化は足し（本家は0）、写真の上の淡い文字は写真の明るさを測ってから、`srcset` には `sizes` を書く（本家は 360px の枠に 1440px）。
25. **商品が1つなら、ロゴの線を後ろの地にして、手前は一行ずつ語る**（nome で追加）：ロゴの線を `position:fixed; z-index:-1` の canvas に立体（または帯）で描き、スクロールの比でカメラを `1 − 比 × .9` まで寄せる。手前は一文だけを 1.1 秒で入れ替え、効き目を並べない。言葉の主題（視点のずれ・寝かせる）は写真の向き（90°）で見せる。ただし、後ろの絵は表紙を過ぎるまで描かず、reduced-motion・saveData では 3D のライブラリを読まずに静止の絵にし、独白には「止めて全部読む」を置く（本家は reduce 0、閉じたメニューのために 1.8MB の書体の一覧を読む）。
26. **記事が増えていく特設は、目標の数に対する進み具合を、表紙と記事の番号の両方に同じ数え方で置く**（日東紅茶100周年で追加）：周年の「100のアクション」や連載のように中身が増えていくなら、表紙に「13/100」のような数字を1つ大きく置き（番号用の書体で 112px・行間 .65）、記事カードの題の横にも同じ数え方の番号を新しい順に振る（`<ol reversed>`）。一覧そのものが目標までの道のりになり、説明の文が要らない。色の多い写真は、記事ごとの地色と額縁の形でそろえ、文字と線は1色に寄せる。その1色が地と 4.5:1 に届かないなら、大きな字と線だけをその色にし、本文は同じ色相の暗い色に下げる。大きさを vw だけで書かず、`max(14px, …vw)` で下限を付ける。
27. **強調は太さでなく書体で、1文の中で切り替える**（Lando Norris で追加）：見出し・宣言を太いサンセリフの大文字（wdth を詰めた 660〜750）で組み、強調したい語だけセリフ＋アクセントの色に替える（`<strong>` に書体と色を持たせる）。ロゴも2書体の2段にすると、同じ約束がページの頭から脚注まで続く。出すときは行ごとに色の帯で拭く（clip .6s＋帯 .6s、行の遅れ .15s）。アクセントの色は暗い地の上だけで使い、明るい地では文字にしない（ライムと白は 1.05:1）。
28. **写真が多い店は、回さずに四辺形で切って積み、動きはコマ落としにする**（GRAN BURGER で追加）：表紙の写真を `rotate` で散らすと角がばらばらになり文字が乗らない。四隅の座標を `clip-path:polygon()` で書き、隣と同じ傾きの辺を向かい合わせると、斜めのすき間が1本の帯になって一語を重ねられる。積む・崩すは `steps(8)` のコマ落としにすると、なめらかな動きより紙の切り貼りに見える。ただし読み込みの最低待ち時間は作らず（本家は 5 秒）、届いた物から表紙を出し、reduced-motion では最後の形だけ置く（本家はここを守っている）。
