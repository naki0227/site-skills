# 横断ルール：共通で効いていること（13サイト）
1. **色の主役は1つ**：多色でも「どこで使うか」が決まっている（セクション単位／ロゴ3色／1点だけ／グラデだけ）。
2. **文字は極端な対比**：太細か、巨大と極小か。中途半端なサイズを並べない。
3. **イージングは1〜2種類に固定**し、時間を3段階にする。
4. **常に動く主役は1つ**（紙吹雪／スライダー／3D／波）。他は控えめ。
5. **ブランド固有の遊びを1つ**（1OOth／揺れ／ZERO→EIGHT／GDPカウンタ）。
6. **軽さは画像で決まる**：重い2サイトは画像が8割超、軽い2サイトは写真をほとんど使わない。
7. **ホバーはマウス端末だけに閉じる**（とらやで追加）：`@media (hover:hover) and (pointer:fine)` の中に書くと、スマホでホバー状態が残らない。
8. **寸法の割合を保つ**（teenage engineering で追加）：余白・文字・行間を「基準幅の比率」で書くと、画面が変わっても見た目の割合が崩れない。ただしズームは止めず、文字に下限をつける。
9. **色を「内容」に持たせる**（ほぼ日で追加）：UIを白・灰・1色の青に絞り、色は記事（ヒーローの地色・サムネ）だけに持たせる。内容が毎日変わるサイトほど、枠は変えない。
10. **動きは「足す」**（Apple で追加）：動きなしの完成形を先に作り、動きは許される環境（reduced-motion でない・saveData でない）にだけ足す。登場の値は1つの型（.15sずつ・opacity .9s・30px/.7s）に固定する。
11. **手触りを1つのカーブで統一する**（スプラトゥーン3で追加）：登場もホバーも「少し行き過ぎて戻る」（Back.easeOut／`cubic-bezier(.34,1.3,.64,1)`）に揃えると、ゲームのような弾力が全体に出る。ただし跳ねは reduced-motion・saveData で必ず止める（本家は止めていない）。
12. **暗い面は、色でなく白の透明度で重ねる**（Linear で追加）：地を4段の灰にし、境界・ホバー・カードの面は白の 5 / 8 / 12 / 15% で作る。色を足すと面が増えて騒がしくなる。アクセントは1色、状態の色は小さな点だけ。
13. **色を「章」のデータに持たせ、境目で見せる**（星野リゾートで追加）：UIを白・`#1a1a1a`・灰に絞り、章ごとに「地の色＋文字色（黒／白）」を1組持たせる。境目は波で切る。季節・特集が変わっても枠は作り直さない。白文字は地との比を計算してから（2.1〜2.5:1は不足）。
14. **線と影を1つの値で統一する**（Oatly で追加）：枠は 1px の黒、影は 2px 2px 0 の黒（ぼかさない）に決め、押したら影の分だけ沈める（沈む量＝影の量）。窓・帯・カード・ボタン・Cookie まで同じ線で組むと、色が無くても世界観が出る。動画を主役にするなら、reduced-motion・saveData で止める（本家は止めず、PC 16.4MB・SP 11.5MB）。
15. **写真が主役なら、UI は暗室にして「沈める」動きだけにする**（teamLab で追加）：地は同じ色味の黒3段（`#0e0f0e`・`#181a18`・`#222422`）、文字は白と `#999`、有彩色は写真だけ。ホバーは写真を `.6`・1.05倍に 1s で沈め、題を .36s で浮かせる。カーブは1つ（easeOutCubic）をトークンにして手で書かない（本家は不正な `cubic-bezier` が7か所）。最初に見える1枚は lazy にせず `fetchpriority="high"`（本家は表紙も lazy）。
16. **「止める」をページの部品にする**（Graza で追加）：常に動くもの（動画・帯・回転・Lottie）があるなら、スキップリンクの次と脚注に「動きを止める」ボタンを置き、`html` のクラス1つで CSS の動きを、同じ関数で video と Lottie を止め、選択を localStorage に残す。初期値は reduced-motion（と saveData）。ただし止めても読み込みは減らない：閉じたメニューや画面外の動画は `preload="none"` にして、見えたときに読む（本家は止まったサムネ4本で 36.4MB）。
17. **押せる物の約束を1つにして、地は淡く保つ**（povo で追加）：文字は1色（`#333`）、章の地は淡い色（`#f4f4f4`・`#fffed4`・`#fff1dc`）にして、濃い色はボタンと札だけに使う。ボタンは「角丸 50px・真下 3px の同系の濃い影・右端の丸い矢印」を全部で同じにし、押したら影の分だけ沈める。章の境目は四角い箱でなく、幅140% の楕円の弧で切る。色は文字に使わない（本家の「いろいろ」は 1.83〜2.40:1）。自動の送りには点の横に止めるボタンを置く。
18. **説明の代わりに、題材の「途中の状態」を回す**（Family で追加）：機能を文で並べず、カードやスマホの枠の中で、題材の本物の画面の途中（バックアップ中・送金の待ち・残り分数）を数秒ごとに進める。章の題・色・ボタンは全部同じ値に固定し、違いは実演だけに持たせる。動画や実演を複数置くなら1本ずつ順に進め、進んでいる1枚だけ大きくする（1.1倍）。ただし実演は画面の外・タブが裏・reduced-motion・saveData で止め、動画は表示の2倍の大きさで `preload="none"`（本家は止めず、1170×2532 を 209px で9本先読みして PC 27.86MB）。
19. **題材の「見本の束」を表紙にして、ほかは黙る**（竹尾で追加）：素材の会社なら、色見本・小口・見本板そのものを表紙の全面に置き、文字はロゴだけにする。UI は墨・灰・面・白の4つ、有彩色の UI は0、押せる物の変化は opacity だけ、矢印は線、題は「英字｜和文」を同じ大きさで。色を足さないほど、見本の色が主役になる。ただし表紙の画像は HTML に書いて先読みさせ（本家は JS で後から入れて表紙全体が透明のまま待つ）、和文フォントは使う字だけの woff2 にする（本家は OTF 3本で 7.04MB）。
