# タイポグラフィの制作会社（文字が絵になる。制作会社・デザイン事務所・印刷所・書体や文字が売りの店のトップ）
Locomotive（locomotive.ca、モントリオールの制作会社）の実測。写真や色でなく、自社の書体と罫で「文字そのもの」を絵にする型。
- 色：トークンは `--color:#000` と `--color-bg:#fff` の2つだけ（CSS の白 38回・黒 28回）。テーマは2つの入れ替え。有彩色の UI はメニューの地 `#312dfb`（白 7.24:1）とテーマの赤 `#da382e`（白 4.58:1）だけ。色は動画・3D・写真が持つ。
- 線：区切りは全部 2px の横罫（SP 1px、`--border-size`）。箱・角丸・影は0。最初の3画面の枠線 8。
- 文字：見出しは細い縦長のセリフ（PP Locomotive New Light → 代わりは Instrument Serif、和文は Shippori Mincho）、本文は Helvetica Now Display 400（→ Inter Tight／Zen Kaku Gothic New）。weight は 400 の1つ、字間は全部 0。大きさは root 15px（1600px 以上 17・2000〜19・2400〜21）に rem を掛ける5段：注記 15・本文 26/1.2・h1 70/1.1・huge 110/1（7.64vw）。SP は 15・18・36・40。
- **文中のグリフ**：自社書体の「絵文字の文字コードの位置」に、箱に組んだ数字（OPS｜DES/DEV、514｜524/5678）・座標・矢印・郵便の箱を入れ、HTML に `aria-hidden` の span で書く。住所・電話・メール・見出しの頭と尻に一語として挟まる。読み上げ用に「(QC)」「@」「電話番号」を `u-screen-reader-text` で別に置く。真似るなら SVG か私用領域（U+E000〜）の文字で（下の反面教師）。
- 構成：表紙（全面の動画、h1 70px・差の合成）→ 要約（4列の中に 5:7 の 3D、言葉を `calc(100% + 20px)` で絵の外に浮かべ、リンクは 2px の罫の上に「語＋→」）→ 作品6行（各 152px、110px の題を中央）→ 70px の一文＋社員の 3D と 26px の本文 → Extras（「題（数）」を両端に、左6列に小題・右6列に罫の行）→ フッター（3列の罫の見出し、最後に住所を 70px で）。押せる物はボタンの形にせず、全部文字のリンク。
- 動き：easeOutCubic `(.215,.61,.355,1)` 46回・easeOutQuint `(.23,1,.32,1)` 9回、.3s と .15s が中心。ヘッダーは下へで隠れ上へで出る（transform .2s）、表紙の上は差の合成。表紙の背景は `position:fixed` で −25vh・黒 .75 まで重なる。**作品の行は、乗ると題の2語の間に width 0→1.5em の窓**（開く .45s／閉じる .2s）、窓の画像はピクセルから（幅 128px の canvas に 8→16→32→48→96→128px、各 100ms）。乗ると文字を4回まぜて .25s で戻す。「All Work」の両脇の約物を 2s で4コマ明滅。GSAP・three.js・Lenis。
- **反面教師**：グリフを絵文字の文字コードに入れたので、書体が届かないと色つきの絵文字（茶の丸・トイレの男女・ふくろう）が住所に並ぶ（`font-display:swap` の間も）。表紙の動画は SP にも 1080p（7.69MB）で、reduced-motion でも再生する（JS の reduced-motion 0）。3D（指輪 694KB・社員 0.7〜1.1MB・Draco 245KB）を見る前に読み、スクロールせずに 12.3MB。閉じた窓のための reCAPTCHA 836KB。タッチ端末では作品の窓が出ない（`hover:none` で `display:none`）。写真 1440×1640 を 440px で。
- 部品：`data-mood="type"` トークン、`.lpa-gap`（言葉の間に開く窓）、`LPA.pixelIn(canvas,{paint})`（ピクセルから）、`LPA.shuffle(el)`（文字をまぜる）、`LPA.scrollHeader` に `hideOnDown`。
- **AIっぽさとの線引き**：「(13)」のような数を題の右端に同じ大きさで置くのは手本どおり（小さな番号の飾りとは別）。英字の短いラベル（Featured work・Articles）は本文と同じ 26px で、字間を広げた小さな英字にしない。グリフの箱は文中の一語の高さまでで、段落を囲む箱にしない。
