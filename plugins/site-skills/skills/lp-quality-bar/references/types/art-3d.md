# アート・3D（ポートフォリオ、ブランド、ギャラリー、制作会社）
- 色は「地＋墨」の2色だけ。階調は墨の透明度（.05/.1/.3）で作り、差し色は1点。
- 文字は巨大（11〜18vw）と極小（13〜16pxの大文字）の2極。中間サイズを作らない。見出しは段違いに配置。
- イージングは入りと出で分ける。時間は .3 / .6 / 1.4s の3段。GSAPなら `power2.out` 中心、強調だけ `back.out`/`elastic.out`。
- 場面転換は1種類に統一（例：角丸の黒パネルがせり上がる）。
- 慣性スクロールは lerp .05〜.075。独自カーソルは対象の上でだけ中身が `scale(0→1)` .3s。
- 3DはDraco圧縮glTF、1モデル100KB前後、テクスチャ5〜20KB、環境マップは数KBのwebp。質感は画像でなく材質で。
- `prefers-reduced-motion`・低スペック判定（`is-low`）で軽いモードに落とす。
- 3Dでも3.95MB：画像合計は約160KBで、重さの大半はJS。写真に頼らないから軽い。
