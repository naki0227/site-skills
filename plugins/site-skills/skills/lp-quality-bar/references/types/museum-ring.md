# 博物館の特設・収蔵品を輪に浮かべ、朗読で聞かせる（暗室の展示）
Mouthful of Dust（mouthfulofdust.slv.vic.gov.au、State Library Victoria、three.js＋Lottie、2026-11-15 実測）の型。Ned Kelly の遺品5点を3Dスキャンで宙に浮かべ、物ごとに作家の文章の朗読を字幕つきで聞かせる。縦に流れるページではなく、1画面（`body{overflow:hidden}`）に場面（幕）を重ねて入れ替える。
- **最初の1画面は題より先に、誰の物かへの敬意**：黒の全面に白の3段落（22px／32px・300・字間 1.1px・幅 893px）と下の矢印1つ。題材が人の土地・遺品・寄贈品なら、題の前に1画面を割く。
- **読み込みは何を取っているかと残り時間を言う**：「Fetching intro audio… → intro images… → textures… → camera animations… → Processing environment…」と「about 2 minutes → 0 sec」。終わってから ENTER（150×56px）を opacity 1s で出す。表紙の写真は 4s で 1→1.05 に寄る。ただし先に読むのは最初の場面の分だけ（本家は 53.6MB を先に読む）。
- **収蔵品は輪に5等分（`torusPosition` 0／.2／.4／.6／.8）、止まった1つにだけ札**：札は作家名 26px 400 大文字・字間 2.6px＋物の名 26px 300＋PLAY。回る間は消し、止まったら 750ms・easeInOutCubic で opacity と blur を 0→1。下に物の線画アイコン5つと現在の点 7px。左右の矢印・キー・アイコンのどれでも同じ1つへ。
- **札は目録の項目をデータで持つ**（`data.json`）：作家・紹介・リンク・物の名・題・作り手・材質・登録番号・寄贈・解説・代替テキスト・輪の位置・カメラの動き。札・情報の面・読み上げ（`Looking at: 作家 – 物`）を1件から作る。
- **写真の焦点はファイル名に**：`…-x50-y25.jpg` を読んで `background-position`。17枚とも x20〜60・y15〜75。
- **朗読は字幕と再生バーで**：字幕 22px／32px・300・字間 1.1px・下から 110px、明るい写真の上は #00000080 の帯。再生バーは左右のキーで5秒、字幕・音声解説（AD）・音のボタンを同じ列に。字幕は既定で出す。
- **設定を1枚に**：画質3段・Gaussian splat・フレームレート3段・字幕・Reduce motion（初期値は `prefers-reduced-motion`、`:root[data-reduced-motion]` で 1ms）・キーの反転・画面のボタン・高コントラスト（文字の後ろに `.25rem` の黒い板）・音量2つ・操作の早見表・「WCAG 2.2 AA」。遅い端末を見つけると画質を下げて知らせる。
- 色：#fff 32回・#000 24回と、その透明度だけ。有彩色の UI は0、色は物（茶・銹・紙）が持つ。ボタンは1種類（1px #fff・地 #ffffff1a・角丸 4px・20px 大文字・字間 3.4px・乗る／フォーカスで #fff3 .3s）。重ねる面は `blur(20px)`、区切りは白50% の 1px の罫だけ。
- 文字：proxima-nova 1書体の 300／400／500。大きさ 10〜48px の9段、大文字は字間 .1〜.25em、本文 17px／26px・300・字間 .02em（SP 15px／19px）。
- 動き：three.js（KTX2・DRACO・meshopt）、Lottie（題 110KB）。CSS は ease-in-out 1つで .2／.3／.5／.75／1／2／4s。
- 重さ：開いた時点 2.32MB、ENTER 前に PC 53.6MB・SP 52.6MB、全場面 57.2MB（音 22.4MB・3D 18.4MB・JPEG 10.0MB）。朗読5本 15.7MB と手紙の3D 13.2MB を表紙で読む。
- **反面教師**：CSS は `Proxima Nova`、Adobe Fonts のキットは `proxima-nova` で、Webフォントが1本も届かない（全文字が端末の標準、ボタンは Arial）／ENTER 前に 53.6MB・saveData を見ない／progressbar の `aria-valuenow` が 23 のまま／`body *{user-select:none}` で解説も字幕も写せない／著作権 10px・SP の一文 15px／19px／CSS に `prefers-reduced-motion` が無く、帯 15s は止まらない／写真の寄りを `background-size` で毎フレーム。
- 部品：`patterns/` の `LPA.focal()`（ファイル名の焦点）・`LPA.namedLoader()`（何を読むかを言う読み込み）・`.lpa-hc`（高コントラストの板）。
- **作例で確かめた翻訳**（汐見町郷土資料館「灯台守の五つの道具」・架空、2026-11-15）：敬意の1画面は寄贈した3家族への謝辞と勤務の年・点数に、輪のメニューは灯台のレンズが回る輪に、札は資料台帳（資料番号・年代・材質・寸法・寄贈）に、朗読は当直日誌の一行の字幕に、ページで唯一動く物は本物の灯質 Fl(2)W 15s（15秒に2回光る）にした。表紙は群青 #2445a8 の地に、旧レンズの写真を切り抜いて群青と白の2色にした主役と、レンズの輪にそって弧に置いた「汐見埼灯台」、灯質の丸い札1つ。暗室ではなく明るい群青にしたのは、店・施設の作例は明るくする決まりのため。
