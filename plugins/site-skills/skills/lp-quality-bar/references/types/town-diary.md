# 町の店・縦書きの写真日記（銭湯・豆腐店・商店街の店・町の老舗のトップ）
小杉湯（kosugiyu.co.jp、高円寺の銭湯）の実測。店の中を先に見せず、町の写真を大きく並べ、その余白に縦書きの短い段落を一つずつ置く型。
- 色：UI のトークンは黒 `#000`・白・`#999` の3つと、ロゴの墨 `#494342`（白 9.7:1）。有彩色の UI は0、色は写真が持つ（写真は彩度を落として青みでそろえる。平均色 `#2b414a`・`#8e9190`・`#b2bdbd`）。メニューを開いた地は `rgba(255,255,255,.95)`。
- 線：ボタンは 1px の黒の縁（260×52）、説明の窓は 2px。角丸・影・グラデは0。最初の3画面の枠線 0。
- 文字：Noto Sans JP の1つ（400・500 を読む）。縦書きの本文は 16px・500・行間 1.6・字間 .25em・`text-orientation:upright`・`palt`、1段 44〜133字、数字は漢数字（一〇分・一九三三年）。名前 20px、ナビ 14px（頭に「●」）、写真の上の営業時間 12px の白。SP の本文 13px は下限に足りない（作例は 16px）。地の文は weight 300 と書いて 400 しか読んでいない。
- 構成：表紙は「幅 130px の柱（縦のロゴ・町と創業年 14px .4em）＋写真」。写真の右上に営業時間・定休・料金だけ（申し込みのボタンは無い）。SP は柱 80px を右へ（`row-reverse`）。物語は「写真 80%＋柱 20%（文は下にそろえる）」を左右入れ替えて3回、間に 12列×40px（3.5vw・SP 8vw）の格子に写真7枚と中央の白地の文、締めは全幅の写真。人の線画（240px）を柱の上 12%・−32px で写真の縁にまたがせる。最後に聞き書きの3人（3列、SP 2列）と 1px の「さらに読む」。
- 動き：イージングは `ease` の1つ、.3s／.5s／1s。**視差は（要素の中心 − 画面の中心）× 係数 .1**、±100px で止め、中を 1.1〜1.2 倍にして余白を隠す。締めの写真だけ逆向き（係数 .12）で `1 − d×1.3/100` で薄くなる。登場は `transition:1000ms .5s ease`（写真は translateY 16px も、文は opacity だけ）。ローダーは白い幕を 500ms 後に 1s で消す。SCROLL の 1×60px の線が 1.5s で流れる（常に動くのはこれ1つ）。メニューの線は白＋`mix-blend-mode:difference`、開くと ±135°。施設案内は**断面図を 2 倍で置き、「前へ／1/8／次へ」で `scale()＋translate()` を 1s ease で替えて寄る**。
- 重さ：PC 8.37MB・SP 2.62MB。写真12枚で PC 6.09MB。srcset 6段の WebP（SP は 390px 幅で写真12枚 約 0.9MB）。HTML は SSR 済み。
- **反面教師**：reduced-motion が CSS・JS とも0（視差・登場・線が止まらない）。視差はスクロールのたびに全要素の `getBoundingClientRect`＋React の state（画面外も）。`sizes` が全部 100vw で、468px の枠に 1440px（3.08倍）・線画 1000px を 240px。SP の表紙は 390×292 を 310×520 の縦の枠に拡大。16枚とも eager・alt は空。SP の本文 13px。React のエラー #418/#423、メニューのボタンに名前が無い。
- 部品：`data-mood="town"` トークン、`.lpa-tate`（縦書きの段落）、`LPA.parallax(el,{center})`（中心からの距離×係数）、`LPA.camera(stage,{stops})`（断面図に寄る）。
- **AIっぽさとの線引き**：縦書きは「段落を短く、柱の下にそろえる」ときだけ。見出しを全部縦にして飾らない。写真の大きさと位置を毎段変え、同じ並べ方を3回続けない（本家は 80/20 を左右入れ替え、間に格子と全幅）。写真の上の営業時間は読める地の上に（作例は黒い帯）。線画が無いなら無理に描かず、写真の出典を縦書きの柱の下に置く。
