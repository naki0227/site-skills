# ポップ・参加型（周年、イベント、学校、NPO）
ガールスカウト100周年の実測（以前は `common.md` に「全タイプ共通」として置いていたもの。1サイトの型なので、この雰囲気を選んだときだけ使う）。
白地＋多色をセクション単位で使い分け、ずらし影と手描き線で手作り感を出す。

**AIっぽさとの線引き**：下の「英字ラベル＋和文タイトルを全セクションで繰り返す見出し」「字間 .1〜.15em」「通し番号 03/02/01」「3枚カード」は、どれも site-skills の ai-tells.md と、taste-skill の247サイト調査で弱いサイトに多かった型（英字の小見出し：上位32%／下位45%、字間を広げた小さな英字：16%／57%、アイコン付きカードの横並び：1%／28%）に当たる。周年・学校・NPO のように題材がこの賑やかさを求めるときだけ使い、使うなら題材の固有の物（ロゴの数字、制服の色、記念の年号）で中身を埋める。


## 1. 構成：ページは「物語」の順に並べる

リファレンスのトップは次の順に並んでいる。各ブロックが1つの役割だけを持つ。

| # | ブロック | 役割 | 学ぶ点 |
|---|---|---|---|
| 0 | ローダー | 期待を作る | 画像の読込率を0→100でカウント。正方形の枠が進捗で埋まる。**初回訪問だけ**表示（cookie `visited`）|
| 1 | ヒーロー | テーマを一撃で伝える | 不定形（ブロブ）の白フレームの中で写真が2秒クロスフェード／3秒間隔。キャプションカードがスライドと**同期**して切り替わる。下にスクロール誘導の矢印（上下バウンス）|
| 2 | アイコン付きナビ | 迷わせない | セクションごとに専用アイコン。スクロールで固定表示に切り替わる |
| 3 | メッセージ | 信頼 | 鮮やかなベタ面に人物写真が**枠からはみ出す**。キーワード（「変」）だけ色チップで強調 |
| 4 | 歴史 | 厚み | コラージュ＋傾けたスタンプ風パーツ＋ドット柄の背景 |
| 5 | 人（アンバサダー/応援団） | 共感 | ピンクのラベルチップで発言を引用。100人をカルーセルで見せる |
| 6 | アクション | 参加導線 | 3枚カード。タイトルはロゴ風に作り込む |
| 7 | 連載（100のコト） | 継続性 | 大きな斜体の通し番号（03/02/01）＋横一列の写真帯 |
| 8 | お知らせ→フッター | 締め | 日付付きリスト、イラストの草花で地面を作って終わる。トップへ戻るボタンは2/3スクロール後に出す |

**セクション見出しの型（全セクション共通）**
アイコン → 大きく細い英字ラベル（薄いティント色）→ 和文タイトル（太字・字間広め）→ リード1行。
この型を**全セクションで繰り返す**ことでページに一貫したリズムが出る。

## 2. 配色：ベース1色＋役割を持ったアクセント群

リファレンスの実測値（style.css の出現回数順）:

| 役割 | 色 | 用途 |
|---|---|---|
| ブランド深緑 | `#009a59` | ロゴ、ナビ文字、SPメニューボタン |
| メイン黄緑 | `#79c60d` / `#89b929` | ベタ面、ボタン、ずらし影 |
| ティント | `#d1eea9` / `#f3f8e9` | 英字ラベル、薄い背景 |
| アクセント空 | `#50b7ec` | 連載の番号・ボタン |
| アクセント桃 | `#ff8291` | アンバサダーのラベル |
| アクセント黄 | `#ffbf35` | ローダー、カルーセル矢印、100th Action |
| アクセント藤 | `#909ffe` | 補助ボタン |
| 文字 | `#221815` | **純黒ではなく赤みのある黒** |

ルール:
- **1セクション＝1アクセント色**。色は「どこにいるか」の手がかりにする。
- 写真がモノクロ（歴史写真）でも、UI側の多色で明るさを出す。写真と色は役割分担。
- 本文色は純黒を使わず、ブランド色寄りの黒を作る。
- 作るものに合わせて置き換える：まず「ベース1色＋ティント＋4前後のアクセント＋文字色」の表を作ってから書き始める。

## 3. タイポグラフィ

- 欧文：幾何学サンセリフ（ITC Avant Garde）を**細く大きく**。和文：游ゴシックを**太く小さく、字間広め**（`letter-spacing: .1em〜.15em`）。この太細の対比が上品さの正体。
- 本文の行間は約2.1。詰めない。
- 遊び：「100」を「1OO」と英字のOで書くなど、数字やロゴにだけ遊びを入れる。
- タイトル文字は1文字ずつ色を変えたロゴ風。遊ぶのはタイトルだけ。

## 4. アニメーション：種類は少なく、全部に「理由」がある

ソース（main.js）から読み取った実装:

| 動き | 仕組み | 値 |
|---|---|---|
| 紙吹雪 | PixiJS（WebGL）の全画面キャンバスを固定配置。粒は**たった20個**。`sin/cos`で揺れながら落ち、`skew`でひらひら回転、画面外に出たら再利用 | `ticker.speed = .5`、色は5色からランダム |
| スクロール表示 | IntersectionObserver で1回だけ発火→anime.js | `easeInOutCubic` / `1000ms` / 左右クラスで±100pxずれた位置から寄ってくる |
| ヒーロー | Swiper の fade 効果 | `speed: 2000`、`autoplay.delay: 3000`、キャプションの別Swiperを同期 |
| ローダー | imagesLoaded の進捗＋5ms刻みのカウンタ | 完了後ロゴを `scale 1.1` しつつ消し、タイトルが `scale 1.1→1` で出る |
| ホバー | CSS transition | ほぼ全部 `.3s ease`（opacity / box-shadow / color）。**統一**が大事 |
| 年表メーター | IntersectionObserver `rootMargin: -50vh` | 画面中央を通過した年に `is-active` |
| 固定ナビ・トップへ | scroll量の閾値でクラス付け替え | トップへボタンは全体の2/3を過ぎたら出す |

原則:
- **アンビエント（常に動く）は1つだけ**、粒は少なく遅く。主役のコンテンツを邪魔しない。
- 登場アニメは1回きり（`observer.disconnect()`）。何度も動かさない。
- 時間は「ホバー0.3s／登場1s／ヒーロー2s」の3段階くらいに揃える。
- `prefers-reduced-motion: reduce` のときは全て止める（リファレンスには無い。こちらは必ず入れる）。
- 最初の画面（ファーストビュー）は動きが無くても完成していること。

## 5. ディテール（"作り込み感"の出どころ）

- **ずらしベタ影**：`box-shadow: -6px 6px 0 0 #79c60d`。ぼかさない影がポップさを出す。
- 写真や人物を**枠からはみ出させる**、パーツを**少し傾ける**。
- 手描き風の線（ロープ、草花）やイラストをセクションの境目に置く。
- ドット柄などの背景パターンは薄く、局所的に。
- 画像はすべて `srcset` で `@2x` を用意。
- ブレイクポイント：1200 / 992 / 768 / 600 / 430px。スマホではハンバーガー（ブランド色の正方形）。
