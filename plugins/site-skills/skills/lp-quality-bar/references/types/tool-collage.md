- **表紙の格子**：24分の1（4.16667vw）が単位。大 14/24（`float:left`）、中 8/24（`float:right`・`margin-top` +4/24）、中 8/24（右から 6/24・`margin-top` −1/24・`z-index:1` で手前に重ねる）。どれも 3:2（`padding-bottom:66.667%`）。1枚まるごと1つのリンク。SP は 100%・22/24（左 2/24）・22/24（−2/24 重ねる）の互い違い。1600px からは同じ割合の px（933／533／400／−66px）に置き換えて止める。本家は5つの並べ方を CSS に全部持つ（1,074 規則・169KB）が、作るなら `min(4.16667vw,66.667px)` の変数1つで足りる。
- 色：UI は白・黒・青 `#0000ff`（白で 8.59:1、#eee で 7.41:1）・`#666`（5.74:1）・`#eee`（帯の地）。影 0・角丸 0。有彩色は記事の種類の札の7色（Artists `#FED134`・News `#D5B3FF`・Tutorials `#00D2BE`・Downloads `#FF8389`・Loop `#6DCBFF`・Videos `#B1C5FF`・Packs `#FFC2CA`）、文字は必ず黒（8.86〜14.38:1）。ほかに名前のついた色（cobalt・salmon・goldfish…）36組を地と文字の class の対で持ち、製品ページや表紙の地に使う。
- **文字の色を写真ごとに選ぶ**：表紙の写真は暗くせず、CMS で `text-white／text-black／text-dolphin（#eee）` を選ぶ。淡い #eee は明るい写真の上で読めなくなる（反面教師）。
