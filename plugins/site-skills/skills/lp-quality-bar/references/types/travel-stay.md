# 旅・宿泊（旅館、ホテル、観光、予約が主役のサイト）
星野リゾート（hoshinoresorts.com/jp/）の実測。UIは白に引き、色は「特集の章」が持つ。最初の画面は写真でなく空室検索。
- UIは白 `#fff`・`#1a1a1a`（65回）・灰 `#e8e8e8` / `#f2f2f2`・青 `#02a0cb` だけ。角丸なし、影は `0 0 20px #0000000f`、フォーカスは `0 0 0 4px #1a1a1a`（`data-mood="trip"`）。
- 章は「地の色＋文字色（黒／白）」の1組をデータで持つ（インライン style）：`#ebebeb` `#fff` `#f8e1e1` `#c0a166`（白文字）`#ee9d9d`（白文字）`#272725`（白文字）`#d4f5f3`。CSS には出てこないので、CSS の色の語彙は白・黒・灰・青だけ。**白文字は金 2.46:1・珊瑚 2.11:1 で不足**（同じ地に `#1a1a1a` なら 7.07 / 8.24:1）。白文字は地との比を計算してから。部品：`.lpa-deck`。
- 章の頭は「スタンプ（イラスト 130 / SP 90px）＋題（PC 32 / SP 24px・500・字間 .02em）＋副題（20 / 16px・500）」の繰り返し。上下の余白は `::before` / `::after` の負のマージンで削る（行間 1.375 で .3875 / .2875em、1.35 で .375 / .275em ＝ 上 (行間−1)/2+.2em・下 (行間−1)/2+.1em）。部品：`.lpa-trim`。
- 境目は波：高さ PC 100px・SP 80px、色は次の章の地、幅は `max(1920px,100vw)`（SP `max(390px,100vw)`）。PC は最初の章だけ、2章目以降は同じ色のまっすぐな境目。SP は全部の境目が波。次の章を波の高さぶん引き上げて重ねる（`margin-bottom:-80px`、下の余白は波＋60px）。本家は止めない。部品：`.lpa-wave` / `LPA.wave`。
- 横レール：カードは 4:5（画像 268×335）、PC 268px・すき間40px、SP 140px・すき間12px。丸い前後ボタンは、カードの左端をレールの左端に合わせて `scrollBy({behavior:'smooth'})`。スクロールバーは隠す。部品：`LPA.peekRail` の `by:'card'`。
- 最初の画面は検索（目的地・日付・人数＋黒い「空室を検索」）。ヘッダーは上段 PC 72 / SP 50px、その下に5タブ（アイコン＋ラベル、現在地は太字）。PC は上に貼りつき（58px）、SP は画面の下に固定（84px・ラベル10px）。
- 動きは少ない：`opacity .2s`・`transform .3s ease-in-out`・メニュー `right .4s ease-in-out`・波。`cubic-bezier` は0回。`:hover` 53か所で `hover:hover` は0。
- 画像は全部 WebP、`<img>` 31個のうち27個が `loading="lazy"`。波の Lottie は動的 import。フォントは `unicode-range` で56個に分割。絵文字は webp の画像で出す。
- 構成：ヘッダー（ハンバーガー・ロゴ・5タブ）→ 空室検索 → 見出し → 7つの章（スタンプ＋題＋カードのレール）→ メールの帯 → フッター `#333`。
- **反面教師**：reduced-motion・saveData が CSS・JS のどこにも無く、波を止められない。白文字の低コントラスト。PC は画像 5.8MB・SP は 1.8MB（`sizes` が 30vw なのにカードは 268px ＝約 18.6vw で、`w_1024` が選ばれる。署名つき URL は幅の段が 128/256/512/1024/2048 しか無い）。HTML 1.45MB（RSC 約0.64MB）。解析タグ（GTM 1.03MB・gtag 0.54〜0.59MB×3・Facebook 2.2MB・TikTok 0.66MB）。
- 部品：`data-mood="trip"`、`.lpa-deck`、`.lpa-wave` / `LPA.wave`、`.lpa-trim`、`LPA.peekRail` の `by:'card'`。
