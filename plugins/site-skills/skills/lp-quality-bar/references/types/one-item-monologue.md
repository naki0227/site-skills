# 一品ブランド・3Dのロゴと一行の独白（商品が1つの D2C、説明を書かずに「ずれ」を見せたいトップ）
nome（isnome.com、静岡の煎茶をティーバッグにして郵便受けへ送るブランド、2026-11-05 実測）の型。商品の効き目や産地を並べず、ロゴの線を後ろに固定した立体にして、手前で一行の独白を入れ替え、写真の向きで「視点のずれ」を見せる。トップは4セクション＋脚注だけ（PC 5,699px）。
- **ロゴの線を後ろの地にする**：canvas を `position:fixed; z-index:-1`、各セクションの地を透かしてずっと見せる。本家は筆記体の SVG パスを 100点ずつ取り、z を `(t−.5)×280＋sin(tπ)×40` で手前と奥に振った three.js の管（`TubeGeometry(curve,800,2.4,16)`・`metalness .5`・`roughness .005`、平行光 5／2.5、背景の板に赤と青のスポット 2000、`ACESFilmic`・露出 1.4）。光の色相が時間で回るので、管と地の色（#F5EFF4〜#F6F4EF）が少しずつ変わる。作るなら Canvas 2D の帯で足りる（作例で確かめた）。
- **スクロールの量をカメラの距離にする**：`距離 = 基準 × (1 − 比 × .9)`（比はページ全体）。章ごとの登場を作らずに、読み進めるほど線が寄ってくる。
- **一行の独白**：200vh を −100vh 重ねた中央に一文だけ（24px・SP 18px・字間 0）。8文を `delay 800ms＋speed 300ms`（1文 1.1秒）の縦向きの fade で入れ替え、後ろの `backdrop-filter: blur(3px)` を scrub で 0 へ。文は効き目でなく独白（「また、考えすぎている。」）。
- **写真を 90 度寝かせて帯を埋める**：`width:150vh; height:100vw; transform:translate(-50%,-50%) rotate(-90deg)` で 150vh の帯をすき間なく埋める。並びは「一文（sticky 100dvh）→縦長の一枚（sticky 100dvh、64dvh×80dvh、帯の中央が画面の中央に来たら opacity .3s）→帯（150vh、margin-top −100dvh）」。題の言葉を写真の向きで見せる。
- **表紙は文字を同じ位置に、手前の物だけ替える**：3枚の写真のどれにもロゴの文字を同じ位置に写し込み、ガラス・ティーバッグ・袋だけを替える（fade .8s・3秒）。題は左上 24px、行動は左下。
- 色：文字は墨 `#1a1a1a` の1色（白で 17.4:1）、地は白と 3D の光の色、有彩色は珊瑚 `#e56c5e`（墨の文字で 5.50:1）だけ。珊瑚は右下の楕円・メニューの全面・乗ったときの文字に。影 0・枠線 0・角丸は楕円の 50% だけ。
- **行動は角括弧の文字だけ**：「[ Shop Now ]」（表紙 24px・締め 72px／SP 44px）。下線は中の語だけ。値段と送料は行動のすぐ横に 14px。ボタンの形を作らないので、写真と 3D の上で浮かない。
- **右下に楕円を3つ固定**：92×30（SP 80×24）・`border-radius:50%`・乗ると `rotate(-10deg)` を .2s。メニューは珊瑚の全面が opacity .2s で出る。
- 文字：英字 Overused Grotesk（自前・可変）＋和文 Zen Kaku Gothic New。段は 72 / 24 / 18 / 16 / 14px（1rem＝10px）、字間 0、行間 1.4〜1.6。代わりの Google Fonts は Hanken Grotesk。和文は作例では手本の業種から選ぶ（Zen Kaku Gothic New は見比べで AI っぽいと選ばれた）。
- 動き：.2s（乗る・開く）・.3s（入れ替わり）・.8s（写真）と scrub。イージングは CSS の ease と GSAP の `"none"`。
- 重さ：PC 8.54MB・309 通信（計測タグを除く）。写真は 538KB だけで、JS 5.1MB（トップで使わない Shopify のチェックアウト 1.6MB、three.js 718KB）、JSON 1.8MB。計測タグを含めた 約 9.75MB のうち 5.4MB は load の後。
- **反面教師**：reduced-motion 0（管・光・独白が回り続ける）／閉じたメニューの「Play」1語のために Google Fonts の全書体の一覧 1.8MB と 50 書体を load の後に読む／トップでもチェックアウトの JS 1.6MB／`.MainContent{opacity:0}` を window の load まで外さない／2000×2000 の写真3枚を srcset なし・eager／`:hover` を hover:hover に閉じない／珊瑚の文字 2.83:1／独白に止める手段が無い／alt が「Hero Image」。
- 部品：`patterns/` の `LPA.lines(list,{delay,speed})`（一行ずつ入れ替える独白。止めるボタン・画面外・reduce・saveData で全文を並べる）、`.lpa-lay`（寝かせた写真の帯）、`.lpa-ell`（右下の楕円、乗ると −10°）。
- **作例で確かめた翻訳**（ひとはば・架空の利尻昆布の水出しパック、2026-11-05）：後ろの線を3Dの管でなく Canvas 2D の昆布の帯（幅が変わるリボン）にし、表紙を過ぎてから描いた（three.js 不要、0KB）。「寝かせる」を写真の向き（90°）と昆布を水に寝かせる手順の両方に掛けた。表紙は写真の上に画面いっぱいの題と、今日の本物の値（今季の旗の日数・次の発送日）。独白は「止めて全部読む」で全文を並べる。
