# 和・上質（老舗、菓子、工芸、美術館、旅館）
とらや（虎屋）の実測。引き算で品を出す型。
- UIは無彩色だけ：`#fff` の地、`#111` の文字（純黒にしない）、罫と縁は `#ccc`、ホバー時の文字は `#777`、薄い面は `#f2f2f2`。色は商品写真の地（パステル）に任せる。
- 赤（`#b30000`）は小さな目印（バッジ・ラベル・重要なお知らせの枠）だけ。金などの予備色は定義しても使わない。
- 文字は大きさ6段（12 / 14 / 16 / 20 / 24 / 32px）。見出しだけ明朝（weight 400、行間1.5）、本文は游ゴシック系で行間1.6。字間は触らない（normal）。太字はボタンとラベルだけ。
- ヒーローは画面いっぱい（100vh）に商品1点を中央に置き、文字は載せない。複数枚のときだけフェード（700ms、7秒）。ヘッダーは最上部で透明、スクロールで白（.2s）。
- イージングは `cubic-bezier(.25,.46,.45,.94)` の1つ、時間は .1 / .2 / .4s の3つ。演出用のkeyframesは持たず、動きはほぼ transition だけ。
- ホバーは「画像が .8 に薄れて 1.03倍、題は灰へ」だけ。`@media (hover:hover) and (pointer:fine)` の中に閉じる。
- 横レールは PC4枚・タブレット3枚・SP2枚（すき間 40 / 20 / 16px）。PCでは縁で切れたカードを opacity .2（.4s）、SPは次の1枚をのぞかせる。
- ボタンは縁だけのピル（高さ46、角丸23、縁2px、太字14px）。墨ベタはホバーで白黒反転。
- 構成：同意ダイアログ → 透明ヘッダー → ヒーロー1点 → お知らせ → ショップ（3本のレール）→ 店づくり・理念（2カラム）→ SNS → 灰の帯 → 墨のフッター。
- **反面教師**：`prefers-reduced-motion` の指定が無い。スマホでもPC用ヒーロー（247KB）を先に取ってから差し替える。Cookieバナー（429KB）とSNS写真（約0.8MB）で外部が重い。
- 部品：`patterns/` の `data-mood="wa"`、`.lpa-thumb`、`.lpa-pill`、`.lpa-burger`、`.lpa-header`、`.lpa-rail`、`LPA.peekRail`、`LPA.scrollHeader`。
