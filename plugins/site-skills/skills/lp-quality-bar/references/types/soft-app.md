# やわらかいアプリ（コンシューマのモバイルアプリ）（iOS／Android のアプリ、ウォレット・家計・予約・空き状況など「画面の状態」が売りのサービスのトップ）
Family（family.co、iOS の Ethereum ウォレット）の実測。説明の代わりに、アプリの本物の「途中の状態」をカードやスマホの枠の中で回す型。
- 色：題 `#121212`（白と 18.73:1）・本文 `#474645`（9.42:1）・注記 `#848281`（3.82:1、14px の補足だけ）。地は白と `#fbfaf9` の2段。章の間は幅いっぱいの 1px `#f2f0ed`、縁が要る所は `box-shadow:0 0 0 1px rgba(0,0,0,.04)`。**枠線は最初の3画面で0本**。トークンは16進で書き、`@supports (color: color(display-p3 1 1 1))` で同じ名前を display-p3 に書き直す。
- 章ごとに1色：金 `#ca9230`・緑 `#44c67f`・橙 `#ff5310`・青 `#3784f4` を章に1つ。使うのは 14px・600 のラベルと箇条の印だけ。**本家は色をそのまま文字にして 2.18〜3.64:1** → 文字は暗い版（`#8a6516` 5.31・`#1e7a4a` 5.33・`#c2410c` 5.18・`#1f63d1` 5.58:1）、印の丸は元の色。
- 文字：見出しは自前の幾何学的な書体（Family → 代わりは Inter Tight 500）、本文は Inter、アプリの画面は別の書体（LFE Sans）。章の題は**全部同じ** 44/48px・500・−.031em（SP 32/35px・−.69px）、表紙だけ 68/74.8px。本文 17/26px・−.22px（PC と SP で同じ）、機能の文 19/27px、カードの文 15/22px、ラベル 14/20px・600。字間はどの段も負。和文の題は −.02em まで。
- 押せる物は2種類：黒 `#171717` と淡い `#f6f4ef`、角丸 32px、高さ 48px（ヘッダー 32px）、文字 17px・500。変わるのは地の色だけ（`.1s`）。影も縁も無い。
- 構成：sticky の白いヘッダー（95px・影なし）→ 表紙（中央の題＋ボタン2つ、左右に絵）→ **5枚のカード**（縦長 319×533 が1枚＋319×249 が4枚・間 34px・角丸 12px・地 `#fbfaf9`）→ **動画のリレー**（3枚）→ 地 `#fbfaf9` の機能の文（2列×3段、上下 104px）→ スマホ（346×707）と文を左右入れ替える章を3つ（各 694〜708px）→ 守り → 2回目のリレー → お知らせ → **題を `sticky; top:240px` で残す長い章**（1,974px）→ 声・質問・終わり。
- カードの中の実演：「Back Up Now → Backing Up（回る輪）→ チェック」「Submitted → Pending → Completed と時刻」「Normal ~60 Secs → Fast ~43 → Urgent ~15」「中央を大きくして送る」。どれも題材（アプリ）の本物の画面の途中の状態。
- 動画のリレー：`<video muted preload>` を JS で1本ずつ `play()`、`ended` で次へ。再生中の1枚だけ 1.1倍（352×353 と 320×321）。同時に動くのは1本。
- 動き：大きな移動 `transform 1s cubic-bezier(.19,1,.22,1)`（56）、小さな移動は同じカーブの `.22s`（42）、色と影は `.1s`。ばね（framer-motion）は stiffness 800・damping 80（減衰比 1.41、行き過ぎない）。`:focus-visible{transition:none; outline:2px solid #848281}`。
- **反面教師**：reduced-motion 0か所で、表紙の SVG（`g` 405個）が reduce でも画面外でも動き続ける。動画 1170×2532 を 209〜346px で、9本とも `preload="auto"`（7.35MB）、再生し直すたびに取り直し → PC 27.86MB・SP 21.12MB。サムネ 1920px を 78px。woff と woff2 を両方 preload（.woff 335KB が無駄）。`_app` 2.96MB（lottie-web 一式）。よくある質問が `height` を動かす。`:hover` 50・`hover:hover` 0。React の hydration エラー。絵文字。
- 部品：`data-mood="app"` トークン、`LPA.relay(el,{scale})`（1つずつ順に進め、進んでいる1枚だけ大きく。止まる条件つき）。
