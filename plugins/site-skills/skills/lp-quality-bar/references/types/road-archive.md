# 歴史の特設・年号の札と光の道（マークや製品の変遷を1年ずつ送る）
Honda WING MARK HISTORY（global.honda/jp/wingmark/、ウイングマークの8つの年をたどる企業情報サイトの特設。three.js r168＋GSAP 3.13＋barba、2026-11-26 実測）の型。赤1色の濃淡の地に、レースのコースと光の筋の「道」を描き、スクロールで道を進むと1年ごとにエンブレム（GLB の3D）が手前から来る。左下に題・右下に年号を毎回同じ場所に立て、最後にコース全体を見下ろして8年を線の上の札にする。

- **年号の札の置き場所を固定**：年号は右下（端 60px・下 50px）に 48px・明朝 Light・字間 -.04em、題は左下に 40px／54px・3行まで・下に 1px の線（scaleX 0→1）。SP は端 20px・題 24px／32.4px。全部の年で同じ場所なので、読む人は目を動かさない。
- **一字ずつ、手前から定位置へ**：`_cmnShowMotion` は z 200→0・opacity 0→1・3s Expo.easeInOut。毎回の乱数 c から rotateX＝sin(c·.9)·20·(1−rate)、rotateY＝cos(−c·.97)·20·(1−rate)、rotateZ＝sin(c·.8)·20·(1−rate)。揺れが登場とともに 0 に収まる。退場は z→200・1s Expo.easeIn。部品は `LPA.settle`（既定 1.1s。3s は作例では長い）。
- **道を目次に**：最後の画面でコース全体を上から見せ、線の上の白い四角（14px・角丸 4px）から引き出し線で札（10.42vw×9.58vw＝150×138px、縁 1px rgba(255,255,255,.3)、地 #ffffff1a、blur(2px)、角丸 .97vw、窓 138×92・#fff3）。真ん中に一言 23px（opacity・scale 1.1→1・1s Power2.easeOut）。乗ると窓と縁が .25s で明るく、絵が少し大きく。
- **右端の点**：12px の点×8＋1px の線、最後だけ四角。押すと 1.5s Power2.easeInOut でその年へ scrollTo。
- **オープニング**：白い地の今のマーク → 赤い地 → 線の球の中で題が一字ずつ → 注記 14px と右下の SKIP（下線）。約8秒。
- **地は1色の濃淡と粒**：中心 #8b0000・四隅 #4c0000（シェーダー）。UI は白と白の透明度だけで、色は主役の物に任せる。
- **描く手間の間引き**：2コマに1回の描画（SP・Windows は常に、出る前は5コマに1回）、ぼかしは 1/10 の大きさで描いて広げる、SP の画素倍率を 1.5 に固定。モデルは DRACO。
- 長さ：PC 22,262px に8年（1年 約2,700px）。年の間は題を消して移動の時間にする。
- 文字：MainichiNewspapersM Light（モリサワの Web フォント）で題・年号・目次、英字のボタンは Helvetica Neue 16px、注記は Hiragino Kaku Gothic W3 14px。代用は Noto Serif JP 300・Noto Sans JP。
- 重さ：PC 9.30MB・146件／SP 9.19MB（measure.js）。解析込み 14.27MB（GA の gtag 5本＋GTM で 3.4MB）。main10.js 863KB、GLB 8つ 2.43MB、下層8ページの HTML を先読み 1.3MB。
- **反面教師**：reduced-motion 0／本文が HTML に無く JS が組む（年号は aria-hidden）／右端の点の button に名前が無い／最初に8年分のモデル・下層の HTML・下層の背景を全部読む／lil-gui（調整画面）が本番の JS に／inspect FAIL 4（SP の本文 13px・書体5種・SP の枠線 48）。
- **作例で確かめた翻訳**（凪島汽船・尾道と架空の島を結ぶ汽船会社の煙突の七十年、2026-11-26）：エンブレムを「七回塗り替えた煙突のマーク」に、コースを「尾道から島への航路」に置き換えた。煙突のマークは平らな塗料の形なので SVG で描き、円筒の陰を1枚重ねた。章の地は藍の放射（中心 #21486b → 四隅 #0e2133）、表紙は暗い地を写さずに晴れた尾道水道の写真を全面に（美的感覚の決まり）。航路の線は本家の5本の線を、太さ 44→4 を藍と地で交互に重ねて作った。「次の便」は日本時間で計算し、終わった後は明日の始発を出す。inspect FAIL 0・WARN 2（煙突の SVG）。
