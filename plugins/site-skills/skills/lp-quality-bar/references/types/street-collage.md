# 町の飲食店・写真を積んで裂く（紙の地と橙）
GRAN BURGER（gran-burger.com、佐賀・唐津のハンバーガー店、Astro＋GSAP 3＋Lenis、2026-11-08 実測）の型。客・クルー・農家など店に集まる人を、太い色の縁の切り抜きと一問一答で見せる。PC 29,775px（うち表紙〜一問一答の固定 19,711px）、SP 29,159px。
- **表紙の写真は回さず、四辺形に切って斜めの辺を共有させる**：4枚を `clip-path:polygon()` で（PC：1枚目 `0 0,100% 0,72.06% 100%,0 100%`・left 1.667% 幅 30.382%、2枚目 `20.234% 0,84.694% 0,100% 100%,0 100%`・left 24.757% 幅 41.549%、3枚目 `0 0,100% 0,100% 77.098%,9.96% 100%`、4枚目 `7.58% 100%,0 24.99%,100% 0,100% 100%`）。隣と同じ傾きの辺を向かい合わせ、すき間を斜めの帯にする。上に橙の一語（Human Again、SVG の本体＋影）と、下に店の一文の帯（marquee 20s）。
- **積んで、コマ落としで崩す**（オープニング）：24の位置（画面比 x・y ±.36、回転 −13°〜+12°）へ scale 0 → .62〜1.12 を back.out(1.2)、長さ .45 → .26〜.12、間 .12 → .035s（4枚ごと +.055s）。退場は 1.275s `steps(8)`・.025s ずつ・回転 +12°。ロゴは scaleX 1.1/scaleY .92/±3.4° を .14s → .94/1.08 を .16s back.out(2.4) → 1 を .2s back.out(2) で伸び縮みし、下から橙が満ちる（yPercent 180 → −40）。同じセッションの2回目と reduce では出さない。
- **大きな題は本体と影の2層**：`y 150vh → 0` 1.65s power3.out、`scaleY .65 → 1.13`（.44s）`→ 1`（.62s back.out(1.35)）、影は .12s 遅れ。見えたら1回。
- **章の境目で前の章を紙のように裂く**：上の片 `(−100vw,−100lvh)`・下の片 `(100vw,100lvh)` へ 1.1 の長さ power2.in、スクロールに連動（scrub）。裂け目に紙の質感 1 枚。
- **切り抜きに太い色の縁、人ごとに色**：常連は青 `#5ebfd7`、クルーは黄 `#f2c549`（縁と引用の札。黒の字と 8.91・11.56:1）。縁の影の層だけ `xPercent 15 → −15` で視差。
- **網点の写真をこすると色に戻る**（店舗案内）：橙の網点と色の写真の2枚を WebGL のテクスチャに、指の跡を状態のバッファーに塗る（半径 300×倍率、時間で消える、画面外で止める）。SP は代わりにロゴを伸び縮み（1.15s おき、IO で止める）。
- **湯気**：2層を 9s・4.5s ずらし（scale .52/.78 → 1.01/.99 → 1.5/1.2、opacity 0 → .9 → 0、ぼかし PC 14px・SP 6px、上を透明にするマスク）。アイコンは `steps(16)` で −360° → 0。
- **乗ると札が反対に跳ねる**：品名の和訳 −7°・英訳 7°、550ms `cubic-bezier(.16,2.4,.3,1)`、フォーカスでも。
- 色：`@theme` に7色。紙 `#e0dbce`（960px の紙の質感の WebP を敷く）・橙 `#ff4e08`・黒 `#111`・白、青と黄は縁だけ、蛍光黄 `#faff00` 1か所。角丸 0・影 0・グラデ 0。市松の帯（40/1440）で品の段を区切る。
- 文字：Google Fonts の Anton（英字）と Noto Sans JP（和文は本文まで 900）。和 26/18/16/15/14/13px（PC）、本文 16/1.8・−.02em。英訳は Anton 14〜15px／1.25〜1.4 を和文の下に。
- 重さ：PC 11.65MB・SP 9.44MB（解析タグを除く）、load まで PC 8.17MB。WebP 7.73MB/71 件、Google マップの JS 1.87MB、書体 45 本 0.97MB、HTML 618KB。
- **反面教師**：読み込みの最低 5,000ms（全部届いても待つ。表紙の一語まで約 7〜8 秒）／英訳を Anton 14px・行間 1.25 で長く組む／紙と橙を重ねて字にする（2.39:1）、店舗案内の白は 3.31:1／市松の帯を img 186 枚（alt 空の img 293）／表紙の 12 コマとコンセプトの写真を全部 eager／単語の途中で折り返す（PC 7・SP 12 か所）／地図を開く前に Google マップの JS。reduce ではオープニング・視差・裂ける遷移・湯気・帯がすべて止まる（ここは見本）。
- 部品：`patterns/` の `LPA.pile(container,{positions,exit})`（積んでコマ落としで崩す）、`LPA.scratch(canvas,{img})`（2色の写真の上をこすると色の写真が出て時間で戻る）、`.lpa-checker`（市松の帯を背景1つで）。
- **作例で確かめた翻訳**（屋台かめよし・架空の中洲の屋台、2026-11-08）：表紙は黄 `#ffc400` の地に画面の幅いっぱいの「かめよし」（Noto Serif JP 900）、手前に絵の赤ちょうちん（墨 7px の縁）、ステッカー「雨の夜は休み」。裂ける遷移は暖簾が左右へ割れる帯に、積むは組み立ての時刻の札5枚（`steps(8)`）に、四辺形は町の写真3枚（墨→黄の2色）に、網点をこするのは那珂川の写真に。触れる1つは L字の長椅子9席（押すと眺めと一皿）。
