# 採用サイト・課題を札にする（会社の採用サイト・採用 LP のトップ）
SmartHR 採用サイト（recruit.smarthr.co.jp、2026-11-03 実測）の型。会社の志の一文と「いま解いている難問（ISSUE）」を見出しにし、見出しを1行ずつ白い札に切って、残りの幅を canvas の網点で埋める。
- 色：UI は墨 `#23221f`（白で 15.91:1）・白・ブランドの1色（`#00c4cc`）の3つ。灰は `#4e4c49`・`#aaa69f`（墨の地で 6.56:1）を数か所だけ。豊かな色は網点の canvas の中だけに持たせる（primary-heading：`#00C4CC` 0・.4 → `#1667C3` .7 → `#160586` 1、.7〜1 を2色の網点に）。影 0・角丸 0。
- **札**：見出しを `display:flex` の行にし、左は白地・1px の墨・左の線なし・`line-height:1` の札（110px は上下 20px で行 150px、文の札 18px で 33px）、右は `flex-grow:1` の canvas。行ごとに文字の長さが違うので帯の左端が階段になる。改行は PC 用と SP 用を別に書く。
- **網点**：Bayer 8×8 の組織的ディザ、粒 3px（SP 2px）×画素比。区間の中の位置 u で「1−u ＞ .5＋(しきい値−.5)」なら手前の色。canvas の1画素を1粒にして `image-rendering:pixelated` で拡大すると、描くのは軽い（142枚でもファイルは 15KB の描画だけ）。
- 文字：和文の太いゴシック（Gothic MB101 DeBold → 代わりは Zen Kaku Gothic New 700）、数字は Zalando Sans の幅 125（Google Fonts）・字間 −.04em・行間 .8。段は 236（数字）・110・80・60・50（単位）・36・32・24（声明）・20・18・16（本文 1.9）。字間は全部 .02em。大きさは `--window-width`（`tan(atan2(100vw,1px))`、JS なしの単位のない画面幅）の1次式を `clamp()` で止める。
- 構成：表紙の札（ボタンなし）→ 声明（24px の7段落）→ 課題（番号の列＋60px の札＋担当者の部署と名前、押すと開く）→ 資料（Speaker Deck）→ 未来（写真＋ボタン）→ 数字（2×2・十字の 1px）→ イベント（カルーセル）→ メディア（3列）→ 締め（札をもう一度＋ボタン2つが止まる）。
- 行動：「カジュアル面談」（白）と「募集職種・エントリー」（墨）の2つ、301×80、PC で右下に固定（1.2s 遅れて .8s で現れる）、締めの段で同じ形に止まる。SP は締めだけ。
- 動き：時間は CSS 変数5つ（.1／.3／.35／.8／.8s、SP の開閉 .6s）、カーブ4つ（easeOutQuad・easeInQuad・easeInOutCubic・easeOutCubic）。reduced-motion で5つとも 0s、JS も同じ変数を読む。網点は 800ms・easeInOut で左から、行ごとに 60ms（SP 40ms）、1回きり。課題に乗ると .4s・30ms ずつ（`hover:hover` だけ）、押すと `grid-template-rows` 0fr→1fr。声明は 140° の文字のグラデを画面の 85%→50% で塗る（scroll は見えている間だけ）。
- 重さ：転送 5.45MB（SP 5.41MB）。和文フォント 3.04MB・60本、計測タグ 604KB、Speaker Deck 846KB、Swup の先読み 12ページ 312KB。写真は microCMS の `sizes` どおりの幅で軽い。
- **反面教師**：13px未満の文字 21%（※・部署・タグ 12px、SP の※ 9〜11px）、SP の本文 14px、まだ塗られていない白い文字が青の上で 2.15:1、和文フォント 3MB、UA を含む計測タグ4本、見えたリンクを全部先読みして saveData で止めない。
- 部品：`patterns/` の `.lpa-strip`（札＋帯の行）と `LPA.dither(canvas,{stops,from,to})`（網点の帯。見えたら左から1回、reduce・saveData では描くだけ）。
- **作例で確かめた翻訳**（天竜すずかけバス・架空、2026-11-03）：網点を「方向幕の LED の点」に読み替え、帯の右端を墨にして LED の橙の粒を灯した（緑→墨の2色＋橙）。課題の番号の列は「系統1〜3」。声明は文字のグラデをやめ、1行ずつ opacity .32→1（inspect の gradient-text を避ける）。題材の基準（勤務の拘束と休息）で動く「触れる1つ」を、課題の次に置くと、課題の文が具体になる。
