# テック・SaaS（IT、通信、金融、B2B）
- 文字は濃紺1色、背景は青み白。鮮やかな色はグラデーション・縁・細線だけに使い、単色のベタ面にしない。
- 日本語見出しは細く（300）、字間−.02em、行間1.15、`word-break:auto-phrase`。
- ヒーロー見出しは前半を濃色、後半を半透明アクセントの2トーンに。
- 主役の演出は1枚のcanvasにまとめる。タブ非表示で止め、WebGL不可なら静止画（WebP、SP/PC別、preload）に差し替える。
- トランジションは `@media (prefers-reduced-motion:no-preference)` の中でだけ定義する（動きは許可されたら足す）。
- 実績は「生きた数字」：`tabular-nums`、1つは毎秒増えるライブカウンタ。
- 製品説明はベント（大きさ違いのカード）＋各カードに実DOM/SVGのUIモック。重いグラフィックは800px手前で組み立て、`threshold:.1`で動かす。
- 画像は全部WebP＋srcset＋lazy。日本語Webフォントは読まずシステムフォント。弱点はJS 5.9MBなので、真似るならJSは絞る。
