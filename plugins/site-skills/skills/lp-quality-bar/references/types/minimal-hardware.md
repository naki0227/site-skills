# ミニマル・ハードウェア（ガジェット、楽器、プロダクト、工業デザイン）
teenage engineering の実測。製品が主役で、UIは黒子になる型。
- UIは墨・白・灰だけ：地 `#0f0e12`、文字 `#f5f5f5`、補助 `#7f7f7f`、線 `#4d4d4d`〜`#272727`。純黒 `#000` は写真の帯に限る。色は製品写真に持たせる（`data-mood="mini"`）。
- 寸法を「基準幅の何分の何か」で書く（PC 980 / スマホ 490、境目 768px）：`calc(0.0183673 * 幅)` ＝ 980幅で18px。ヒーローの高さも幅 × 1.3367。部品は `--lpa-u`。**ズームは止めない**（本家は `maximum-scale=1` とキー操作の `preventDefault` で止めていて、これは真似ない）。文字には `max()` で下限をつける。
- 文字は極細の1書体（太さ 100 / 300）：標準 18/20px、ほかに 9/10・13/15・27/30・36/40px（980幅、フォント/行間）。字間は触らない。名前はソースを小文字で書き、CSSで `uppercase`。日本語は専用Webフォントを読まず端末のフォント。
- ヘッダーは「アイコン → 大きな名前 → 小さな行き先2〜3個」の3段セルを横に並べる。アイコンは輪郭と塗りの2変種（`data-theme-variant`）、色は `--theme-mc` の1変数、切替時間は `--theme-dt`（トップは0）。PCは `position:absolute` で流れて消え、スマホはバッグとメニューだけの固定バー。
- トップは写真1点（高さ＝幅 × 1.34）＋黒い帯に告知1行＋フッター。商品は別ページ（/products）で「大きな画像 → 小さな名前」を繰り返し、画像の地が黒と明るい灰で入れ替わるリズムにする。
- 動きはほぼ無い：スクロール演出もローダーも無い。バッグの `bulge`（.25s、1→1.25→1）、`opacity .15s`、`background-color .2s`、イージングは `ease` 系のキーワードのみ。流れる帯は 12s linear、すき間40px、2コピー、ホバーで停止（`LPA.marquee`）。
- 画像は webp ＋ `srcset`（128〜5120w の最大7段、`sizes="100vw"`）。ヒーローだけ `eager`＋`fetchpriority=high`、ほかは `lazy`。SPは 512w（39KB）、PCは 2048w（990KB）。
- **反面教師**：トップに動画が無いのに動画プレーヤー（685KB）を読む。製品JSON（486KB）をトップで取る。JSは計1.5MB。`prefers-reduced-motion` は流れる帯の1か所だけ。ズーム禁止。
- 部品：`data-mood="mini"`、`--lpa-u`、`LPA.marquee`、`LPA.bulge`。
