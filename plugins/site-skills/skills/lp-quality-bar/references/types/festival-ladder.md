# 音楽フェス・段のロゴと名前の帯
Flow Festival（flowfestival.com、Astro の静的出力、2026-11-19 実測）の型。出演者の写真ではなく、**名前の組み方1つ**をフェスの顔にして、ヘッダー・表紙・帯・案内の窓で使い回す。色は黒・白・灰に、ブランドの色1つ。
- **段のロゴ**：名前・種類・場所の3語を、高さ 184／112／60（1 : .61 : .33、最初の比はほぼ黄金比）の箱に載せ、上下の中央でそろえる（下をそろえない）。箱は灰 `#e6e6e6`、字は墨 `#1d1d1b`、1つの SVG（viewBox 1074×184、3〜5KB）。ヘッダーは 3つ目を日付に替えて 30vw（SP 70vw）、表紙は 70vw（SP 95vw）、ニュースレターの窓では縦に積んで上下に同じ語をくり返す。写真の上に載せるときは箱を外し、字の大きさの比だけで段にする（箱ごと載せると inspect の title-box）。
- **名前・場所・日付の帯**：語を灰の札に、間をブランド色の四角（55px）で区切った SVG 1074×34 を20枚並べ、`translate(-50%)` を 35s linear。高さ PC 50px／SP 20px。表紙の下端に置く。
- **止めるボタン1つで飾りの動きを全部**：表紙の動画（72px の丸・右下 1.5rem）のボタンが、帯の `animationPlayState` も paused にする。aria-pressed・aria-label・アイコンを状態で替える。reduced-motion と saveData でも同じ状態から始める（本家はしていない）。
- **表紙は図形の無限の寄り**：ブランド色の星の中に同じ絵の枠があり、そこへ 4.46秒で寄ってくり返す。動画（1.35MB）にせず、層を倍率 k ずつ重ねて全部を `scale(k)` 倍まで寄せれば CSS だけでできる（部品 `.lpa-zoom`）。
- **丸い札のナビ3つ**（TICKETS・INFO・PROGRAM）：白い札・radius 50px・圧縮書体の大文字 30px、余白は上 .4em・下 .25em（大文字だけの行を目で中央に）。乗るとブランド色 .3s。SP では表紙の下端へ移して親指の届く所に。
- **章の題を1字ずつ起こす**：`rotateX(-90deg)`→0・.15s linear・軸は左下・1字 .05s ずらし。本家は読み込みで全部の題に走るので、IntersectionObserver で画面に入ってから（部品 `LPA.flipTitle`）。和文の題でも1字ずつで成り立つ。
- 色：トークンは `--brand-primary:#fff203`・`--surface-default:#e6e6e6`・`--border-color:#000` の3つ。黄は白い地で 1.17:1 なので字にせず、フッターの全面・帯の四角・題の左右の星・ホバーにだけ。ボタンは黒い丸（radius 10rem）、乗ると黄に黒字（17.95:1）。
- 文字：自前の圧縮書体（Flow Foundation）を大文字だけ・字間 0・行間 1〜1.2。題 83px（SP 49px）・写真の上の文 35px・札 30px・ニュースの題 24px・日付 14px。代替の Arial に `size-adjust:76.34%` と ascent／descent-override を書き、書体が届く前後で行の長さを変えない。代用は Antonio 700（国内のフェスでも SUMMER SONIC が使う）。
- ニュースの札：360px 固定・地 `#f2f2f2`・写真 240px・題 24px 大文字、`scroll-snap-type:x mandatory`。SP でも 360px のまま横に送る。
- 重さ：PC 5.17MB・40件／SP 4.07MB。表紙の動画 1.35MB（1920×1080・50fps・AAC 316kbps）を SP にも、送りの写真 818／880KB、会員の SDK 約 1MB。
- **反面教師**：h1 が無い（ロゴは alt=""）／reduced-motion で止まるのは View Transitions だけ／送りに止めるボタンなし・今の点 2.03:1／`pointerup` の処理で `e` が未定義／字の起こしが画面外でも走る／muted の動画に音声トラック／alt がファイル名／4書体（Poster Bold 93KB を字の 1% に）／下へ 1,000px で窓が自動で開く。
- 部品：`patterns/` の `.lpa-zoom`・`LPA.zoom()`・`LPA.flipTitle()`（既存の `.lpa-marquee` を帯に）。
- **作例で確かめた翻訳**（小樽・北運河の旧製氷工場の音楽祭「製氷所サウンド」・架空、2026-11-19）：段のロゴ SEIHYOJO／SOUND／OTARU をヘッダー（箱あり・3つ目を日付）・表紙（写真の上で箱なし）・フッター（箱あり）に。町の写真を錆の朱と氷の水色の2色に置き換えて全面に。帯は「第3製氷室・Quay・貨車庫・日付」。ステージは製氷所の部屋の名前のまま。触れる1つは時刻表で、部屋のあいだの徒歩（4・6・9分）から、重なる分数と聞き逃す分数を出す。
