# 黒い地の菓子の店・名前の字を章ごとに1字ずつ（色は暗く撮った物だけ）
Lune Croissanterie（lunecroissanterie.com、メルボルン発のクロワッサン専門店のトップ。WordPress の自作テーマ＋jQuery＋slick、2026-11-27 実測）の型。純粋な黒の地に、黒い布・黒い皿・黒い箱の上で暗く撮った菓子の写真だけで色を出す。章の題は置かず、店の名前の字を輪郭の線で章の端に1つずつ置き、下りきると名前が綴られる。

- **名前の字を章の目印に**：SVG の輪郭の字（L 144×202・U 158×204・E 144×202、線 1px #fff・塗りなし）を章ごとに1つ。字の数と章の数をそろえる（本家のトップは N の章を外して「LU E」になった。About には L・U・N・E がそろう）。
- **字と文を違う速さで**：移動 =（要素の中心 − スクロール位置）×（速さ − 1）。字 .875・宣言／本文／ボタン 1.0625・写真 1。transform に 400ms cubic-bezier(.25,.46,.45,.94) を付けてなめらかに（本家は Chrome のマウスのときだけ、タッチは動かさない）。写真の中は枠の 112.5% の高さにして 12.5% だけ動かす。部品は `LPA.parallax(el,{center,self:true,smooth:true})`。
- **押せるものの印は ◇ と ○**：メニューは左の縦の真ん中に 24px の ◇（rotate(−225deg)、中の角 50%→75%）＋縦の Menu。ボタンは 220×72・線 1px #666→白、右下の角に ◇ が 0→1rem（250ms）。リンクは頭に 7px の ○ を塗る（250ms）。部品は `.lpa-notch`。
- **表紙**：右半分に今月の商品の写真、左に行動の2語 ORDER / NOW（8vw・行間 .65・字間 −.05em、2語目を 1.73em ずらす）。写真は黒の幕を translateX(−100%)、中の写真は +6rem→0、どちらも 1600ms (.215,.61,.355,1)。文字は 3rem 右から 1200ms・遅れ 400ms。
- **宣言**：5行の英文 50px／70px を行ごとに span にし、3rem 右から 1600ms、遅れ 250ms から 50ms ずつ。画面の 2/3 に来たら1回。
- **写真3枚の段違い**：左上・中下・右上（高さ 62.5%、幅 33% − .75rem）。10vh 下・skewX(−5°) から 1200ms (.07,.51,.12,1)、500／600／700ms ずらし。slick の speed 0・fade で3枚ずつ、送りは点（今は 11px の輪、ほかは 3px の点）。
- **読み込みの輪**：r27・dasharray 170 を、読み終えた物の段ごとに 170→90→70→40（4000ms linear）→0（600ms）。
- **店の一覧**：「— 地区名」＋住所の2行を1つの地図へのリンクに、右寄せで並べる。
- 文字：DIN Next LT W01 Bold／Regular の2本（fast.fonts.net、woff2 31＋29KB）。太さは書体の名前で切り替え、font-weight は全部 normal。代用は Barlow 700／400。
- 色：#fff 41 回・#000 26 回・#666 7 回・#a4a4a4 3 回、有彩色はフォームのエラー #990000 の1回だけ。
- 重さ：PC 4.89MB・SP 3.72MB（measure.js）、解析込み 7.04MB／5.50MB。写真は JS が幅で srcset から選ぶので SP は 273KB。
- **反面教師**：reduced-motion 0、ORDER NOW が 20s で止まらない／SP の本文 12px（PC 14px）／メニューの選んでいない語 opacity .15 で 1.39:1／`data-cache-url=""` で同じ HTML を2回／トップで WPForms 一式と zxcvbn 803KB／使わない Figtree を読む／alt 全部空・src は JS が入れるまで空／audio 要素が無いのに音のコード／スクリプトのエラー（inspect FAIL 3）。
- **作例で確かめた翻訳**（FOUR・神戸の鯉川筋でバゲットとカンパーニュの2つだけ焼くパン屋、2026-11-27）：名前 FOUR（フランス語の「窯」）の4字を4つの章に、黒の地を「窯の煤」#16110d として理由づけ、字は粉の白・差し色は焼けた皮 #d9924a。最初の画面は明るい写真が 70% を覆うようにし、左 30% の煤の面に2語「バゲット／カンパーニュ」。触れる1つは日本時間で次の回に印を付ける「今日の焼き上がり」6回。inspect FAIL 0・WARN 4（文字の段・dark-first）。
