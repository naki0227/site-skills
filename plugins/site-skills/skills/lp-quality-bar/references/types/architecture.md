# 建築の会社・分野の札を横に流す（建築設計事務所・工務店・インテリア・ランドスケープの会社のトップ）
LPAS（lpas.com、米国サクラメントの建築設計事務所、Awwwards SOTD 2026-10-10）の実測。仕事の「分野」を同じ形の札にし、札ごとに地の色を替えて、ページの1区間だけ横に流す型。
- 色：UI は白・`#111`（本文 18.88:1）・`#262626`（暗い面）・`#747474`（補助 4.67:1）・`#d6d6d6`（罫 1px）。有彩色は「分野」のトークンだけで、`[data-marketcolor]` の1つに地・淡い地・文字・反対の文字の4変数を持たせる（Housing `rgb(98,86,83)`／白 7.06:1、Interiors `rgb(146,84,52)`／白 5.93:1、Higher Education `rgb(201,211,223)`／`#262626` 9.99:1、Civic `rgb(112,117,105)`／白 4.73:1、Commercial `rgb(227,193,170)`／`#262626` 8.99:1）。文字は地ごとに白か墨を選び、比を 4.5:1 以上に。
- 線と箱：罫は 1px `#d6d6d6` の横だけ。影 0。角丸は丸ボタン（50%）と Menu（6px）だけ。最初の3画面の枠線 5。
- **面取り**：大きい写真だけ、左上か右下を `clip-path:polygon()` で斜めに欠く（`--cut` 実績 6rem・ローダー 4rem・縮図 2rem）。ロゴの斜線と同じ角度の言葉。
- 文字：1書体（Aeonik → 代わりは Hanken Grotesk）、weight 400、日付と小見出しだけ 600、字間 0。段は 75/1・56/1.1・50・38/1.1・28/1.3・本文 16/1.35・14・12（SP は 46・44・32・28・24）。大きな題と 12〜16px に分かれ、中くらいは 28・38px の2つ。`html{font-size:62.5%}` に `clamp()`。
- 構成：表紙（全面の映像、細い文字3つ 14px、左下に h1 75px）→ **分野の札5枚を横に**（PC：771×900 の札、上が写真・下 285px が分野の色、縦のスクロール 4,520px で送る。SP：390×275 の札を縦に積み、写真は右 28%）→ はじめに（56px の題、左に手順の4語 14px、右に本文 16px）→ 実績（大1＋小2 を2段、左右を入れ替え、分野の絞り込みに件数）→ お知らせ（罫の行：題・抜粋・日付・矢印）→ フッター（全面の写真に住所・電話）。問い合わせのボタンは最初の画面に置かない。
- 動き：GSAP＋ScrollTrigger＋Lenis＋Swup。横送りは `pin`・`scrub:.5`・`end=幅×3`、列を `xPercent:−100×(n−.8)` で直線、表紙に黒 0→.6 の幕。札ごとに行の高さ「50% 50%」→本来、写真 1.3→1倍、題はぼかし 10px・.5s（戻りは2倍速）。流れ切ったら表紙の映像を止めて `src` を外す。**社名の頭文字のローダー**（L・P・A・S が .2s ずつぼかし 10px から .6s、残りの字 1.3s で Listen・Plan・Analyze・Shape に。セッションに1回）。CSS は `.3s cubic-bezier(0,0,.13,.99)` 19回：丸ボタンの塗り（`top 100%→0`・角丸 100%→25%）、矢印の丸（29→37px、矢印が入れ替わる）、線のリンク（2本目が −105%→0）。写真に乗るとカーソルが 110px の「Explore」の丸（`#0e0e0e99`・ぼかし 10px、`pointer:fine` だけ）。
- 重さ：PC 7.75MB・SP 6.55MB（転送 5.73／5.56MB）＋1080p の映像 33.2MB。写真は WordPress で切った WebP を lazysizes が幅で選ぶ。
- **反面教師**：SP の縮図（100×68）に 2500px の原寸 JPEG 5枚・3.08MB を `srcset` なしで、PC では `display:none` なのに読む。GSAP に reduced-motion が0（ローダー約5秒とホイールの停止、横送りが reduce でも動く）。映像は SP にも 1080p、ローダーと表紙の2つの video が同じ URL。Swup の先読みで 28 ページの HTML。お知らせの抜粋 14px・`#747474`、暗い面の `#747474` 3.24:1。見える写真の alt が空、woff を woff2 より先に書く。
- 部品：`patterns/` の `.lpa-cut`（面取り）、`LPA.hscroll(section)`（縦のスクロールで横に流す。reduce・saveData・SP は縦のまま）。
- **作例で確かめた翻訳**（さしがね設計室・架空、2026-11-02）：分野の4色を題材の色（杉・藍・墨・雪）にし、色相は2つ。札の写真の場所に、その分野の数字（積雪 1.2m・床 30mm・梁 7本・112㎥）を大きく置くと、写真が無くても札が立つ。頭文字の手順は和文では「測る・描く・刻む・建てる」の頭の字を先に出す。
