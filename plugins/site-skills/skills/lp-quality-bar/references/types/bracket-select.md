# セレクトショップ・括弧で挟む誌面（白地に墨と赤1色）
味覚編集。（mikakuhenshu.com、食材のセレクトショップ、Shopify＋自前の main.js 55KB、2026-11-14 実測）の型。選んだ物を、雑誌の注のような括弧で挟み、札の間に店の動詞をローマ字の音で立てる。PC 14,191px・SP 8,803px。
- **並べた物を1つの括弧の形で挟む**：左の「(」の SVG 1つを `scaleX(-1)` で右に使い回し、色は `currentColor`。商品写真 87px・ボタン 37.6px（白のピル 269×46 の外に −8.45px 重ねる）・手順 84.4px・ピン留めの小窓 84.8px。挟んだ物が「選んで注を付けた物」に見える。
- **店の動詞をローマ字の音に分け、札の間に縦に1つずつ**：MI・KA・KU（味覚）／SHO・KU・ZAI（食材）／YO・MU（読む）／NO・KU・ZO（覗くぞ）。Libre Baskerville 20px（SP 16px）・字間 .06em・`vertical-rl`＋`sideways`。送ると単語になる。読み上げでは `aria-hidden`。
- **表紙の題は手で描いた1色の線**：細長いセリフを SVG の path で直書き（赤 #e81c14、幅 459px の設計＝1440px で 551px）。写真7枚の上に 10% の黒を1枚。左右の縦の一言（和文 21px 600・英語 18px）で題を挟む。最初の画面にボタンは無い（SCROLL の丸と 01〜07 だけ）。
- **ピン留めの区間で写真を下から拭き、小窓を同じ割合で横へ**：助走 3.4 画面（SP 2.4）。最初の 25% で枠を画面に合わせて拡大（`1−(1−t)²`）、写真ごとに止まる区間と切り替える区間 .11、上の縁 14% をマスクでぼかす。真ん中の括弧の小窓は `translateX((i−位置)×100%)`。
- 数え方は分数（57.7×28.3、1px の線を −19.47°）。英字の副題は階段（2行目 2.1em・3行目 .35em）。商品の説明は「」の一言から始め、産地と作り手が続く。タグは墨の地に白字の四角。
- 色：トークン2つ（`--ink #1a1a1a` 92回・`--red #e81c14` 30回）と白。赤は題・#番号・カートの数・ホバーだけ。白／赤 4.56:1、墨／白 17.40:1。章の端に銀の帯（液体金属の写真 35×278px）を置き、色を増やさずに光る物を足す。
- 文字：3書体。Noto Serif JP（描かれた字の 78%）・Libre Baskerville（20%）・Roboto Condensed（2%）。章の題 31.3px（英 Libre 400／和 600）、コンセプトの本文 16px/2・500。
- 動き：ライブラリ0。送り .8s `cubic-bezier(.22,1,.36,1)`・5秒ごと（乗る・タブが裏で止まる）、編集者の送り 1.75s `cubic-bezier(.83,0,.17,1)`（幅と高さも）、表紙の写真 1.6s ease・6秒ごと、ボタン .3s。スクロールの「登場」は無い。

- **作例で確かめた翻訳**（古書 縄手堂・架空の松本市縄手通り、2026-11-14）：括弧は古書目録の「（初版・函・帯欠）」の状態の括弧に、ローマ字の音は YA・MA・NO・HO・N（山の本）の棚出しに、ピン留めは蔵の買い取り（蔵の会館・書庫の写真）に、銀の帯はグラシン紙の半透明の帯に。表紙は売るときに押す判の朱 #c8361d の地に、幅いっぱいの「縄手堂」と、古い本の背の写真を本の輪郭で切り抜いて朱と墨の2色にした主役を前後に重ね、白い括弧で挟む。触れる1つは背表紙を押すと目録の札（目録番号・状態・鉛筆の値・棚の場所）が出て取り置きを頼める棚。
