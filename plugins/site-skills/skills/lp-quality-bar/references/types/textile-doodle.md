# 服とテキスタイルのブランド・ロゴの横の手描きと、来るたびに替わる1枚
minä perhonen（mina-perhonen.jp、Nuxt 3 の SSR＋jQuery 1.12.3、2026-11-18 実測）の型。白い地と墨の字だけで組み、色は図案と写真に任せる。作り込みは大きな演出でなく、**手で描いた小さな物の扱い**（ロゴの横の線のコマ送り・来るたびに替わる1枚・図案が動く表紙）にある。
- **ロゴの横に手描きの線のコマ送りを1本**：GIF 5本（ちょうちょが羽ばたく／芽が伸びて花が咲く／飛び回って止まる／着地する／切り株に火がともる）から `mounted()` で `Math.random()` の1本。1本 22〜101KB・5〜11fps・3〜9秒、a だけくり返し、b〜e は1回で最後のコマに止まる。線1本の黒でロゴと同じ色、PC は幅 450px でロゴの左上、SP はヘッダーの下線の上に乗る。真似るときは SVG のコマを opacity で切り替え、画面外・reduced-motion では最後のコマだけ（部品 `LPA.doodle`）。
- **章の1枚を来るたびに替える**：Fashion 12・Textile 20・Life 5・展覧会 2 枚から1枚。同じ場所・同じ大きさ（875×583、角丸 3px）で中身だけ替える。本家は SSR の既定の1枚・PC の1枚・SP の1枚を全部落とす（1章で 1〜3MB の無駄）ので、選んだ1枚にだけ src を入れる（部品 `LPA.pickOne`）。
- **表紙は図案そのものを動かす**：写真でなく、テキスタイルの図案（メリーゴーラウンドの馬）を動かした 17秒の動画（875×492）。線の図案なら SVG の帯を transform で流し、一文は焼き込まずに文字で重ね、止めるボタンを置く。
- **章の題は小さく細く、1枚を大きく**：題は高さ 26px（100px の PNG を縮めた画像）、下 65px、写真は列いっぱいの 875px。題と写真はおよそ 1:22。
- **左の目次を塊で空ける**：12語を4つの塊（作る物／店／読みもの／会社）に、語の間 14px・塊の間 36px。Helvetica Neue 14px・500・字間 .1em・大文字。列は 200px＋25px＋875px（最大 1130px）。
- 色：UI は墨 `#212121`（16.1:1）・罫 `#bdbdbd` 1px・白の3つ。有彩色は CSS にほぼ無い（Pure.css の残りだけ）。角丸は写真もボタンも 3px。
- 文字：和文は游明朝（無ければ Noto Serif JP）500、英字の見出しは adobe-garamond-pro 24px、目次と日付は Helvetica Neue。見出しは「2026-2027 → Autumn / Winter Collection」（→ は sup）の下に「光輝く 深い森」の2段。お知らせの題 16px/24px。
- お知らせ：明朝の題・日付とカテゴリー1行・右に写真の欄 22.6%（左 21px）、行の上下 25px と罫 1px。乗ると opacity .7。
- 動き：CSS はほぼ動かさない（hover .7・目次の color .6s・SP のメニュー opacity .6s・先頭へ 500ms）。動きは GIF と動画に任せる。
- 重さ：PC 24.08MB・150件／SP 22.94MB。動画 9.27MB（1440×810・4.1Mbps・音声つき）、JPEG 12.7MB（章の写真は 1750px の JPEG を 875px に）。
- **反面教師**：reduced-motion 0・17秒の動画に止めるボタンなし／来るたびの写真を3回落とす／SP にも 1440×810 の動画と使わない音声／日付 10px #999（2.85:1）が文字の 60%／一文を動画に焼き込む／Typekit を CSS と JS で2回（171KB×2）／和の題の機械の斜体／SP で単語の途中の折り返し 41か所。
- 部品：`patterns/` の `LPA.doodle()`・`LPA.pickOne()`。
- **作例で確かめた翻訳**（浜松の注染の手ぬぐい工房「かわせみ舎」・架空、2026-11-18）：表紙は型紙の写真を全面に、竿に干した手ぬぐいの絵を主役に斜めに大きく。その柄が来るたびに4柄から替わり（型2）、17秒で揺れる（型3）。名前は写真の外の白い帯に、横に手描きの線（かわせみ・千鳥・干した手ぬぐい）のコマ送り。触れる1つは「注ぐ」：染料を選んで糊の土手の中を押すと広がり、2色が出会うとぼかしになる。章の題は「柄・注ぐ・型紙・干し場の日・便り・店」の1語を 26px で。
