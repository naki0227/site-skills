# ギャラリー・暗室（美術館、展示、写真家・作家のポートフォリオ、作品・施設が主役のブランド）
teamLab（teamlab.art/jp）の実測。UI は暗室に徹して、色は作品の写真だけに持たせる型。
- 地は純黒にせず、同じ色味の3段：`#0e0f0e`（地・39回）・`#181a18`（一段明るい面）・`#222422`（カード）、開くメニューは `#171717`。文字は白 `#fff`（19.2:1）と補助 `#999`（6.7:1）だけ。縁は `#5a5a5a`（2.8:1、文字には使わない）、罫は白12%。**UI に有彩色を1つも置かない**（`data-mood="gallery"`）。
- 写真の上の文字は、白い札（11px・700・padding 12/10px・最小幅100px、終わったものは黒地に白）か、下へ透明 → 黒32% のグラデで読ませる。
- 文字は Webフォントを読まず、システムフォント（`Helvetica, Arial, ヒラギノ角ゴ Pro W3, 游ゴシック, メイリオ…`）。最大でも 20px（見出し・700）、表紙の題 16px、カードの題 14px・行間1.6、日付と場所 12〜13px `#999`、ナビ 12px・字間 .02em・大文字。太さは 400 と 700。
- 構成は写真の並べ方だけ：表紙1枚（高さ `calc(100dvh − 180px)`、下に60pxの帯）→ 開催中の6枚（3列・すき間 2vw・16:9）→ WORKS 15枚（3列・すき間 10px・100:67、SP は 1:1 の1列・すき間0）→ フッター。説明の文章を置かない。
- 動きはカーブ1つ：`cubic-bezier(.215,.61,.355,1)`（easeOutCubic、184回）に .24s（色・矢印）／.36s（薄れる・反転）／1s（写真の拡大）。作品のホバーは写真が `opacity:.6; scale(1.05)`（transform 1s・opacity .36s）、中央の題が .36s で浮かぶ。タッチ端末では題を下に常に出す。ナビは `opacity:.5`、「もっとみる」は白黒反転。
- 登場は `scale(1.03)→1`（表紙・2s ease）と `translateY(40px)→0`（帯 2s、カードは1行ごとに 1s ease・同じ行は同時）。読み込み中は写真の枠の中に 24px の輪（`#3d3d3d`／一辺 `#707070`・1s linear）。
- 写真は AVIF、`srcset` 8段（640〜3840w）、`sizes` は 33.333vw / SP 80vw。3.75MB（SP 3.45MB）の半分が写真、半分が JS。
- **反面教師**：表紙の写真まで `loading="lazy"`（`fetchpriority` なし）／日本語のページでアラビア文字のフォント 162KB を preload／`_app` の JS 834KB に全言語の文字列／最初の HTML の23個が `opacity:0`／reduced-motion・saveData は0、素の `:hover` 77か所／不正な `cubic-bezier(.215,.61,.3)` が7か所（宣言ごと無効）。
- 部品：`data-mood="gallery"`、`.lpa-thumb[data-reveal]`。
