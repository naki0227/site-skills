# ミッション型の食品ブランド・大声の見出しと四辺形の札（原色の地）
Tony's Chocolonely（tonyschocolonely.com の世界向けトップ、オランダのチョコレート、Shopify＋Tailwind＋自前の customElements、2026-11-09 実測）の型。会社の目的（カカオの搾取をなくす）を大声の見出しで言い、商品は包み紙の色の札で見せる。PC 3,587px・SP 6,369px。
- **大見出しは行ごとに幅いっぱいへ計算する**（`fluid-heading`）：語を行の数（`data-lines="SP,PC"`、768px 未満が SP。例 "2,1"）で等分し、行ごとに 8px で組んで幅を測って `8 × 入れ物の幅 ÷ 測った幅` px。短い行ほど大きく、SP では1つの見出しに 51px と 106px が並ぶ。上限（SP 110・PC 200px）は「3文字未満の行」か「全体5文字以下」だけ。行間 .85em・字間 0・大文字だけの手作りの書体（Chocolate letter 400、45KB）。PC の実測 111.9〜223px。章の頭5つすべて。
- **札は回さずに角をずらす**：`clip-path:polygon()` の1〜2つの角を内へ（国の札 10px・商品の地 4px・記事の枠とボタン 2px・モーダル 19.2px）。クラス名の4桁が左上・右上・右下・左下のどれをずらすか（`clip-1200`・`clip-0100`・`clip-_00_` など）。`nth-child(1n/2n/4n)` で組を替える。影 0・角丸 0、輪郭は地との差だけ。
- **乗ると包み紙が3コマで破れる**：商品の札（336px 角）で、包み紙の画像の層に `@keyframes` で `clip-path:url(#mask-1)`（30%）→ `mask-2`（68%）→ `mask-3`（100%）を .6s forwards。下に割れた板の画像。離れると JS が逆の順の keyframes を足す。
- **動きはコマ落とし**：メニューは本文の入れ物ごと `translateY(100vh)` を .3s `steps(3,end)`、横送り steps(2)、ほか steps(6)。色の変化だけ .15s `cubic-bezier(.4,0,.2,1)`。スクロールで出る登場は無い。
- 色：トークン6つ（黒 #000・青 #006BE1・灰 #F1F1EC・赤 #EB0000・白・黄 #FFED00）。章の地は 青→白→赤→赤→白→赤 で罫も余白の帯も無し。多色（橙 #FF7400・紫 #6464BE・緑 #009E00・黄緑 #78C828・桃 #FF60A6）は商品の札の地だけ。白／赤 4.63:1、白／青 5.01:1、黒／黄 17.37:1。
- ボタンは1種類：黄の地（`::before`、右下を 2px ずらす）・黒字 22px/24px 700・padding .75rem 1.25rem。乗ると字に下線 3px・offset 5px だけ。使えないときは黒の破線の枠。
- 文字：2書体。大見出しの手作りの書体と、残り全部を American Typewriter 600/700（PC 28/22/18/15/13px、SP 26/18/14/11px）。描かれた字の 94% が後者。
- フッターに冗談の札：`***` で区切った3つから前回と違うものを押すたびに1つ、ボタンは「meh..」。
- 重さ：PC 5.78MB・SP 5.82MB（解析タグを除く）、解析タグ込みでスクロール後 7.37MB。JS が 81%（トップでも Shopify のチェックアウト 1.9MB、本番に marker.io 427KB、Sentry 154KB）。画像は AVIF/WebP で 395KB だけ（全部 lazy・`sizes` あり）。
- **反面教師**：着くと国を選ぶ札と cookie の札が重なる／CSS・JS とも reduced-motion 0／大見出しが `invisible` で始まり JS と書体を待つ／SP の注記 11px が 48 か所／青の地に黒字 4.19:1（ナビ）／preload の URL に `?v=` があり `@font-face` には無く、書体3本を2回ずつ読む（152KB の無駄）／ナビの吹き出しで横スクロール（PC 1467px・SP 417px）／alt がファイル名。
- 部品：`patterns/` の `LPA.fitLines(el,{lines,rows})`（行ごとに幅いっぱい）、`.lpa-slant[data-quad]`（`--lpa-quad` で角をずらす札）。
- **作例で確かめた翻訳**（干し芋の工房ひらべた・架空の茨城県行方市、2026-11-09）：表紙は飴色 #ffd27a の地に、幅いっぱいの「ひらべた」（Noto Serif JP 700、PC 344px・SP は2行）、手前に破れた紅の紙袋からこぼれる平切りの干し芋の絵（縁は紅はるかの皮の紅 #a81d44）、判子「規格外も同じ値」。包み紙は紙袋の封に（押すと在庫を確かめて3コマで破れ、畑と買い取り値が出る）、札の四辺形は工程と買い方の札に、冗談の札は干し場の壁の札に。色は紅・飴・墨の3つ。
