# ポップ・料金プラン（サービス）（通信・サブスク・アプリ・会員制のサービス、プランを選ばせて申し込ませるトップ）
povo（povo.jp、KDDI のオンライン専用プラン）の実測。淡い章の地を弧で切り、押せる物だけを濃い色にする型。
- 色：文字は `#333` の1色（描画後の文字の 86%、白と 12.63:1）。地は白と淡い章の地（灰 `#f4f4f4`・黄 `#fffed4`・橙 `#fff1dc`・`#f6f6f6`、`#333` と 11.3〜12.3:1）。濃い黄 `#fffa00` と緑 `#64c8a0` は**ボタンにだけ**、札（選べる中身）は黄・橙・紫の面。
- 章の上辺の弧：章に `position:relative`、`::before` に同じ地の楕円 `width:140%; height:100px; top:-35px; left:50%; transform:translateX(-50%); border-radius:50%`（なだらかにするなら高さ 200px、950px 以下は `top:-3%`）。四角い箱で区切らずに章が替わる。
- ボタンは1つの約束：角丸 50px・高さ 56・幅 400（SP 290×49）・右端 12px に 24px の丸い矢印・**真下に 3px の同系の濃い影**（黄 `#fffa00`/`#ceca14`、緑 `#64c8a0`/`#43a77f`、灰 `#f0f0f0`/`#ccc`、白は縁なしで `#ccc`）。メニューの6枚（185×155・角丸27px・下影 `#e0e0e0`）も同じ影。本家は押しても沈まない（ホバー opacity .6 だけ）→ 押したら 3px 沈める（`.lpa-offset[data-under]`）。
- 主な行動はプランごとに2つ（「通話＋データ」黄／「データ専用」緑）。最初の画面に1つ＋2つ、**画面の下に白80%・高さ75px の帯で固定**。ヘッダーは画面の2/3を過ぎて下へ進むと隠れる（.2s）。
- 構成：お知らせ（開け閉め）→ 表紙の送り（キャンペーン5枚、PC 2800×905・SP 1200×1500 を `<picture>` で）→ 申し込み＋メニュー6枚 → キャンペーン（灰の弧）→ サービスとは（黄の弧、マスコット、3つの約束）→ 選べる中身（札3枚、「いろいろ」を4色）→ 3STEP（列の地を白 → `#fffef0` → `#ffffb5` と濃く）→ おススメ（中央を大きく送る）→ ニュース → 関連リンク → 注意事項。
- 文字：Noto Sans JP 400/700/800、英数字だけ幾何学的な大文字（LEMON MILK Pro → 代わりは Lexend）。題 26px／1.5・700・字間 .015em、STEP の題 24px・800、小見出し 20px。本文の字間 .035em。
- 動き：表紙の送りは Splide（loop・5秒・.4s `cubic-bezier(.25,1,.5,1)`）に**点の横の一時停止（黒丸32px）**、Splide の既定値で reduced-motion なら最初から止まる。おススメは中央以外を scale(.8)・opacity .5（.3s ease-in-out）。時間は .2 / .3 / .4s。
- **反面教師**：本文 14px（SP 12px）・注記 10px `#a6a6a6`（2.43:1）。色の文字（「いろいろ」1.83〜2.40:1、「基本料0円」2.11:1）。タグが 69 ホスト・約11MB（自前 3.07MB）、チャットの `<script>` が2つで設定を2回、同じ id が4つ。表紙の最初の1枚が lazy。PC と SP の部品を両方 HTML に置く。CSS に reduced-motion・`hover:hover` が0か所、ヘッダーは `top` を動かす。
- 部品：`.lpa-offset[data-under]`（真下の影・押すと沈む）、`.lpa-arc`（章の上辺の弧）、`LPA.centerSlider(el,{pause, scale})`（止めるボタン・中央を大きく）。
