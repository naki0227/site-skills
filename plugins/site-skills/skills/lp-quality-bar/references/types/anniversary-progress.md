# 周年の特設・記事の番号で目標の数へ進む（レトロな赤の掲示板）
日東紅茶100周年特設サイト「NITTOH 100 PICNIC」（100th.nittoh-tea.com、STUDIO 製、2026-11-06 実測）の型。周年に向けた「100のアクション」のうち、いまいくつ進んだかを、表紙の数字と記事カードの通し番号で見せる。トップは表紙（500px）と記事カードの格子（5,244px）だけ（PC 6,762px）。
- **表紙に進み具合の数字**：右の柱の下に「13/100 PROGRESS」。Unna 700 の 112 / 48 / 14px（7.78vw / 3.33vw / .97vw）、行間 .65、字間 −.02em。表紙は3列（左の柱 186px：ロゴ・周年の印・メニュー 20px／中央：ロゴタイプ SVG 996×429／右の柱：「今コレがおすすめ!!」の札・丸い写真 158px・数字）。
- **記事カードの大きな通し番号**：3列（SP 2列）の格子、1枚 482×918（サムネ 570・下 348）。題 24px（最大4行）の右下に 112px（SP 64px）の番号を、新しい順 13→01。番号は表紙の数字と同じ数え方。並びは `<ol reversed>` にすると意味が通る。
- **記事ごとの地色と額縁の形**：サムネを6色の地（#584862・#345947・#f08230・#f5cd20・#6bb8d0・#e60012）に塗り、写真をアーチ・盾・三角・楕円・窓の形に切って置き、上か下に一行の札。撮り方がばらばらの写真でも一覧がそろう。札の文字は地と 4.5:1 を計算する（本家は 1.72〜2.17:1 が混じる）。
- **文字と線を1色で組む**：文字・罫・ボタン・ロゴは赤 #e60012 の1色（文字色の 74%）、地はクリーム #f3e7d7。区切りは 1px の罫だけ（172要素）、影・グラデーション 0、角丸は楕円 100px と丸 50% だけ。多色はサムネの地に閉じ込める。**ただし赤とクリームは 3.94:1**：24px 以上と線・面だけを赤にし、本文と注記は同じ色相の #9e000d（7.0:1）に下げる。
- **流れる一文の帯**：44px の赤い帯に斜体の一文を 30px/s（Web Animations、312px＋間を 11.2秒）。脚注では線のロゴタイプを同じ速さで流し、ページの最初と最後を同じ帯で閉じる。
