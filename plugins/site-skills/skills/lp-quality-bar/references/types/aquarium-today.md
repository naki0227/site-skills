# 水族館・おでかけ施設・今日の時刻が表紙で、写真の柱を波で区切る
すみだ水族館（sumida-aquarium.com、Astro＋GSAP ScrollTrigger＋Lenis＋Splide、2026-11-20 実測）の型。来る人がいちばん知りたい「今日は何時まで・次は何が何時から」を表紙の右下に出し、下の章は「左に写真の柱・右に大きな英字の題」を、波の帯で区切って重ねていく。色は紺と青の2段に白い字、差し色は1か所だけ。
- **表紙の「本日」**：表紙（100svh・最小 620px）の右下に、本日の営業時間（数字は Prompt 700・PC 36px／SP 24px・字間 .08em）・入場受付の締め切り（閉館の60分前を計算で出す）・次のプログラム（まだ過ぎていない最初の1つ）を出す。暦と回は CMS から。**「今日」と「過ぎたか」は施設の時間帯（Asia/Tokyo）で計算する**：本家は端末の時計（dayjs・`new Date`）なので、ロサンゼルスの端末では前の日の 10:00–18:30 と、東京ではもう終わった 16:00 の回が出た（部品 `LPA.today`）。
- **表紙は60組×3枚から1組を乱数で**：Splide の fade・interval 7000ms・speed 4500ms（ゆっくり溶ける）・rewind。画面外では止める（rootMargin 100%）。PC と SP で別の切り出し（1905×1111／780×1326）。ロゴとコピーは SVG の img（alt あり）を `<hgroup>` の h1 と p に。
- **左に写真の柱・右に英字の題**（PC）：写真 660×870 を sticky で左（x 15px）、題は x 751px から。題は Prompt 900・76px（SP 40px）・字間 .08em・行間 .75、すぐ下に和の小さな添え字（10〜12px）と1〜2行の説明（PC 22.9px・700）。章の真ん中（`top+=高さ/2` が画面の 55%）を越えると、柱の写真を2枚目に opacity で替える。SP は柱を章の頭の写真にして、2枚を 1.8s ごと・2.2s power1.out で溶かす（見えている間だけ）。
- **章の境目は波の帯で、次の章が前の章に重なる**：波は 2230×254 の画像を2枚横に並べ、`x:-50%` を 20s linear でくり返す。**スクロールの速さで流れる速さを変える**（`timeScale(1+clamp(-100,100,velocity×.01))`）。章は `pin`・`pinType:"transform"`・`pinSpacing:false`・start "bottom bottom"・end "bottom -50%" で止め、次の章（上に 25vh の余白・最小 100vh）が波を先頭に被さってくる。波の高さ PC 164px／SP 44px。
- **ボタンのホバーで波が下から上がる**：波の SVG（420×160）を `translate(-20%,100%) rotate(15deg)` → 0 に .4s ease-out、出るときは `translate(5%,100%)`。`:focus-visible` でも同じ。白地に紺字のボタン（PC 190×61・角丸 7.6px）。
- **館内図は等角の線画に丸い写真のピン**：6F・5F を白い線だけの等角図にし、見どころを丸い写真のピンで指す。階の札は Prompt 38px。
- 色：紺 `#036`（12.61:1 で白い字）と青 `#307ecc`（白い字 4.22:1。**本文は載せず大きな字だけ**）・`#1762ac`（6.21:1）の章を交互に。ボタンは白地に紺字。差し色は黄緑 `#e2ff00` を「並ばず買える」の札1か所だけ。色は primitive（sumida-50〜1200 の12段）と semantic の2層のトークン。
- 文字：Noto Sans JP（本文・題の和文）＋ Prompt（英字の題・数字）。大きさは 1512px の画面で決めた値を `clamp(.75rem,min(1rem,1.0582vw),1rem)` のように「幅に比例・上限で止める」。PC の本文 14.3px・SP 12〜14px は小さい（下の反面教師）。
- 重さ：転送で PC 最初 11.1MB・最後まで 22.3MB（SP 10.1／20.7MB）。うち microCMS の写真 16MB（原寸 6864×4705 を `?fm=webp` だけで 272×164 の札に）・チケットの札の SVG（中に画像）487KB×3。
- **反面教師**：端末の時計で「今日」を決める／91日分の予定（1,422件・アイコンの SVG 1,100個）を HTML に入れて 3.99MB（転送 108KB でも、解いて組むのは端末）／同じ予定の JSON 1.65MB を JS にも／400ms のローダーの点のために lottie 300KB／写真の原寸配信／表紙の写真の src を JS が入れるまで空（LCP が遅れる）／reduced-motion は Splide の自動送りだけ（波・柱の溶け・Lenis は止まらない）／SP の文の 40% が 13px 未満／見出しの上の日付と NEW（eyebrow）。
- 部品：`patterns/` の `LPA.today()`・`LPA.todayBoard()`（既存の `.lpa-wave`・`LPA.wave()` を章の境目に）。
- **作例で確かめた翻訳**（長野の山のロープウェイ「雲雀岳ロープウェイ」・架空、2026-11-20）：本日の時刻は表紙のカードにせず、名前の下の1行（「本日 8:30–16:45　次の上り 10:15」）に。波は稜線の線に、写真の柱は山の写真1枚に、英字の題は駅名標の組み方（大きな和文＋小さなローマ字）に替えた。触れる1つは、15分ごとの発車と7分の乗車から「いま2台のゴンドラが線のどこにいるか」と次の便を日本時間で出す路線図。
