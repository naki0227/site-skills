# 素材の会社・見本帳が表紙（紙・布・タイル・木・塗料などの素材の商社やメーカー、B2B の老舗のコーポレートのトップ）
竹尾（takeo.co.jp、紙の専門商社）の実測。題材の「見本の束」を表紙にして、それ以外の UI を墨・灰・白と細い文字で黙らせる型。
- 色：文字は緑がかった墨 `#161f20`（CSS で51回、白と 16.79:1）、日付・線の矢印は `#707070`（4.95:1）、章の面 `#f6f6f6`、地は白。**有彩色の UI は0**。色は見本帳・水辺・紙の写真だけが持つ。章の境目は白↔`#f6f6f6` の1段の差だけ。枠線は最初の3画面で1本、角丸0、影0。
- 表紙：見本帳の小口（紙の束の端の色の並び）の写真を全面（画面の高さ − ヘッダー、PC 828px）。3枚から読み込みごとに1枚。文字はロゴだけで、1000ms 待って 1000ms で出る。下端に「NEWS｜日付 題 詳しく見る」の帯を1件。右下に縦書き SCROLL と伸び縮みする線（2s）。
- 文字：欧文 Inter、和文は細いゴシック（本家 AotoGothic の OTF → 代わりは Zen Kaku Gothic New 300/400/500）。weight 300 が基本、メニューだけ 500。本文 16/35px（2.19倍）・字間 .05〜.09em、ステートメントの題 26/48px・.08em、カードの題 21/45px、注記 14/23px。SP は題 20/34px・本文 16/32px。読点だけ字間 .5em（`.spacing`）。
- 章の題は「英字｜和文」：同じ 26px（SP 20px）、英字 Inter 400・.05em、和文 300。英字の右に 1px の縦線、右 18px・左 20px（SP 14 / 16px）。全部の章で同じ。
- 矢印は線：70px の 1px 線＋−42° に倒した 16px の線（カード右下 24px・23px）。「詳しく見る」も同じ線の右に文字。**塗りのボタンはページの中に1つも無い**。主な行動（見本帖オンライン）はヘッダー右端の灰の四角 110×72 に常設。
- 構成：固定ヘッダー（72px）→ 表紙＋お知らせの帯 → ステートメント（紙の写真の地、幅 760px の1段、18行）→ 事業（地 `#f6f6f6`、274px の正方形のカード8枚の横の棚、ドラッグできるバー）→ 全面の写真に白文字（475px）→ お知らせ（`#f6f6f6` の行、日付 170px｜題｜分類 180px、間 8px）→ 採用（文｜写真）→ お問い合わせ（写真｜文）→ フッター（`#f6f6f6`、5列・上に 1px の線）。同じ並べ方を続けない。
- 動き：押せる物の変化は opacity .5 だけ（.3s ease-in-out、矢印 .2s、四角 .15s）。メニューは乗った1つ以外を `#bebebe` に（color .3s）、サブは slideDown、サブの下線は 0→100% 1px を .5s `cubic-bezier(0,.7,.32,1.28)`。登場は WOW.js（offset 画面の20%）で章を fadeIn .6s、子を 30px 下から .6s ease-in-out で (i+1)×300ms ずつ。横の棚は Swiper 11（freeMode・mousewheel forceToAxis・scrollbar draggable）、SP はふつうの横スクロール。
- **反面教師**：和文の OTF 3本を間引かずに 7.04MB（転送 12.9MB の55%、Light と Medium は preload まで）。表紙の写真を `new Image()` で後から入れ、届くまで表紙全体が透明（先読みできない）。`.wow{opacity:0}` が無条件で、JS が無いと本文の章が見えない。reduced-motion 0・saveData 0（SCROLL の線は無限）。押すまで見えないメールニュースのために HubSpot と reCAPTCHA（約0.6MB）を読み込み時に読む。沈んだ色 `#bebebe` と言語の切り替えが 1.72〜1.86:1、白文字の四角 `#949495` が 3.0:1。SP のお知らせの題 14px・分類 11px。alt に `&lt;sup&gt;` がそのまま。ホバーを `min-width:769px` で分ける（`hover:hover` 0）。SP でも写真が表示の3〜4倍。
- 部品：`data-mood="sample"` トークン、`.lpa-split`（英字｜和文）、`.lpa-arrow[data-line]`（線の矢印）、`.lpa-dimnav`（ほかを沈めるメニュー）、`.lpa-rail`＋`LPA.peekRail`（横の棚）、`LPA.stagger(box,{delay:.3,y:30})`（登場）。
- **AIっぽさとの線引き**：英字の小見出しは「題そのものを英字｜和文の2つにして同じ大きさで並べる」なら手本どおり。題の上に小さな英字を載せる（eyebrow）のとは別物。表紙のロゴを読ませるために暗い板を置くなら、四角1枚だけにして影もぼかしも足さない。
