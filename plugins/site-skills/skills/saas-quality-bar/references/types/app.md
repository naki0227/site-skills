- 最初の画面の行動は1つ（「無料で開始する」／ストアの入口／「Webで無料登録」）にし、相談・資料の副は置かない（3件とも）。その1つは PC の 900px に入れる（TimeTree のバッジは y=1,121px で外）。SP は主をアプリに替え、下に帯で常に出す（マネーフォワード ME の 75px の帯）。
- 製品画面は言語ごとに作り直し、その言語の暮らしの値で埋める（Todoist /sequences/ja/、TimeTree hero_ja.png、マネーフォワード ME の「食費 ¥64,080」「ドラッグストア 田町店」）。キリのいい数（¥300,000・¥9,800,000）は避ける。
- 最初の画面で「誰の悩みが、どの画面で解けるか」を3組回す（マネーフォワード ME：利用歴7年・1年・13年の声と、家計・資産・共有の画面、28.233秒）。組の順を機能の並びとそろえる。文字は HTML にし、止めるボタンと reduce で止める（本家は画像で止まらない）。
- 機能は使う人の変化の段で並べ、メニュー・カード・ページの h1 で同じ言葉を使う（マネーフォワード ME「見える→わかる→前へ」）。
- 主ボタンが明るい色なら文字は黒（TimeTree #20d88c に #1a1b1c で 9.25:1）。白文字にするなら地を濃くする（Todoist #e34432 は 4.09:1、マネーフォワード ME #ed7100 は 3.02:1 で足りない）。押す物の色は1つに（マネーフォワード ME は橙と青の2色）。
- 無料と有料の違いは数か「何ができるか」で書く（Todoist「プロジェクト 5 → 300」、TimeTree「予定に PDF などを添付」、マネーフォワード ME「連携 4件まで → 制限なし」「閲覧 過去1年分 → 制限なし」）。比較表は区分ごとに列名の行を置き直す（マネーフォワード ME 6区分34行、Todoist）。
- 年払いの得は具体的に言う（TimeTree「2ヶ月分割引」）。払い方（Web／ストア）で値段が違うなら、全プランの両方の値段をカードの中に書く（マネーフォワード ME は注 11px でスタンダードだけ）。
- ストアで払うアプリは、料金ページで解約と自動更新に答える（TimeTree：FAQ 4問中3問が解約・「24時間前」「アプリを削除しても解除されない」、マネーフォワード ME：「無料期間だけ使える」「自動的にプレミアムにならない」）。無料体験の日数と回数も書く（2件とも日数なし）。
- 入口を「誰と使うか・何をしたいか」で分ける（TimeTree の利用シーン 8枚、マネーフォワード ME の目的別ガイド 4つ）。利用シーンのページは「悩み → 機能 → POINT → 有料が要る条件を FAQ で言い切る」（マネーフォワード ME「ふたりとも無料プランの場合…使えません。」）。
- 事例は運用の書式まで書き、無料で足りるなら章を立てて言う（TimeTree のバレエスクール）。
- 実績の数字の横に時点・調査元・人数を書く（マネーフォワード ME：マクロミル・2025年8月29日〜・1,034名、「約30万円」に 2,870名の平均値）。注は 13px 以上・4.5:1 以上で。
- お金・予定など預ける不安への答えを、全ページの締めの前に同じ形で置く（マネーフォワード ME の「安全への取り組み」3点）。
- 払い方で値段が違うなら、全プランの列に「Web 決済」「アプリ決済」の2段を同じ順で置き、両方の値段を書く（Moneytree：Grow 3,900円／4,300円。マネーフォワード ME は 11px の注でスタンダードだけ）。差額と税込かどうかもカードに書く（Moneytree は税の語0）。
- SP の料金は、区分のタブをヘッダーの下に貼りつけて1プランずつ縦に読ませ、おすすめはタブの点で示す（Moneytree：4タブ 90×48px・top:100px）。PC の表と SP のタブは同じ行のデータから作る（Moneytree は SP で MCP の行が消える）。
- 機能は「困りごとが消える題（h3）→ 仕組み1つの本文 → 下の章で機能の名前」の2段（Moneytree「うっかり使いすぎを防ぐ」→「カテゴリ別予算設定」）。
- 預ける不安への答えは番号つきの見出しと確かめられる値で（Moneytree：登録・認証番号・退会後24時間・規約変更1か月前）。

## 反面教師
- 主ボタンの白文字 4.09:1、小見出しの色 #6b9fa0 2.91:1・#78a271 2.87:1・#ee6449 3.15:1、料金の「月額」「$60 年払い」12px・3.05:1（Todoist）。
- 料金の切り替えの checkbox に名前が無い。SP のシートで通貨の select が AUD のまま、カードは US $（Todoist）。
- 割引の率を全プランで1つ（「約20%オフ」）にし、実際の率と合わない（プロは 28.6%）。税の表記がビジネスだけ（Todoist）。
- reduce で数字の帯を止めず 30s → 180s に遅くするだけ、製品の動画も止めない（Todoist）。
- 料金ページに買う・試すボタンが0、ヘッダーからも消える。価格は本文の一文の中だけ。税の表記なし（TimeTree /premium）。
- 比較表の ○ #20d88c が地 #e9fbf4 と 1.74:1、事例の緑の文字リンク 1.86:1、ホバーでボタンごと opacity .5（文字と地 2.36:1）（TimeTree）。
- 製品画面の alt が空、法人の画像の alt がクラス名「TopPage__business--adsButton」。日本語ページに英語の同意の帯（TimeTree）。
- HTML に本文が無く、JS が描くまで 6〜8秒白い。主の一文が PNG 164枚の SVG で alt=""、h1 は 15px の橙の行（マネーフォワード ME）。
- 写真10枚を1枚の SVG に base64 で入れて 8,139KB。SMIL・Lottie・出す動きが reduce でも止まらない（マネーフォワード ME）。
- 記章の画像 1,800万人と alt 1,700万人が合わない。目的別ガイドに h1 が無い。登録のリンクが全部 target="_blank"。料金ページの本文に登録・試すボタンが0（マネーフォワード ME）。
- 使わない列の割引の札を opacity:0 で残し、読み上げで「16% OFF」と読ませる。Work の実際の割引は 10.0%。税の表記なし（Moneytree）。
- 緑のボタンの白文字 2.46:1、ホバー 3.23:1、RECOMMENDED の白 1.94:1（Moneytree）。
- 機能の章の3層のパララックスが reduce でも動く。CSS に reduced-motion 0回（Moneytree）。
- ヘルプ（Intercom）から製品サイトに戻れず、日本語の検索は1文字ずつ一致して0件が出ない。製品サイトの4ページが lang="en"（Moneytree）。
