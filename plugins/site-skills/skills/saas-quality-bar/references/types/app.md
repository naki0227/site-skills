## 見本の実測

### Todoist（Doist）https://www.todoist.com/ja — 2026-10-27
- **最初の画面**：h1「シンプルに整う。」55px/600・字間 -0.01em（SP 37px）、一文 20.5px/500（地との比 5.14:1 の #25221e 66%）、レビューのピル（Apple・Android の印＋「35万+ ★★★★★ 件のレビュー」14.5px）、主ボタン「無料で開始する」164×64px だけ。副の行動（資料・デモ）は無い。ストアのバッジはトップに置かず、「アプリをダウンロード」は締めの章の主ボタンの下に文字で。/ja/downloads は6タブ（デスクトップ・Android・iOS・ウェアラブル・ブラウザ拡張機能・メール アドオン）。
- **主ボタン**：下に 6px の板（#ffb399・角 13px）を敷き、ホバー .3s `linear(0, .804 19.5%, 1.02 29.6%, 1.054 38.2%, 1.001 64.3%, 1)` で 2.5px、押す .15s cubic-bezier(.3,.7,.3,1) で 5px 沈む。戻り .5s のばね。角 15px。ナビのボタン（139×39px・角 8px）は平ら。白文字と地 #e34432 は 4.09:1（足りない）。
- **製品の見せ方**：4機能の右に動画（webm、Cloudinary `f_auto,q_auto`、1本 139〜201KB）。URL が `/product-ui/sequences/ja/…` と言語ごとに分かれ、日本語版の画面は「ヨガ 30分間」「歯科の予約」のような日本語のタスク。autoplay なし・`loop muted preload="metadata"`・poster ありで、見えたときに JS で再生。PC 590×550px を sticky で止めて左の文が入れ替わる（scroll-pin-group）、SP 327×305px を1本ずつ。トップの動画の合計 PC 1,093KB・SP 290KB。
- **機能の並べ方**：機能別。機能ページは10章、h2・h3 がすべて 38px（段が1つ）、絵と文の左右交互。h1 は打ち消し線の言い直し「~~手に負えない~~ 上手に管理」。トップのテンプレートは radio の6タブ（選ぶと地 #ebf5f0）・カード 243×315px・角 10px。
- **料金表**：初心者 $0／プロ $5（年払い、$60/年）・月払い $7／ビジネス $8（+ 地方税・/ユーザー/月、$96/年）・月払い $10。初めは年払い、切り替えの横に「約20%オフ」12px・緑 #4c7a45・地 #f0f6df（プロの実際の割引は 28.6%）。通貨の select 13（JPY ならプロ ￥672/月・￥8,064/年）で、押して 50ms で全カードと比較表の見出しが変わる。カード3枚が同じ 426×727px・枠 1px・角 10px、プロとビジネスに同じ星のバッジ。比較表は5区分39行、区分ごとにプラン名を繰り返し、名前の行を sticky top:72px、? の吹き出し38。FAQ は料金ページに置かず、ヘルプの記事1本へリンク。SP は切り替えと通貨を下の「支払いオプションを表示」のシート（271px）に入れる。
- **無料と有料の違い**：数で書く（個人プロジェクト 5 → 300、フィルター 3 → 150、ファイル 5MB → 100MB、レポートの履歴 1週間 → 全期間、テーマ 4 → 8、音声入力「制限付きのセッション」→「無制限」）。
- **試すまで**：「無料で開始する」がトップ10・料金10、すべて /auth/signup。カードの要否・無料期間はどのページにも書いていない。
- **信頼**：媒体の引用3つ（The Verge・PCMag・TechRadar、ロゴは高さ 16px で黒 48% に落とす）＋受賞の札。「私たちは Todoist の開発を 19 年と 271 日間続けています。事業譲渡は決して行いません」。SOC2 Type II の札をトップと料金に。稼働状況は status.todoist.net。事例8件は業種6で絞る（URL が ?industry=）が、/ja でも本文は英語。
- **ヘルプ**：検索欄 802×56px・角 13px、打つと候補8件、Enter で件数つきの結果。0件は「他のキーワードをお試しください。」だけ。
- **見た目**：地 #fefdfc、文字 #25221e と 66%、帯は peach #fff6f0・sea-salt #ebf5f0・grey #f9f7f6。書体は Graphik（見出し）・Inter（本文 15.5px）・Caecilia（引用）・Shantell Sans（手書きの一言）、日本語は端末の書体。文字は clamp で 480〜1120px の間を伸ばす。動きは .15s／.35s cubic-bezier(.2,.8,.2,1) の2つ。
- **重さ**：PC で top 4.83MB / features 3.69MB / pricing 2.79MB / customers 2.81MB / help 2.60MB（SP top 3.98MB、解析を除く転送量）。広告・解析が top で21ホスト・展開後 約3.7MB（自分の分 2.8MB より多い）。top の HTML 694KB は実験の別の版を隠して入れているため。構造化データは0。

## 真似る型
（見本が2つ以上そろったら、共通する型をここにまとめる。今は Todoist 1件だけなので、上の実測を出発点にする。）
- 個人向けは、最初の画面の行動を1つにしてよい（Todoist は「無料で開始する」1つ。業務SaaS の Backlog・開発者向けの Resend は「試す＋読む」の2つ）。
- 翻訳したサイトの製品画面は、その言語のタスク・日付で作り直す（Todoist /sequences/ja/）。
