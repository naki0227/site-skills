# SaaSで見ること・決めること

解剖でも、作るときでも、この順に見る。作るときは、それぞれに「どうするか」を1行で決めてから書き始める。
解剖で裏づけた値は `types/<slug>.md` に、どのサイトの値かを添えて書く。このファイルには問いだけを置く。

- **最初の画面**：何をする道具かの一文、主な行動と副の行動（試す／相談）、製品画面を見せるか。
- **製品の見せ方**：実画面の画像・動画・DOM で作ったモック・図のどれか、動くか、重さ。
- **機能の並べ方**：課題別・役割別・機能別のどれか、1機能の説明の型（見出し・一文・画面）。
- **料金表**：プランの数、おすすめの強調、月払い／年払いの切り替えと割引の見せ方、比較表の行数と折りたたみ、問い合わせのプラン、税と通貨の表記。
- **試すまで**：無料で試すまでの手順の数（見える範囲。登録はしない）、フォームの項目、クレジットカードの要否の表記。
- **事例と信頼**：ロゴの並べ方、数字、引用、事例詳細の構成、セキュリティ・認証・稼働率の見せ方。
- **データと重さ**：構造化データ（SoftwareApplication・Product・FAQPage）、他ページの先読み、チャットや解析のスクリプト。
- **見た目**：配色（上位の色と役割・コントラスト）、文字の段（PC／SP）、余白の段、角丸、ボタン、動きの値。
- **状態**：空・エラー・0件・読み込み中・送信中・完了が、公開ページの部品（料金の計算・検索・絞り込み・フォーム）でどう見えるか。
