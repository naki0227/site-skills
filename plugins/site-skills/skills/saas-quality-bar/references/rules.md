36. 料金のカードの中身が、開くたびに変わる（Plain は8回中3回だけ「MOST POPULAR」の札、Ramp はカードの機能の箇条の順が3通り）。真似ない：サーバーの HTML と最初の描画を同じにし、試験で出し分けるなら同じ人には同じ版を出す。

37. SP の料金ページで比較表を削る（Cursor は PC の 57行の table が SP で幅0、Runway は PC の 3区分46行のうち SP は AI video の4行だけで、画像・音声の区分と View more が出ない）。真似ない：SP でも区分を全部置き、閉じて始める（rules 2・35）。
38. 写真や背景の画像を、テキストのファイル（CSS・SVG）に base64 で埋めて重くする（ワンバンクはフッターの背景 PNG 2枚 2,682KB を全ページ共通の CSS 2,718KB に、Studio とマネーフォワード ME は写真を SVG の中に PNG で＝規則22）。真似ない：画像は別ファイルにし、見えるところで読む。
