# 横断ルール：SaaSのサイトをまたいで効いていること

2つ以上のサイトで同じ結果になったことだけを、番号つきで書く。1サイトだけの発見は `types/<slug>.md` に置く。
書くときは（〇〇と△△で確認）のように、元になったサイトを添える。

1. 料金ページの下に FAQ を10問以上置き、料金・上限・支払いの疑問をそこで答える（Backlog 10問、Resend 15問）。Resend は FAQPage の構造化データも付け、Backlog は付けていない。
2. 比較表は5〜6区分に分け、区分ごとに見出しを付ける（Backlog 5区分35行、Resend 6区分）。
3. 契約の入口の文言は、プランごとに変えず1つにそろえる（Backlog は全カード同じトライアル、Resend は全カードのボタンが「Get started」で /signup）。
4. 最初の画面の行動は2つにし、主は「試す」、副は「読む」（資料・ドキュメント）にして、副を見た目で一段弱くする（Backlog は橙の塗りと橙の枠、Resend は枠＋面のボタンと枠なしの文字）。
