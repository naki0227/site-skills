# 横断ルール：SaaSのサイトをまたいで効いていること

2つ以上のサイトで同じ結果になったことだけを、番号つきで書く。1サイトだけの発見は `types/<slug>.md` に置く。
書くときは（〇〇と△△で確認）のように、元になったサイトを添える。

1. 料金ページの下に FAQ を10問以上置き、料金・上限・支払いの疑問をそこで答える（Backlog 10問、Resend 15問）。Resend は FAQPage の構造化データも付け、Backlog は付けていない。Nani翻訳は料金ページに FAQ を置かず、上限は ? の吹き出し、支払いはヘルプの3問に分けている。Todoist も料金ページに FAQ を置かず、ヘルプの記事1本へのリンクだけ（個人向けの2サイトは、どちらも料金の FAQ をヘルプに置く）。microCMS も料金ページに FAQ を置かず「ご契約に関するよくある質問はこちら」でヘルプへ。代わりに比較表の下に注 ※1〜※8（超過時の API 停止・トライアルは1サービス1回など）を置く。
2. 比較表は5〜8区分に分け、区分ごとに見出しを付ける（Backlog 5区分35行、Resend 6区分45行、Todoist 5区分39行、microCMS 8区分46行）。行が40を超えると、Backlog の SP・microCMS は `<details>` で区分を開閉できるようにしている。
3. 契約の入口の文言は、プランごとに変えず1つにそろえる（Backlog は全カード同じトライアル、Resend は全カードのボタンが「Get started」で /signup、Todoist は有料2枚とトップ・ナビが「無料で開始する」で /auth/signup、無料のカードだけ「始める」、microCMS は3枚が「無料で始める」で app.microcms.io/signup、Enterprise だけ「お問い合わせ」。ただし microCMS はヘッダー・トップでは「無料ではじめる」とかなにしていて、文言が2つある）。
4. 最初の画面の行動は2つにし、主は「試す」、副は「読む」（資料・ドキュメント）にして、副を見た目で一段弱くする（Backlog は橙の塗りと橙の枠、Resend は枠＋面のボタンと枠なしの文字）。個人向けアプリの Todoist は「無料で開始する」1つだけで副を置かない（業務SaaS・開発者向けの型）。microCMS の副は資料ではなく「ビジネス職向けページ」（読み手を役割で分ける入口、枠のボタン）。
5. 年払いの割引は、切り替えの部品の中か横に率で書く（Backlog はラベルに「(5%オフ)」、Nani翻訳はタブの中に青い札「-20%」、Todoist は切り替えの横に緑の札「約20%オフ」）。3つとも年払いのときだけ価格の横に年額を出す（Backlog は年額の行、Nani翻訳は「￥12,000 年払い」、Todoist は「$60 年払い」）。個人向けの2つ（Nani翻訳・Todoist）は、初めから年払いを選んでいる。
6. 稼働状況のページを別ドメインに持ち、フッターからつなぐ（Backlog は status.nulab.com、Nani翻訳は「障害情報」→ status.nani.now、Todoist はフッターとヘルプの「システム ステータス」→ status.todoist.net）。
7. 相談・チャットのウィジェットを全ページで読み込み、どのページでも一番重いファイルにしている（Backlog・コドモンは商談予約の immedio main.js 2,037KB、microCMS は PC だけ HubSpot の会話 visitor.js 1,404KB＋CSS 537KB ほか 約 2.5MB で、機能ページの PC の 69%）。真似ない：右下のボタンは自前の小さな部品にし、押したときに本体を読む。
8. 実績の数字には、時点と数え方を添える（Backlog「2026年6月末」と数え方の注記、コドモン「2026年10月1日時点」と※の数え方・調査元）。microCMS の「ご利用企業数17,000社以上・継続率99%」には時点も数え方も無く、何を数えたのか（無料を含むか）がわからない。
9. 検索の0件は、見出しと一言だけで終わっていて、言い換えの例・よく読まれる記事・問い合わせへの道を出さない（コドモンのヘルプは「0件」の見出しだけ、Todoist のヘルプは「他のキーワードをお試しください。」と挿絵だけ、microCMS の事例の絞り込みは「0件」と「絞り込み条件（リセット）」だけで、リセットは span）。真似ない：0件には言い換えの例と、よく読まれる記事2〜3件と、問い合わせへの道を置く。
10. 流れ続ける帯を、`prefers-reduced-motion: reduce` でも止めない（Nani翻訳の声の帯は 48s のまま、Todoist の数字の帯は 30s → 180s に遅くするだけ）。どちらも止めるボタンが無い。真似ない：reduce では止めて横に並べ、止めるボタンを付ける。
11. 事例の詳細は、問答の本文の前に「導入前の課題」「導入後の効果」を箇条書きで置く（Backlog は h1 に成果の数字＋課題・効果の箇条書き、microCMS は課題3行・効果2行のあとに目次）。読み手は箇条書きだけで自分ごとかを決め、本文は確かめたい人が読む。
12. 「試す」の直前か中に、クレジットカード（支払い情報）が要らないことを書く（Backlog はボタンの中に「支払い情報の入力不要」、microCMS はボタンの直前に「＼ クレジットカードの登録不要 ／」と料金の Hobby のカード）。Todoist はどのページにも書いていない。
